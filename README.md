**敞口刻度（F25）**：基准是满仓等权池，而袖套平均只投出 76.9%（0.873 权益权重 × 整手粒度），
实测**超额 ≈ −10.4 + 26.2 × 权益权重（R²=0.955）**：0.873→+14.9pp/−32.3% 回撤；
0.95→+16.7pp/−35.1%；**1.00→+17.6pp/−36.6%**（生产构型，F52 两套种子 +17.78/+17.47；研究构型 hyst=0.2 是 +18.00/+17.30、−36.9%）。
⇒ 想要更多超额，先决定**愿意让袖套多满仓**——这是风险预算，不是 alpha。
