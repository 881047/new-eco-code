# 第三轮预注册 · LLM 拥挤度剔除器（2026-09-17 冻结）

> 背景与数据支撑（第二轮门禁实证）：
> 图特征在微盘域是**显著反向**——金股热度死区 -0.98%(t=-2.73)、多事件共振 -0.77%(t=-2.47)。
> 事件图谱特征不预测哪个股会涨，但能识别哪些股**正在被拥挤关注**（散户跟风热门推荐的行为痕迹）。
> ⇒ 本轮假设：**剔除"拥挤/过热"股可以提升组合的死区超额**。
> LLM 的角色：对共振子图打拥挤分（1~10），输出必须引用具体边（券商/日期/事件类型），
> **引用不实的打分行按 0 分计**（机械 SQL 校验——幻觉锚定）。

## 剔除器构造（冻结）

1. 种子池 = 现役生产构型的月末候选（top100/带宽8×，与生产一致）；
2. LLM 打分：每个候选股的共振子图（锚点日前 60 天的图谱边）→ 拥挤分 1~10
   （维度：券商推荐密度、评级一致性（全是买入=拥挤）、事件多样性、标题情绪热度）；
3. 剔除规则：拥挤分 ≥ 阈值 θ 的候选从买入池剔除，空出的槽位由候补（排名下一位）补足；
   θ 扫描 {5,6,7,8} 四档（这四档是本批全部臂，Bonferroni 分母=4）。

## 判据（跑数前冻结；对照臂 = 不剔除的现役回测，同期同代码）

主判据（两轴，与 exp_train_months 同款纪律）：
- **采纳** ⇔ 死区窗(2020-09~2023-12)超额比对照**改善 ≥ 1.0pp/年**
  且 全期(2019-07~)超额退化 ≤ 1.0pp/年
  且 最大回撤不劣化 > 1pp；
- 任一 θ 档全过 ⇒ 取改善最大的 θ 进组合层复验；全不过 ⇒ 剔除器方向结清。
- LLM 打分不实惩罚（引用缺失计 0 分 ⇒ 不触发剔除）已内建于构造。

## 明确不做

- 不改现役 31 因子、不改打分模型、不改生产链路（剔除器是候选池的**负向过滤层**，
  采纳与否由组合层判决，进生产另走重钉流程）；
- 不在死区窗之外的任何窗口上调参（θ 扫描四档一次跑完，禁止跑完加档）。
