## 2. 硬性执行规则

1. **预期 Δ < 5.1pp 的候选，禁止直接上 L3。** 组合层月频根本测不出来 ⇒ 必先过 L1。
   （这一条解释了为什么超参 / 结构 / 权重 / 数据族等方向反复判"不可区分"——不是没效果，是秤不够准。）
2. **L1 通过**（Δ ≥ 1.6pp 且 t ≥ 1.6，或按预注册自定门限）才上 **L3 双轴终判**（超额 + MDD）。
3. **要判 Δ ≈ 2pp** ⇒ 走 **L2**（1 组 seed 集即可）或 **L4**（需约 7 组 seed 集，见 B5 误差预算）。
4. **多组 seed 集 N** 一律用**零重叠**种子集（F76b 共享 2/4 seed 的缺陷不许重演）⇒ error = √2·σ_total/√N。
5. **配对 t 的虚高只有约 1.20 倍**（组合层 J4 = √2·2.721/3.212），远小于 F76b 实测的 1.77
   ⇒ 既有配对 t **基本可用**；1.77 那个异常已被 B3 归因到生产表漂移，不是 t 的问题。

## 4. 不可判定的处置

候选效应 < 所在档的可辨 Δ ⇒ 直接判 `effect_indistinguishable` 并登记 05 号，**不再投入重训**，
登记时必须写明：预期 Δ、所在档、该档可辨 Δ。⇒ 避免"秤不准却反复称"的浪费（F76b 就是前车之鉴）。

## 5. 前提与失效条件

- 本文所有 SE 基于 **K=4、T=115、全窗 2017-01~2026-08、生产构型零覆盖**。换任一条件需重标定。
- 若后续组 A 继续扩臂导致 σ_total 点估计移动超过 CI，本文表格需同步更新（**追加**，不回溯改旧读数）。

  本文按当前点估计取"加期数优先"，若后续判定翻到 persistent_dominant，L2/L4 的红利需重新评估。
