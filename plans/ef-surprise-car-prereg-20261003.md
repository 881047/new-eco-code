# 业绩预告 surprise 条件化事件研究预注册（2026-10-03，跑数前冻结）

> 来源：事件族普查（`plans/event-census-prereg-20261003.md`）登记的活路①条件化变体；
> 用户指令"把活路全部实践一遍" = 本预注册的拍板。普查无条件设计看不到条件化效应
>（无条件 periodic_report −0.27pp = PEAD 需 surprise 条件化的再证），本预注册检验
> 第一优先条件化：**预告方向与幅度**。

## 一、可行性勘察（冻结，先于判据）

标题层三变体全部不可构造（实测）：回购金额/股数在标题 **0%**（30,541 事件）、业绩
预告方向词仅 4.1%、幅度 0.0%、激励规模 0%（且 equity_incentive 类混入大量解除限售/
注销噪声，普查该类 +0.43pp 的可解释性存疑）。**正文级字段路径**：
`data/text_corpus/fields_llm_all/llm_all.parquet`（已付成本 ~1,300 元的在库资产）：
ef 类 92,579 条公告、**全年份 2019-2026 覆盖**，`ef_yoy_pct` 非空 34,910 条（4,422 只）、
`ef_np_min_wan/ef_np_max_wan` 非空 45,222/45,216 条。

**三变体的执行性终判（冻结）**：
- 业绩预告 surprise（方向+幅度）：**可执行**（字段在库，零新成本）——本预注册；
- 回购比例：**不可执行**（fields 未覆盖 buyback 类——抽取停在 ef/operating；标题 0%）
  ⇒ 复活条件 = buyback 正文抽取（成本须拍板）；
- 激励力度：**不可执行**（同上 + 类目噪声须先清理）⇒ 复活条件同上。

## 二、构造（冻结）

- 事件 = 普查 ef 事件（tagged category=earnings_forecast，(ts_code, 公告日期) 去重，
  元事件排除正则同普查），左连 fields_llm_all（join 键 = 代码+公告日期；同日多条取
  `ef_yoy_pct` 均值）。
- **C1 方向分桶**：`ef_yoy_pct` > 0 = 好消息桶，< 0 = 坏消息桶（yoy 可 < −100%，符号
  仍为方向代理；扭亏的基数为负属已知限制）；
- **C2 幅度分桶（描述读数）**：各符号桶内按 |yoy| 秩三分位，看单调性；
- 求值链与普查逐字同源：主读数 = 市场调整 CAR(21)（E = t0 后首个交易日，
  Σ_{E+1..E+21}(r_stock − r_bench)，缺失 ≤3 且窗末日有收盘），基准 000300.SH；
- **精确基线对照（普查审计的标准件）**：每桶的等权宇宙基线 = 语料股票（5,455 只）在
  **该桶自身事件日历**上的等权 CAR21（事件数加权）；超额 = 实际 − 基线。

## 三、判据（冻结）

- **主判据 C1 spread = CAR21(好消息) − CAR21(坏消息)**：Welch 双样本 |t| ≥ 2 且双子窗
  （2019-2022 / 2023-2026）spread 同号且各自 |t| ≥ 1.5，且两桶超额符号与 spread 一致
  ⇒ **"条件化效应成立"**；否则 = "本构造下未证实"；
- C2 单调性为描述读数不进判决；
- 事后不许：换 surprise 度量/换分桶阈值/加桶/子样本重跑/把 C2 单调性当判决。

## 四、边界与留痕

  精确基线只控宇宙共模不控类内风格；surprise 为抽取字段（金标准 C1 90.9% 在册）；
