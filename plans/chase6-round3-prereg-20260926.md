## 一、两个臂组（同引擎同撮合，缝注入零改动）

### 臂组 1：θ 剂量曲线（日频代理信号，两窗）

`chase6@θ`，θ ∈ **{1.5, 2.0, 2.5, 3.0}**（θ=2.0 为主臂重跑作锚），两窗各跑：
- 85 期窗（20190731..20260831）
- 全史窗（20170126..20260831）

信号定义与第一/二轮**一字不改**（chase_z = max(z(mom5), z(devvwap))，截面 = 当期锚点
model_score ∩ PIT 可交易域）。

### 臂组 2：min60 原信号替换（θ=2.0，85 期窗）

把日频代理换成 F75 注册的 min60 原信号（r4 同款配方，`data/min60_derived/daily.parquet`，
覆盖 2020-01 起）：
- `x2`（尾盘动量）|x2|≤0.21、`x3`（收盘对日 VWAP 偏离）|x3|≤0.15 净化后 pivot；
- `lr5 = x2.rolling(5).sum()`、`cv5 = x3.rolling(5).mean()`，**在锚点交易日取值**（不用
  resample("ME")——日历月末与交易日月末错位会引入一个月陈旧）；
- 截面 z（当期锚点 model_score ∩ PIT 域内可算者）⇒ `chase_z_min60 = max(z_lr, z_cv) > 2.0`
  剔除；**2020-01 之前无 min60 数据 ⇒ 不剔除**（该段臂与 base 同构，如实登记）。

## 二、判据（冻结）

**"进拍板"（chase6 从候选升级为正式采纳包）= 以下两条同时成立**：

1. **剂量稳健**：全史窗 θ ∈ {1.5, 2.0, 2.5} 的 Δsys_ann（vs 全史 base_fh）**全部 ≥ +0.5pp/年**
   且 Δsys_mdd ≥ 0——剂量曲线不许只在单点上成立；
2. **信号不反**：min60 臂（85 期窗）Δsys_ann ≥ 0——原信号至少不能比代理差出符号。

任一不成立 ⇒ **chase6 线结清**（85/全史两窗的确认读数判"剂量/信号脆弱"，不再投入）。
两条都过 ⇒ 产出**正式采纳包**（builder 候选剔除 + config 开关 + 重钉评估清单）交用户拍板；
本轮本身**仍不改任何生产文件、不重钉**。

2. min60 三列的净化阈（|x2|≤0.21 / |x3|≤0.15）沿用 r4 冻结值，不重调；
