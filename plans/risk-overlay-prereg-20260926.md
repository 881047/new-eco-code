## 一、问题（单一）

月频主线的**日频回撤 −32.77%** vs 月频口径 −22.80%（pin `20260922_trbench`）是当前最大痛点
（09-25 调研 #1 评级中-高）。月频链**月内没有仓位自由度**（持仓固定一个月），唯一可行动点 =
**建仓时（plan-time）**。本轮判一件事：**建仓时的量价风控叠加，能否以可接受的收益损耗
压低日频回撤**。

## 三、臂设计（5 个判决臂 + 2 个灵敏度臂，全部同引擎同撮合）

| 臂 | 配置 | 动作 | 角色 |
|---|---|---|---|
| `base` | 生产 config（top6、cand_top=0、恒定 0.873） | 无 | 有效性门：逐位复现 pin 7 项（容差 5e-4） |
| `base20` | 同 base 但 `candidate_top=20`（引擎自带 nlargest(20)+整手/行业上限向下补位） | 无 | 诊断臂：把"补位效应"从"剔除效应"里剥出来（P5-1：1 万本金下补位系统性恶化） |
| `chase6` | 生产 config + 追高剔除 | 建仓名单剔除追高股，**不补位**（少买 ⇒ 现金留存） | 主臂 1 |
| `chase20` | candidate_top=20 + 追高剔除 | 剔除后由第 7~20 名**向下补位** | 主臂 2 |
| `gate` | 生产 config + 市场风险闸 | 闸开当月 `equity_cash ×0.5`（每月自动重新判定，无退出） | 次臂 |
| `chase20@θ=1.5 / 2.5` | 同 chase20 换 θ | — | 灵敏度，**只报告不判决** |

采纳包语义：`chase6` = "生产 config + 剔除"；`chase20` = "candidate_top=20 + 剔除"——
判据一律对 `base` 比（真实采纳差），`base20` 只做归因分解（Δ_chase = Δ_补位 + Δ_剔除）。

## 四、信号冻结（跑数前写死）

### 4.1 追高信号 `chase_z`（日频代理，动因 = F75 头部 t≈−5.9 的已登记认识）

对每个锚点日 `d`（= `model_score.trade_date` 月末评分日，与引擎 `sd` 同源）：

- 截面 = 当期锚点 `model_score` 全体 ∩ `PITEngine.tradable_mask(d)` 可交易域
  （与生产候选域同口径，`star/bse` 按 config 关）；
- `mom5_i = adjClose_i(d) / adjClose_i(d−5) − 1`（近 5 交易日复权收盘动量，含 d）；
- `vwap5_i = 10 × Σ_{j=d−4..d} amount_ij / Σ vol_ij`（近 5 日成交额/成交量比，tushare
  amount 千元 / vol 手 ⇒ 元/股；比例的截面 z 对统一量纲因子不敏感）；
  `devvwap_i = close_i(d) / vwap5_i − 1`；
- `z1 = z(mom5)`、`z2 = z(devvwap)`（截面 z，均值/样本std）；
  **`chase_z = max(z1, z2)`**（任一轴极端即视为追高）；
- **θ = 2.0**（主判）；θ∈{1.5, 2.5} 只做灵敏度报告。

无前视声明：信号只用 `d` 当日及以前的数据（评分在 d 收盘后、执行在其后，与生产一致）。

### 4.2 市场风险闸（冻结一组参数，不做网格）

`gate_on(d) = [ 中证500(000905.SH) close(d) / max(close, 近 20 交易日含 d) − 1 ] ≤ −0.08`
⇒ 闸开当月两线 `equity_cash ×0.5`（满仓线与系统线同乘；结转仓位处置不变）。

### 4.3 缝（引擎零改动）

`E.allocate_lots` 包一层：按期号（调用奇偶 = 满仓线/系统线，每期恰 2 次，退出时断言
调用数 == 2×期数）从 `lot_df`（ts_code 索引）剔除 `chase_z > θ` 的行（chase 臂）或
缩放 `equity_cash`（gate 臂）。补位由 `allocate_lots` 现有的"向下贪心"机制自然完成，
不写第二套分配实现。信号不满足可查（候选不在截面 dict 中 ⇒ 不剔除，计数上报）。

## 五、判据（冻结；X = 3.0pp / 2.0pp，用户授权 AI 定）

**主判据（对 `base` 比，双轴同时满足才算过）**：

- **回撤轴**：`Δ sys_mdd_daily ≤ −3.0pp`（日频回撤从 −32.77% 改善至少 3pp）；
- **收益轴**：`Δ sys_ann ≥ −2.0pp`（系统线年化损耗 ≤ 2pp，即 ≥ 12.97%）。

**为什么是 3.0/2.0**：袖套 governor 的实测保费比 = 3.14pp 换 13.75pp ≈ 1:4.4；
月盘风控层若连 1:1.5 都做不到（损耗 2pp 换回撤 3pp），不值得引入常驻复杂度 +
candidate_top 行为变更 + 重钉成本。两轴**必须同时**过，任一不过 = 按冻结判据不采纳。

**有效性门**：`base` 臂 7 项读数逐位复现 pin（容差 5e-4，同 governor A/B）；
失败则本轮作废、查数据漂移，不许带病出数。

**多重性登记**：3 个判决臂 × 1 个双轴判据。本轮是风控采纳决策（非 alpha 发现），
按 governor A/B 先例不做 Bonferroni 折扣，但 3 臂同时过才考虑"组合使用"；
单臂过 = 该臂单独采纳建议。灵敏度臂（θ 网格）无论读数如何不触发采纳。

**窗口**：20190731..20260831（85 期，与 pin/governor A/B 同窗）。单窗结果，
外推须谨慎（§6补.2 的教训：全史与评估窗结论可以方向相反）。
