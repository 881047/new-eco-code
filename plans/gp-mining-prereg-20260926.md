## 一、背景与唯一目的

`app/alpha/factory.py` 的 GP 路径 2026-09-11 冒烟建线 → 09-13 修复 `bind_factory`
接线缺陷（P0-05 类静默退化：适应度摸不到工厂 PIT 域 ⇒ 整个符号回归退化为随机搜索，
DB 实证当时 171 行里 0 行来自 GP）→ **此后从未真实运行**（现 alpha_bank 206 行里
0 行来自 GP）。调研 #2（`plans/neweco-model-innovation-survey-20260925.md`）把
"GP/LLM 挖掘 + 半衰期/拥挤度监控循环"列为优先级 #2；监控仪表盘已上线
（`scripts/factor_lifecycle_monitor.py`，13 号 §八），缺口就是挖掘环节从未转起来。

**本轮唯一目的：第一次把 GP 环真实跑通**（挖掘 → 门禁 → 登记 → 可被监控闭环），并
把它的多重比较成本显式入账。**跑前预期管理（诚实写死）**：正向选股方向在本仓已全线
证伪（LLM 提案 0/18、KG 图特征 0/14、alpha_pool 筛查 49/189 → Phase 2 重训不采纳），
本轮 **0 PASS 是基准预期，不是失败**。产出价值 = ①机制首跑与可复现性（seed 冻结）；
②GP Pareto 前沿的死区 head 读数分布（这是 factory 建成以来第一次有这个数）；
③分母成本入账后，"要不要再挖"从此有价签。

## 三、判据与出口声明（跑前写死）

1. 门禁 = `app/alpha/gate.py` 六判据**一字不改**（死区 head ≥0.5%/月、t ≥2、死/活同号、
   Bonferroni p_adj <0.05、死区 top6 ≥0、成本项 fail-closed）。
2. **PASS = POOLED = 有资格进组合层回测，不等于可用**（在册反例 4 个：die_flow /
   head_vt / h10 / margin_net_share）。任何 PASS 因子的组合层判决须另立预注册；
   本轮**不产出任何"该用哪个因子"的结论**。
3. **本轮预注册的"成功"定义** = 完整跑通 + 全部求值行入册 + 读数 JSON 产物 +
   分母入账 —— **不是**"挖出 PASS 因子"。0 PASS 的结论写作"GP 在本仓死区 × 900
   预算下无可检出增量"，照样登记结清。
4. 事后不许：改判据 / 重跑挑窗 / 把前沿外个体捞回 / 用活跃区读数反向挑前沿成员。

## 五、限制（跑前写死）

1. 60×15 是**小预算**（行业实践 DFQ 级为百万级个体）⇒ 本轮只回答"机制通不通 +
   小预算下有没有明显信号"，**不回答"GP 挖不出"**——那需要分母预算的拍板；
2. 死区 39 期月度截面，单 alpha 检出下限低（v1 轮已登记）；
3. GP 个体全部是量价派生 ⇒ 与存量 31 因子**同信息源**，非异构口粮（中心论点
   "数据异构 > 算法异构"下，量价 GP 的先验增益有限）；
4. 分母 900+ 永久入账 ⇒ 下一批任何候选的门禁都更严——这是本轮最真实的成本，
   登记在案供"要不要再挖"的拍板引用。
