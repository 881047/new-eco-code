# LLM 金融雏形可行性研究——"堆数据预测市场趋势"（2026-09-29）

> 性质：战略研究（用户问题："如果堆数据，在预测市场趋势方面是否可以打造出一个
> LLM 金融雏形"）。承接 plans/llm-paradigm-for-markets-survey-20260929.md
> （LLM 骨架可迁移、差距在数据侧）。本文回答"堆数据造雏形"的工程可行性、
> 该让雏形预测什么、以及最小可行形态。

## §一 我们已经堆了多少数据（库内实点盘点）

| 类别 | 资产 | 规模 |
|---|---|---|
| 量价/估值 | daily / adj_factor / daily_basic | 1,286 万 + 1,342 万 + 1,278 万行 |
| 资金类 | moneyflow / margin / hk_hold | 1,258 万 + 676 万 + 560 万行 |
| 因子/模型 | factor 表（31 因子月频+近端日频）/ model_score | 2,211 万 / 44 万行 |
| 事件类 | lhb 族 / fina_indicator / namechange / index_weight | ~53 万行 |
| **文本（库外）** | 巨潮公告标题（rubric v2 已打标） | **459 万条**（2024-01 起 PIT） |
| 研究 | alpha_pool npz 因子面板 | 247 个 |
| 合计 | 结构化 ~9,000 万行 + 文本 459 万条 | 11G SQLite + 语料目录 |

**判定：雏形的数据底座已完成 ~80%**——量价/资金/事件/文本四族齐备，且全部带
PIT 纪律（ann_date 顺延、时点行业、可交易域六层），这是外面任何公开数据集都没有
的工程化程度。缺的只有：公告**正文**（PDF 链路已验证 GO 未回填）、互动易/问询
（已登记）、新闻流（东财接口已死）。

## §二 文献给出的雏形形态判决：适配 > 预训练

- **BloombergGPT**（从零预训练，约 267 万美元训练成本）：被通用模型追平，
  领域从零预训练的性价比被证伪。
- **FinGPT**（LoRA 适配开源底座，训练成本 ~65.6 美元）：在金融情感基准上
  **击败 BloombergGPT**（~82% 准确率）。
- **Kronos**（清华 2025-08，开源）：K 线"语言"基础模型已存在——零样本做
  波动率/价格序列预测。**但文献与上一轮综述一致：对截面收益预测弱**。
- **本仓硬件现实**：CPU-only（torch 被 Smart App Control 拦）、2 万本金。
  从零预训练不可行也不必要；**适配/零样本/检索增强路线完全可行**。

⇒ **雏形的正确形态 = "现成 LLM 推理引擎 × 我们的数据底座 × 门禁"，不是从零训练**。
这与 LLM 史教训（RLHF/LoRA 时代：底座通用化、价值在数据与对齐）完全一致。

## §三 "预测市场趋势"必须拆成三个问题（可行性各不同）

| 问题 | 判决 | 依据 |
|---|---|---|
| **① 方向择时**（涨/跌） | ❌ 不可行 | 本仓三连败（29 补"去糟"清单）；regime 判"描述性非信号"；反身性最强、文献无稳定证据 |
| **② 波动/体制状态** | 🟡 部分可行 | TSFM/Kronos 对波动率预测有正面证据（波动可预测性远强于方向）；本仓 vol 缩放 INDETERMINATE（MDD 改善 +4.42pp 差 0.58pp 达线）——体制信号真实但边际薄 |
| **③ 截面相对强弱**（选股） | ✅ 可行且是主战场 | 这不是"趋势预测"而是排序；LLM 雏形的正路 = 文本→截面信号（Lopez-Lira 方向，且我们有 459 万公告 + 打标体系） |

⇒ **"LLM 金融雏形预测市场趋势"若指①：堆再多数据也不成立（判死线+均衡逻辑）；
若指②③：工程上能造出来，且资产已就绪。**

## §四 雏形最小可行架构（全部用现有资产拼装）

**P1 文本→截面信号链**（治本路，最高优先）：
公告正文回填（pypdf，链路已 GO）→ LLM 打标/嵌入（rubric v2 已建，扩到正文级字段）→
事件因子族 → 三层门禁。判据：沿用门禁（六判据门→单因子档→组合层）。
这是 09-27 LLM 线"可行角色"清单的正位执行。

**P2 体制/波动读数链**（Kronos 路线）：
Kronos 零样本输出波动率预测 → 接入 vol 缩放 overlay 的 σ_est（把 INDETERMINATE
的 4.42pp 转正所需的正是更好的波动估计）→ 季度复跑判据（≥5pp 达线即触发生产预注册）。

**P3 LLM 复盘/异常检测**（零风险）：
日终总结 + 事件流叙事已有（llm.py agent 模式），扩成"打标→归因→复盘"闭环。
09-27 已判：LLM 可行角色 = 复盘/异常检测/降噪素材（非正向挖因子）。

**共同纪律**：三个链路全部走本仓门禁；雏形的"准确"不由感觉判定，由
pin/PBO/纸面盘（唯一不被回测污染的评测）判定。

## §五 结论

**能造，且 80% 的材料已经在库里。** 判决分层：
1. 从零训练金融大模型：❌（BloombergGPT 教训 + 硬件现实 + 均衡逻辑三杀）；
2. 用堆数据造"适配型雏形"（检索增强/LoRA/零样本 TSFM × 9,000 万行结构化 +
   459 万文本）：✅ 工程可行，形态 = P1+P2+P3 三条链，成本量级数百美元级；
3. "准确预测市场趋势"：方向①不可行（结构性），波动/体制②部分可行（边际薄、
   接口已在），截面③可行且是我们唯一拥有持续正路的方向。

**一句话：雏形造得出来，数据已经堆得差不多；它的价值不在"预测涨跌"，
而在把 459 万条公告变成门禁愿意盖章的截面信号——那是这个系统唯一还在变宽的路。**
