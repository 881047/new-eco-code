# LLM 自主挖因子循环 r2 + KG 降噪读数 预注册（2026-09-26，跑数前冻结）

> 性质：研究层（framework 全关；LLM 只离线提案，**不进任何生产链路**——硬性不变量 #4）。
> 判据跑前冻结；0 PASS 为基准预期；本预注册的"成功"定义 = **自主闭环机制首跑**，
> 不是挖出 PASS（gp_000 第 5 反例的教训已写进上下文）。

## 一、起点与"走自己的路"

- LLM r1（09-17）一次性提案 0/18（17 撞车——LLM 在重新发明已知因子）；此后 LLM 线停摆。
- 本仓三条硬证据构成"自己的路"：① chase6 **采纳**的恰恰是排除性信息（追高剔除 +2.07pp）；
  ② KG/事件/min60 族全部是**反向定价**（t −4~−5 级）；③ gp_000 证明正向 PASS 也可能是
  已知因子影子（ρ(size)=0.951）。⇒ 本轮把冠军思路"KG 降噪声"**翻译成本仓的语言**：
  LLM 不负责发明 alpha，而负责在 KG 拥挤知识条件下提出**可证伪的降噪假设**，
  由标准门禁客观判决；KG 降噪本身作为一组**平行读数**被测量。
- 参考来源说明：2026 深圳国际金融大赛冠军的"KG 降噪声"细节**公开渠道检索不到**
  （2026-09-26 网络检索无相关结果），本设计只采纳其方向（KG 用于降噪而非选股），
  机制全部来自本仓自己的证据与门禁纪律。

## 二、自主闭环（"自己挖"的机制定义）

**迭代 1**：LLM 读上下文 → 提出 **≤10 条**提案。
上下文 = ①现役 31 因子清单；②工厂 DSL 算子表；③KG 25 列数据字典（含覆盖/语义：
评级/金股/股东/催化剂/情绪/共振/pagerank/解禁/增减持）；④**失败知识库**（bank 214 行
分布、r1 撞车原因、F75 反向 t≈−5.9、gp_000 影子教训、chase6 采纳启示）；⑤KG 拥挤
目录（kg_resonance / kg_pagerank_ind 的截面分布）。
每条提案必须带：`name` / `expr`（标准 $ 列 DSL）或 `kg_op`（KG 列机械变换，见 §三）/
`why`（一句话经济含义）/ `noise_hypothesis`（**它借 KG 判断这条因子躲开了什么噪声**）。

**判决**：全部候选过 factory 标准门禁（六判据一字不改，PIT 域，撞车硬闸生效）。

**迭代 2**：LLM 读迭代 1 的**全部读数**（head/t/p_adj/PASS/撞车原因/降噪域对比）→
再提 ≤10 条（允许沿有苗头方向加深、允许修正错误假设；**禁止重复自己已被否的方向**）→
同款判决。

## 三、KG 降噪读数（创新点的测量，报告用，不参与判据）

对每条候选，除标准域读数外，加测**降噪域**：死区横截面剔除「KG 拥挤前十分之一」
（每锚点 `z(kg_resonance) + z(kg_pagerank_ind)` 合成分最高 10% 的票——图谱意义上的
共振/热门股）后的死区 head 与 t。报告 `Δhead_denoised`（降噪域 − 标准域）。
**判据仍以标准域为准**（与全仓所有在册轮次可比）；分母保守计双域。

## 四、预算与判据（冻结）

| 项 | 值 |
|---|---|
| 提案 | 2 迭代 × ≤10 = **≤20 条**；超发截断 |
| KG 变换 | 只许机械小变换：`z(col)` / `rank_pct(col)` / `chg3(col)`（月环比）/ `mul(a,b)` / `ratio(a,b)`，单条 ≤2 列 |
| 门禁 | gate v2 六判据**一字不改**；撞车硬闸生效 |
| Bonferroni 分母 | **40**（20 提案 × 2 域，保守）；N_used = max(40, 在册+40) |
| 判决 | 标准域 PASS = POOLED = 资格非可用；任何 PASS 的组合层第一问 = 增量 vs rev_5/size，第二问 = KG 降噪域是否必要 |
| 成功定义 | 闭环机制首跑（迭代 2 的提案与迭代 1 读数有可检验的承接关系）+ 12+ 降噪读数入册；0 PASS 照样登记 |

## 五、无前视与安全边界（如实登记）

1. LLM 训练语料含 2020 年后的一切 ⇒ **想法层面的前视不可量化**——这正是门禁
   门槛存在的理由；缓解 = 判决只认死区+Bonferroni+组合层，LLM 上下文**不含任何
   原始未来数据**（只有聚合读数与目录）。
2. LLM 输出不进任何生产链路；密钥只在 .env，不落日志。
3. KG 降噪只作用于**读数域**，不改生产选股域（那是换 pin 级，需另立预注册）。
