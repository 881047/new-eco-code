## 因子物化（进第二轮门禁）

每个锚点日 T（只见 ≤T 的边）：
1. **一阶统计**（~10 列）：近 60 天评级上调数/下调数/净方向、金股新纳入券商数、
   席位净增持股变动、分红事件计数、研报覆盖密度变化、主题热度；
2. **共振计数**：多类型边同时指向的股票计数列（≥2 类事件共振=1）；
3. **传导传播**：事件种子沿「PIT 行业边 + 机构共同行为边」做带衰减扩散
   （personalized PageRank，衰减 λ=0.5，NetworkX），输出每只股票的传导强度列；
4. 与第一轮 B/C/D 的 27 条提案合并成第二轮候选池。

## 分母（冻结）

分母 = 图特征新列数 + 27(B/C/D) + 18(第一轮 A 组已用, 如实计入历史 prior)

Bonferroni 累计（`n_tests = max(本批, prior + 本批)`，工厂已实现该语义）。

## 判决

工厂门禁 v2 六条判据**一字不改**（死区头部超额≥0.5%/月+成本、HAC t≥2、
Bonferroni p<0.05、死区/活跃同号、top6≥0、成本可得 fail-closed）。
过闸 ⇒ 组合层两轴判决（另预注册）。

## LLM 锚定推理（第三轮，过闸后）

共振子图 → DeepSeek 打分（-1~1），输出必须引用具体边（券商/日期/方向），
**引用不实的推理行按零分计**（机械检测：边存在性 SQL 校验）——幻觉被锚定。
打分作为因子值进死区评估（历史锚点回放，图时点性阻断未来函数）。
预注册另行冻结（打分 prompt 也属于实验程序，一并冻结）。
