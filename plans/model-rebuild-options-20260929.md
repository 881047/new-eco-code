# "是否是模型的问题" —— 模型归因赛马 + 底层重构可执行方案（2026-09-29）

> 性质：预注册（判据跑数前冻结，commit 即时点）。用户假设：机器学习模型本身有很大劣势，
> 同意从底层直接重构。本文件回答两件事：①"是不是模型的问题"**用实验机械回答**（§1 赛马）；
> ②无论答案如何，底层重构的可执行方案树（§3）。
> 纪律：全部走隔离表 + `run_backtest(score_table=)` 换表回测（09-27 确立的组合层 A/B 通道），
> 零生产改动、零 pin 影响。

## §0 用户假设的已有证据盘点（跑数前如实列出）

- **反对"模型是瓶颈"的既有证据**：13 轮改模型全机械判决（label/head_vt/horizon/uniqueness/
  B1 加权/E2E-DL…）无一过组合层判据；09-27 病因诊断"模型/挖掘/组合技巧/数据质量全非病因"；
  风格暴露归因：去风格后 alpha 10.47%/年 t=1.75 **不显著**（收益主体是小盘凸性暴露）。
- **支持"模型有问题"的既有证据**：全量重训跨日不可复现（根因未定位）；种子噪声 ±3.5pp/年；
  IC 与 top-6 收益反相关（发现② 5 次复现）；LightGBM 黑箱 vs 115 个月度样本的信息比。
- **缺口**：从未测过"**同一特征同一标签下，把学习器换掉会怎样**"。13 轮都在改 LightGBM 的
  用法，没测过"不用 LightGBM"。这正是本次赛马要补的归因实验。

## §1 模型归因赛马（跑数前冻结）

**协议**：同特征（生产 26 因子，消费侧剔除口径）、同标签（21 日行业中性超额，
delist_last_price=True）、同 walk-forward（36 月窗、近端 6 月 holdout 不参训、PIT 可交易域、
北交排除）、同引擎评估（`run_backtest` 全史窗 + prod 窗双窗）。对照 = 生产 LightGBM pin
（库内 `20260928_exe` / `20260928_exe_full`，不重跑）。

**臂**（新打分写入隔离表 `model_score_mlattr_*`）：

| 臂 | 学习器 | 说明 |
|---|---|---|
| ridge | 岭回归（闭式解，标准化特征，λ=1.0 冻结不调参，NaN→0=均值中性） | 极简学习模型：线性 + 强收缩 |
| rankens | **无学习**：26 因子当月截面 pct-rank 等权均值 | "不用机器学习"的 null model |
| random | 固定种子均匀随机分 | 假设检验地板（管线 sanity） |

**判据（冻结）**（全史窗系统线 sys_ann_return 为主判；种子噪声容差 ±3.5pp/年为既有实测界）：

- V1 "ML 无可测增量"：`ridge ≥ LGBM − 3.5pp` **且** `rankens ≥ LGBM − 3.5pp`
  **且** sanity `random ≤ LGBM − 5pp`。
  ⇒ 学习器复杂度不是收益来源；"底层重构"的正确形态 = **以极简模型重构生产打分**
  （换的不是 alpha 是稳定性/可复现性/可审计性——直击跨日不可复现与种子噪声两个痛点），
  另立重构预注册提请拍板。
- V2 "ML 有真实排序增量"：`LGBM − max(ridge, rankens) > 3.5pp`（且 sanity 过）。
  ⇒ "模型是问题"被反驳：瓶颈不在模型家族，在数据/结构 ⇒ 重构目标 = 新数据族（换货）。
- V3 混合：一臂进容差一臂不进 ⇒ 逐臂细读，两方向都如实报告。
- Sanity：random 若 ≥ LGBM − 5pp ⇒ 评分/回测管线有 bug，全部结果作废先修管线。
- 诚实预期（写在这里，跑数后对照）：归因证据（风格 t=1.75、13 轮全否）偏向 V1；
  但 rankens 是"26 因子等权秩"，与 LightGBM 的非线性交互能力差异真实存在，V2 也有先验。

## §3 底层重构可执行方案树（判据判决后按分支激活）

**分支 V1（学习器无可测增量）→ "向简单重构"**：
- R1 以 rankens 或 ridge 替换 LightGBM 集成为生产打分：零种子噪声、全量重训当日确定性
  可复现（直击不稳定痛点 #1、#2）、模型文件 KB 级可审计。重构预注册判据 =
  双窗 Δsys_ann ∈ [−3.5pp, +∞) 且换手/回撤非劣 + 可复现性验收（同输入重跑逐位一致）。
- R2 保留 LightGBM 但"冻结为规则"：把现役集成蒸馏成显式打分表/规则卡（研究资产，不动生产）。

**分支 V2（学习器有真实增量）→ "向数据重构"（29 补处方的治本路）**：
- R3 公告语料正文级深加工（459 万条已在库，唯一在途的新 α 入口；须新预注册）。
- R4 低覆盖事件族重开（问询回复延迟等，数据受限已登记）。

**两分支共用**：
- R5 跨日不可复现根因诊断（不稳定三源唯一未解项；输入级 diff 工具化）。
- R6 结构性"换车"项（打新 L1 / 可转债 L2）属账户决策，维持用户拍板清单。

## §4 结果（2026-09-29 晚实测回填，产物 experiments/ml_attribution_20260929.json）

**对齐验证**：三臂打分表 444,312 行 / 116 月 —— 与生产 model_score **逐位同构**
（首跑曾因"打分月错误要求前瞻标签"缺首尾 2 期，已修：打分月不需要标签，只有训练月需要）。
sanity：random 臂显著低于 LGBM（-15.8/-25.9pp）⇒ 管线无 bug。

| 臂（同特征/同标签/同 walk-forward） | 全史 sys_ann | prod sys_ann | 全史 MDD |
|---|---|---|---|
| **LightGBM（生产 pin）** | **+18.77%** | **+29.13%** | −32.1% |
| ridge（λ=1.0 冻结） | +7.32% | +7.43% | −33.3% |
| rankens（无学习因子秩等权） | **−2.67%** | −2.17% | **−51.9%** |
| random（随机分地板） | +2.94% | +3.20% | −32.8% |

**判决：V2 —— ML 有真实排序增量（双窗一致，幅度远超 ±3.5pp 容差）**。

### 判读（对用户假设的直接回答）

1. **"是不是模型的问题" ⇒ 不是。模型是系统里价值密度最高的部件**：同一批因子，
   LightGBM 比线性模型多赚 +11.5pp/年、比"不用机器学习的因子秩等权"多 +21.4pp/年。
   把模型换掉/简化，同一个特征集的收益从 +18.8% 掉到 +7.3%（线性）甚至 **−2.7%（无学习）**。
2. **rankens 为负是最锋利的发现**：26 个因子不做学习直接等权排序 = 年亏 2.7%、回撤
   −52%。这些因子本体就是拥挤的反转/微盘/流动性敞口（09-27 病因诊断），**等权拿着
   是被收割的**；LightGBM 的价值在于学会了条件性组合与加权——是模型让这批"货"变得
   可交易。这与 13 轮"改用法无法再提升"合起来构成完整图景：**模型已是这套数据下的
   局部最优资产，既不欠债也无油水**。
3. ridge(+7.3%) − random(+2.9%) ≈ **4.4pp/年的线性可提取信号**；LGBM 在其上再叠
   +11.5pp 的非线性/交互增量——模型远没饱和，但增量通道在"同数据换用法"维度已被
   13 轮实验穷尽。
4. **底层重构的正确目标（用户已同意重构）**：
   - **向数据重构（治本）**：公告语料正文级深加工（459 万条已在库，唯一在途新 α 入口，
     须新预注册）——给模型喂新货，而不是换发动机。
   - **向稳定性重构（止痛）**：跨日不可复现根因诊断（不稳定三源唯一未解项）。
   - **模型本身不动**：它是被本实验证明的资产。"V1 向简单重构"分支被本实验排除
     （ridge 差 11.5pp，不进容差）。

## §5 R5 跨日不可复现 —— 根因已定位（2026-09-29 深夜诊断轮）

**不稳定三源中唯一未解项（"全量重训跨日不可复现"，09-16 起悬置）今晚机械定位**。

### 证据链（全部只读诊断，产物入 experiments/05_label/）

1. `diag_factor_row_drift_0929.py`（09-22 周备份 vs 现库）：factor 表 **20260831 月末行
   157,810 行中 118,041 行（75%）跨日值变**（p99 相对差 0.30%——真实值变化非 ulp 级）；
   **窗外月末 20260731/0630/0529 零变化**——边界精确落在日频链 KEEP_DAYS=30 覆盖窗上。
2. mom_20 差异形态：全截面比值**恒定 1.0000635~1.0000639**（1%→99% 分位几乎不变）
   = 纯 std 缩放指纹；601777.SH（千里科技）自身 rel 高达 −0.91/+2.0/−3.1（残差级剧变）、
   size ratio=0.456（换组指纹）——与"该股换了行业组"完全吻合。
3. `diag_source_row_drift_0929.py`（源表定位，含 0916 漏查的 lhb 族）：daily/adj_factor/
   daily_basic/lhb/lhb_org 8 月窗口**零修订**；stock_basic **6 行变化**（含 601777
   摩托车→汽车整车**行业重分类**、300211/300096 摘帽改名）；fina_indicator 补录 102 行
   历史财报。`diag_data_drift_0928_result.json`（09-28 备份复跑）：单日窗口 stock_basic
   又变 5 行 ⇒ **行业快照每个交易日都在被上游微调**。

### 根因链（闭合）

    上游 stock_basic 行业重分类/摘帽（每天数行, "当前快照"表, 历史被静默改写）
      → industry_map（读当前快照）逐日变化
      → 日频链 daily_engine 每天 upsert 最近 30 个交易日的 factor 行（含月末日）
      → 月末行的中性化值随"覆盖那天"的行业映射漂移（换组股残差剧变 + 全截面 z 统一缩放 ~6e-5）
      → 月度链增量从不重写旧月末 ⇒ 漂移永久化（30 天后日频链停覆盖才冻结）
      → 跨日全量重训读到的**最新月末特征不同** ⇒ LightGBM 分数不同 ⇒ 不可复现

09-16 的"双备份对比推翻数据修订假说"**只对原始行情表成立**——它没查 factor 表本身、
也没把 stock_basic 快照修订与"日频覆盖通道"连起来。本轮补上，三源之一（数据级）
正式结案：**不是玄学，是行业快照修订 × 日频覆盖通道的确定性机制**。

### 修复方向（登记，均属预注册级，未动手）

- F1（最小治本）：daily_engine **跳过月末日**（月末行只归月度链写）——改 factor 表内容
  = 特征口径变化 ⇒ 须预注册 A/B（预期影响 ≈0：只消除最新月末行的 1e-5 级噪声，
  但 8/31 行已被漂移版污染，采纳后须重算受影响月末并重训重钉）。
- F2（治本扩展）：industry_map PIT 化（已知缺陷，任务 #23 实测代价≈0 但覆盖度逐年剧变）。
- F3（零风险体检）：把"月末行稳定性指纹"做成每日监控项（漂移即告警）。
- R5 结案对重构的意义：**稳定性重构（F1）与"向数据重构"相互独立且都成立**；
  修复 F1 后，重训类实验的"当日对照臂"纪律可放宽为"同特征面板版本"纪律。
