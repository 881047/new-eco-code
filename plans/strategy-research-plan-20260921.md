## 2. 阶段划分 / 交付物 / 验收标准

### 阶段 1：周频化统一（频率改造）—— 优先级 **高**

**为什么先做**：目标定义在周频维度 ⇒ 频率是评估的前提；且频率改造会改变换手 / 期数 ⇒ 影响后续所有指标的可比性。

| 项 | 内容 |
|---|---|
| **目标** | 调仓 / 回测 / 评估 ⇒ 统一周频（锚点 = `week_end_dates`） |

**改造项**
1. **调仓**：生产 `model_score`（月频 → 周频）⇒ 标签跨度 `HORIZON=21 → 5`（与袖套同跨度）+ 禁运 3 锚点（`EMBARGO=3`）+ 训练窗（36 个月滚动）
2. **回测**：`run_backtest` 的锚点（`month_end_dates` → `week_end_dates`）
3. **评估**：指标 ⇒ 周频（周胜率 / 周超额 / 周回撤 / IC / IC_IR）

**交付物**
- 周频调仓的 `model_score` 校准记录（标签 / 训练窗 / 禁运）
- 周频回测（逐期序列）
- 周频评估指标（周胜率 / 周超额 / 周回撤 / IC / IC_IR）

**验收标准**
1. **周频回测 ⇒ 与月频对齐**：逐期序列 ⇒ 月度聚合 ⇒ 与 F53（月均 +1.34/+1.31pp、命中 65.6%/65.6%）对齐 ⇒ 差值在容差内（**不要求提升，只要求口径一致**）
2. **评估指标 ⇒ 不劣化**：与 F50（IC 0.0875 / IC_IR 0.685）对比 ⇒ IC / IC_IR **不降**
3. **成本显式化**：评估必须用**净超额（扣成本后）**（=> 周频 ⇒ 换手更高 ⇒ 成本更敏感）

## 3. 周频化注意事项（数据频率 / 交易成本 / 过拟合 / 风险控制）

### 3.1 数据频率
- **更短的持有期**：`HORIZON = 5`（周频标签 = `forward_excess`（`open(t+1+H)/open(t+1) − 1`）⇒ 减当日可交易票池等权均值 ⇒ 学的是**超额**（不是绝对收益）
- **样本量**：周频锚点 **651**（scores 存档：651 锚点）⇒ 更短的持有期 ⇒ **更多期** ⇒ **更短的持有期** ⇒ **标签噪声** ⇒ 需 HAC / DSR（多重比较）
- **财务因子**：`ann_date` 对齐（**其后第一个交易日**）；缺披露日 ⇒ 法定截止日保守估计（**宁可滞后，不可前视**）
  - 周频 ⇒ 更短持有期 ⇒ 财务滞后更明显 ⇒ 标签噪声 ⇒ 需 DSR / HAC（与 F38 一致：DSR<0.95 ⇒ 全史超额不得当显著读数）
- **口径不变**：中性化顺序（2%/98% winsorize → 行业去均值 → z-score）不变（`fe.neutralize`）⇒ 频率只改锚点，不改中性化口径。

### 3.2 交易成本
- **更高换手**：生产 0.137（F52）⇒ 周频 ⇒ 更高 ⇒ **成本（滑点 / 费率）** ⇒ **净超额（扣成本后）** ⇒ 评估：**净超额（扣成本）**（=> 周频化 ⇒ 成本更敏感 ⇒ 必须用净超额评估，不能用毛超额）
- **已否**：F37（贪婪预算：投入率 0.769→0.993，全史 +20.4pp，但 MDD −32% → −41% ⇒ 不采纳：同一根风险刻度）
- **关键**：周频 ⇒ 更高交易频率 ⇒ 成本 ⇒ 净超额 ⇒ 扣成本后评估（=> 成本敏感：滑点 / 费率 ⇒ 净超额）
- **注意**：周频化 ⇒ 换手上升 ⇒ 成本 ⇒ 净超额（=> 若净超额不达标 ⇒ 说明"周频化的成本 > 收益提升** ⇒ 应否（=> 判据：净超额 ≥ 月频基线 / 扣成本后不劣化）

### 3.3 过拟合
- **多重比较**：N = 171 已测因子（qlib158 PASS = 0）⇒ **过拟合风险 = 多重比较（N），不是样本长度**（F48 独立复核 F38 DSR ⇒ MinTRL 129 ~ 136 期；现有 491 期）
- **周频 ⇒ 期数增多**（651 锚点）⇒ 多重比较分母 N 增大 ⇒ DSR 门槛更严 ⇒ 过拟合风险更高
- **需 DSR**：周频 ⇒ 更短持有期 ⇒ 噪声 ⇒ 过拟合 ⇒ 需 **DSR**（F38 DSR < 0.95 ⇒ **全史超额不得当显著读数**）
- **超参** ⇒ F47 六格结清 ⇒ 现役局部最优 ⇒ **不重跑**（复活条件：新证据 + 重新预注册 + 两套种子同向增益）

### 3.4 风险控制
- **更频繁的调仓** ⇒ 回撤控制（MDD：生产 −36.6%（月度）⇒ 周频 ⇒ **周频回撤**）
- **已否**：vol-target（F54：动态敞口线结清 ⇒ 超额 ÷ \|MDD\| 掉（0.485 → 0.369）+ OOS 极端（+9.21/+11.40 → −5.08 / −3.54pp）⇒ 不采纳
- **关键**：周频 ⇒ 更频繁 ⇒ 风险（=> 回撤）=> 控制：**成本 / 回撤 => 风险调整（稳定性 = IC_IR / Sharpe）+ 胜率（周命中率）+ 回撤（周频 MDD）**
- **注意**：周频 => 风险控制 => 成本（=> 换手）+ 回撤（=> MDD）=> 净超额 / 回撤 => 风险调整（=> 稳定性 = IC_IR / Sharpe）+ 胜率（命中率）+ 回撤（MDD）
