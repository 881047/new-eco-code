# 周频化预注册（2026-09-21，**跑数前冻结**）

> 依据：`docs/know/05_实验台账.md` 纪律（换 pin 需预注册 + A/B + 重钉 pin；01 号）。
> 计划：`plans/strategy-research-plan-20260921.md`（阶段 1 周频化统一）。

## 一、背景

用户要求：**调仓 / 回测 / 评估频率 = 月频 → 周频统一**。

现状（实读）：
- 生产 `model_score`：`app/models/trainer.py`，标签跨度 **`HORIZON=21`**（L124，约一月，月频）；训练窗 `_train_window` = `md_all[i-36 : i-1]`（不含上月 = 月频禁运，L259-267）。
- 周频袖套：`app/weekly/scores.py`，`HORIZON=5` + `EMBARGO=3` + `TRAIN_MONTHS=36`（**已是周频**）。
⇒ 改造对象 = **生产打分（月频→周频）+ 回测评估（月频→周频）**。

## 二、A/B 两臂（**不改常量，先取证据**）

`trainer.run()` 已支持 `horizon` 参数（L348）⇒ **无需改 `HORIZON` 常量即可做 A/B**：

| 臂 | 配置 | 说明 |
|---|---|---|
| **A（对照 / 现役）** | `trainer.run(horizon=21)` | 月频，现役口径（pin 用它） |
| **B（候选 / 周频）** | `trainer.run(horizon=5)` + **禁运 3 个锚点**（与袖套 `EMBARGO=3` 对齐）| 周频候选 |

⇒ 只有 B 臂胜出，才改 `HORIZON=21 → 5` 常量并重钉 pin（**需你批准**）。

## 三、判据（**冻结，跑数后只填结果不许改**）

1. **对齐**（与月频口径可比）：B 臂回测逐期序列（周频）⇒ 月度聚合 ⇒ 与 **F53**（全史月均 **+1.34 / +1.31pp**、命中 **65.6% / 65.6%**）对齐 ⇒ **差值在容差内**（容差参考 F52 单次校准：全史 \|Δ超额\| ≤ 1pp、\|ΔMDD\| ≤ 2pp）。
2. **不劣化（信号）**：B 臂**周频 IC / IC_IR** ⇒ 与 **F50**（IC mean **0.0875** / sd **0.1278** / **IC_IR 0.685**）对比 ⇒ **不降**。
3. **净超额（扣成本）**：周频 ⇒ 换手更高 ⇒ 必须用**净超额（扣成本后）**评估 ⇒ 与 A 臂（月频）净超额对比 ⇒ **不劣化**（基线 F52：+17.78 / +17.47pp、MDD −36.6%、换手 0.137）。
4. **全量**：≥ **1407 passed**（不回归）。

**判决规则**
- B 臂满足 **①②③④** ⇒ **采纳周频** ⇒ 改 `HORIZON=21→5` + 重钉 pin（需你批准）。
- 任一不满足 ⇒ **不采纳** ⇒ 周频化**否** ⇒ 在 05 号登记证伪（**勿重跑**）。
- 若"全史更优但留出集（OOS）反向" ⇒ 按 **F55 判据否**（与 F55 同型权重线已否一致）。

## 五、目标定义（用户要求）

- **短期**：周频维度追求更高**绝对收益**。
- **最终考核**：**相对基准的周频超额收益**；同时关注 **稳定性（IC_IR / Sharpe）+ 胜率 + 最大回撤（周频 MDD）**。
- 说明：生产标签 = `forward_excess`（`open(t+1+H)/open(t+1) − 1`）减当日可交易票池等权均值 ⇒ 学的是**超额**（不是绝对收益）⇒ 与"最终考核 = 相对基准周频超额"一致。**绝对收益** ⇒ 通过"提高超额 + 基准暴露（敞口 w）"实现（F25：超额 ≈ −10.44 + 26.23×w，R²=0.955）⇒ **本预注册不改敞口**（F37 贪婪预算已否：MDD −32%→−41%）。

## 七、周频化注意事项（记录）

- **数据频率**：`HORIZON=5`；651 锚点（期数更多但持有期更短 ⇒ **标签噪声更大** ⇒ 需 HAC / DSR）；财务 `ann_date` 对齐其后第一个交易日（**宁可滞后，不可前视**）；中性化顺序（2%/98% winsorize → 行业去均值 → z-score）**不变**。
- **交易成本**：生产换手 0.137 ⇒ 周频更高 ⇒ **必须净超额（扣成本后）评估**；已否 F37。
- **过拟合**：多重比较 **N = 171**（qlib158 PASS = 0）；周频 ⇒ 期数增多 ⇒ N 增大 ⇒ DSR 更严 ⇒ 需 DSR（F38：DSR<0.95 ⇒ 全史超额不得当显著读数）。
- **风险控制**：更频繁调仓 ⇒ 周频回撤；已否 vol-target（F54）⇒ 用**成本/回撤风险调整**（稳定性 = IC_IR/Sharpe）+ 胜率 + 回撤。
