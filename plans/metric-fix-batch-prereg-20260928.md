## §一 sys_ann_return 年化频率自适应（engine.py:913）

**现状**：满仓线年化用自适应 `ppy`（:859，month=12 / week=52 / 双月=6），系统线
`sys_nav ** (12 / n_periods)` 硬编码 12 —— 非月频锚的 A/B 只要读系统线就会算错
（week 锚低估、双月锚虚高）。现役 month 锚下 ppy 恒 = 12。

**修复**：`12 / n_periods` → `ppy / n_periods`（同一作用域已有 ppy）。

**冻结判据（Δ=0）**：现役 month 锚两窗（85 期 prod / 115 期 full）重跑后
`sys_ann_return` 与现行 pin 行**逐位相等**。不等 ⇒ 修复有误，回滚。

## §二 日频 MDD 锯齿（engine.py:774 循环右端 + :798/:808）

**现状**：月内盯市循环 `range(b_idx, s_idx)`（s_idx=pos1+1）把**下一个锚点日 d1** 也
算进去：d1 在内存 `daily_rows` 出现两行——先 :798 近似行（未扣当月费用/利息），后 :808
精确行（含双边费用+利息）。`mdd_daily/sys_mdd_daily` 吃**内存序列**，而落库表
`backtest_nav_daily` 主键 (run_date,trade_date) 塌缩同键行（保留精确行）⇒ **指标与表
不可互审**；方向 = 上涨月的近似行先创虚高峰值、精确行回落 ⇒ 回撤被人为放大（36 补
估 0.1~0.7pp），"日频回撤"这一对外头条数字含此成分。

**修复**：循环右端 `s_idx` → `pos1`（锚点日只保留 :808 精确行）⇒ 内存序列日期唯一、
与落库表逐行同构。撮合/账务/其余指标零改动。

**冻结判据**：
1. 修复后重跑两窗，summary 中 **除 `mdd_daily`/`sys_mdd_daily` 外全部键逐位不变**
   （ann/bench/excess/max_drawdown/sys_max_drawdown/sharpe/vol/win_rate/换手/IC/实持/闲置…）。
   任一其他键变化 ⇒ 修复方案错误，回滚。
2. `mdd_daily`/`sys_mdd_daily` 变化方向 = 改善（绝对值变小/不变）。
3. 修复后日频内存序列与落库行数一致（抽样核对两窗）。
4. 判读通过 ⇒ **重钉 pin**：`backtest_run` 换新 tag（旧 tag 留痕保留不自清），同步
   config 口径注释 / README 关键设计 / CLAUDE.md §0 / 08 号 pin 台账。
5. 判读不通过（出现判据 1 之外的键变化或 mdd 恶化）⇒ 线结清登记，不重钉。

## §三 board_of 沪 B 股 900xxx 归类（board.py:74）

**现状**：`("4","8","9") → bse` —— "9" 同时覆盖北交所 920 新段与**沪市 B 股 900xxx**；
B 股实际限幅 ±10%、整手 100 股整数倍，被归 bse（±30%、最低 100 股后 1 股递增）后若进
候选域，封板判定线被抬高 3 倍。实测 `model_score`/`daily_score` 无 9 开头行（36 补
§36补.2）⇒ 对现役回测/选股 **Δ=0**，纯潜伏。

**修复**：bse 判定改为 `("4","8") 或 920 前缀`；900xxx 落 "other"（±10%、100 股整数倍，
与深 B 200xxx 同档）。920xxx 行为逐位不变。

**冻结判据（Δ=0）**：① 单元测试钉住 920001→bse / 900901→other（±10%）且既有
main/chinext/star/bse 判定逐位不变；② §二的重跑对照中其余键逐位不变（隐含验证候选域
无 9 开头票）。
