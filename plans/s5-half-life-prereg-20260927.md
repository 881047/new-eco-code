> 同时是创新 3 衰减分层持有的依赖读数）。动机铁证：W2 M1"配对差 t=+2.73 但 α 只在首期、
> lag≥1 转负"= 半衰期短于执行延迟的极端案例——**当时若有时效判据可在门禁层拦住，
> 不必烧 70 分钟机时 + 组合层回测**。本预注册把这条教训制度化为单因子档第 5 轴。
> 命名说明：单因子档现有 S1-S4（20260926 预注册），本轴编 S5；集成级 evaluate() 内的

## 一、判据冻结（S5，跑前冻结）

**衰减曲线（执行延迟口径）**：对月频锚点序列 t_i（`month_end_dates`，≥2019-01-01），
定义 lag L = 0..5（单位 = 月频调仓周期，即**锚点步数**，非交易日）：

  IC_L(t_i) = Spearman( factor[t_{i−L}], fwd21[t_i] )

即"信号晚 L 期执行还剩多少边缘"。fwd21 = 门禁家族 naive 标签（`gate.forward_return`，
close×adj 21 交易日，末尾 NaN）。**选 lag 变体而非 horizon 变体**（综述给的是 lag-1..k 期
IC，两参量化在平稳性下等价）：① 直接对准 M1 失效模式（执行延迟后 α 消失）；
② 全部 lag 共用同一个 fwd21 面板 ⇒ 各 lag 的可用锚点集相同，曲线逐点可比；
③ L=0 与 gate.evaluate 的 ic_full 机器完全同口径 ⇒ 可逐位交叉校验。

**半衰期（机械规则）**：HL = 最小的 L≥1 使 |IC_L| < 0.5×|IC_0|（单位：月）。
- 全曲线（L≤5）从未过线 ⇒ HL = 6（删失，记 "≥6"，**通过**）；
- |IC_0| 为 NaN 或 0 ⇒ HL = 0 ⇒ **判否**（fail-closed，同 cost_per_month 缺失判否先例）；
- DEAD 区可用锚点（该因子该锚点有 IC）< 24 个月 ⇒ S5 = None（"未测"，**不否决**，
  如实列报——同 S4 覆盖缺口惯例；≥24 但个别锚点缺 ⇒ 用可得锚点，n 如实记录）。

**阈值（冻结）**：**S5 = HL ≥ 2.0（月）** = 2× 月频调仓周期。依据：
1. 综述的 practitioner 标准流程（IC 衰减曲线 → 半衰期 ≥ 2× 调仓周期）；
2. 本仓 M1 铁证：HL<2 期的信号"存在性显著"但不可执行，S5 在门禁层直接拦住；
3. 用 |IC| 而非带号 IC：测"预测关联的存续"，与方向无关；反向显著因子（chase6/min60
   教训：正解是排除/风控）其**排除依据**同样会随延迟衰减，S5 对其一体适用——
   S5 否决的是"作为时序稳定信号（alpha 或排除依据）的资格"，不改变用法哲学。

**判定语义**：verdict_single 增加可选参数 `half_life_months=None, hl_bar=2.0`——
None（未测）不否决（向后兼容，既有调用零变化）；非 None 时 S5 参与判：
`PASS_single = S1 ∧ S2 ∧ S3 ∧ (S4 is not False) ∧ (S5 is not False)`。

## 二、口径（与 20260926 重测逐字对齐）

- 面板：池 31 = `factor` 表（`T._load_factors_wide`）；bank 过档 50 = `data/alpha_pool/*.npz`
  原值——**与重测同源，不另行中性化**。S5 是面板内自比较（自身滞后 vs 自身前瞻），
  半衰期是**比值**，对共同的单调截面变换稳健。
- 截面域：锚点 t_i 的 PIT 可交易矩阵 + 因子行（t_{i−L}）非 NaN + fwd 行（t_i）非 NaN
  三者交集 ≥200 只（`MIN_NAMES`），与 evaluate() 同；L=0 时与 evaluate 语义逐位一致。
- 判定区：**DEAD（2020-09..2023-12）**——与 S1/S2 同区（门禁家族"只看死区"哲学）；
  ACTIVE 区曲线**只记读数不判定**（参考）。
- 交叉校验（执行体内置）：8 个池过档因子的 IC_0 与 gate.evaluate 的 DEAD 区
  mean(ic_full) 逐因子比对，最大绝对差须 < 1e-9（机器同源自证）。

## 三、范围（跑前冻结）

- **31 在池因子全量**（不只过档 8 个）：池成员的 HL 分布就是 bar 的**校准读数**——
  若在产因子大面积过不了 HL≥2，说明 bar 过严，如实登记供修订（修订须新预注册）；
- **bank 单因子档过档 50 个**（`single_factor_retest_20260926.json` 的 `pass_list`）：
  S5 只对 S1-S4 过档者有判决后果；合计 **81 个面板**。

## 五、限制

1. naive 21 日标签（门禁家族既有口径，与生产标签差异已在册）；
2. lag 以锚点步数计（月频周期），未对停牌/数据缺口的锚点内插——缺了就缺了，n 如实记；
3. bank npz 面板的覆盖域/日期轴以各自 npz 为准（与重测批② ρ 现算同口径）；
4. 半衰期只刻画**线性秩关联**的存续，非线性头部结构（head vs IC 反号）不在 S5 视野内
   ——那是 S1/S3 与组合层档的职责；
5. 曲线只到 L=5：HL>6 月一律删失为"≥6"，不再细分（对判据无影响，对创新 3 分层够用）。
