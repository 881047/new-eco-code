## 2. 各实验预注册（判据冻结）

### Phase A — F76 标签并发诊断（P0-1 唯一性权重的前置测量）

- **动机**：27 号 §五"本项目没有显式处理重叠权重"。但月频锚点 = 月末交易日、
  HORIZON=21，锚点间距 ≈20~23 交易日 ⇒ 预期并发 ≈1。先量，再决定烧不烧机时。
- **口径**：生产 trainer 锚点序列（`md_all`，月末日）× HORIZON=21；逐交易日统计被
  多少个在窗标签覆盖 ⇒ 平均并发 c̄（全史 + 分年度）；同口径复算周频
  （`app/weekly/scores` 周锚点 × HORIZON=5）。
- **决策规则（跑前冻结）**：c̄ ≤ **1.05** ⇒ P0-1 以诊断**结清**（无实质重叠，唯一性权重
  无素材，不改 trainer；27 号 §五 更正为"已量，并发≈1"）；c̄ > 1.05 ⇒ 进 A/B：
  trainer 加 `sample_weight_mode` 实验参数（默认 None 生产逐位不变），双种子 +
  组合层两轴 + 噪声门（Δ>10%×基线 且 t>1.6）。
- **产物**：`experiments/05_label/F76_label_concurrency.py` + `_result.json`；不改任何生产文件。

### Phase B — F56b purged-CSCV 敏感性（P0-2 收尾）

### Phase C — round-6 供给侧合并剔除器（P1）

- **信号（PIT 已物化、量纲已修）**：`kg_insider_sell_60d`（60 日高管减持事件数）、
  `kg_unlock_90d_ratio`（未来 90 日解禁股数/流通股本，×1e4 修正后）。
- **合并规则（冻结）**：z_sell、z_unlock 为当日截面 z-score；supply_z = 0.5·z_sell +
  0.5·z_unlock（双有值），单有值者用单值，双缺失 = 不剔除。θ 网格 {1.0, 1.5, 2.0, 2.5}。

  是否重钉 = 用户拍板（不在本轮范围）。
