# 预注册：E2E-DL 轮——端到端组合层训练（第 13 轮"改模型"）

- 冻结时间：2026-09-29（跑数之前）。用户指令"DL 路线继续"。
- 定位：**不是复活 seq_die**（PatchTST 预测模型范式，已退役），而是检索（2026-09-29，
  plans/model-layer-survey-20260929.md）确认的 DL 第一优先方向：**端到端组合层训练**
  （可微组合目标直接进损失，绕开 IC 代理）。外部证据：Zhang-Cucuringu-Zohren（arXiv
  2111.09170）E2E-LSTM Sharpe 2.60 vs 预测-再优化 0.86（美股日频）；Fernandes-Desell
  2026 开源。病理警示：arXiv:2605.01176 decision-induced ranking = prediction
  inflation + 换手放大 ⇒ **换手是本判决的第二判据**。

## 与 12 轮失败的本质区别（预注册前提）

前 12 轮全部在"预测-再优化"范式内（改目标函数/加权/标签/窗口，损失仍是预测损失）。
本轮范式变更：**损失 = 组合层目标本身**。发现②（IC 与 top-6 收益反相关，5 次复现）
在该范式下不再是"优化方向的脱节"，而是被绕开——这正是检索把它列为 DL 重启第一
优先的依据。历史失败形态不构成本轮先验否决，但**预期管理照旧**：效应量不明，
A 股月频 top6 长多无外部实证，大概率 INDETERMINATE/REJECT。

## 设计（跑前冻结）

### 口粮与协议（与生产逐字同构）
- 特征 = 现役 26 因子（factor 表，生产中性化口径），月末截面；
  训练窗 = `trainer._train_window` 同款（36 个月滚动、holdout_recent=6）；
  可交易域 = `PITEngine.tradable_mask`（训练域 = 选股域）；
  评分 = 逐月末截面 → 隔离表 `model_score_e2e_ts1_a/_b` → 组合层回测
  （`run_backtest(score_table=)`，85 期窗 20190731..20260831）。
- **架构（极小参数量，对冲 tabular 数据量约束）**：MLP 26→64→32→1（≈3.3k 参数，
  GELU，无 dropout/无 batchnorm——样本 14.4 万/窗对 3.3k 参数充足）。
  理由：Transformer/深网在 12 轮里死于数据量；3.3k 参数的 MLP 与 LightGBM 50 轮
  ×31 叶同级复杂度，"模型容量"不再是有差异的变量。

### 损失（唯一变量）
- 主候选 **top-softmax 交叉熵（ListNet）**：p*(i) = softmax(y_i/τ_i)（真实 21 日收益
  的软 top 分布），p(i) = softmax(score_i/τ_i)，loss = −Σ p*·log p（截面内）。
  **τ_i = std(y_当期截面)**（逐期自适应温度）——跑前量纲审计修正：21 日收益截面
  std ≈ 0.06-0.1，固定 τ=1 下 softmax 近似均匀、损失退化为"预测均匀分布"（y/1 的
  softmax 几乎无锐度）；τ 取当期标签 std 使 p* 获得适度头部集中度。τ_i 用训练窗内
  当期标签统计，无前视。敏感性 0.5×/2.0×std 只报告不判。机理：直接优化"概率质量
  放在真实头部"，与 top6 决策对齐；可微 top-k 构件族的标准实现。
- 对照臂 = 生产 LightGBM（现役 pin 构型，不重训）。
- 训练细节：AdamW lr=1e-3，早停 = holdout 6 个月的同款损失（每 epoch 评估，
  patience 10），上限 100 epoch；np.random.RandomState(seed) 全链路种子化（种子纪律）。
- **双种子集**：A = [42, 7, 123, 2024]，B = [7, 13, 99, 2024]——每个种子集训练
  4 个 MLP 取**分数秩平均**（与生产 ens 同构）。

### 判据（跑前冻结，与 B1 同款）
- 有效性门：现役 pin 读数由生产表回测复核（5e-4）。
- 组合层档 P1：双种子集 Δsys_ann ≥ +2.0pp 且同向（门=组合层档 v1，F76b 噪声刻度）；
  P2 回撤劣化 <2pp；**P3 换手 ≤ +5pp（E2E 病理警示的针对性判据）**。
- 0<Δ<2pp 同向 = INDETERMINATE（效应小于判定力）；异向/负 = REJECT 线结清。
- 研究层读数（IC/DEAD head/top6）**只作参照**——范式变更下 IC 不再是判决量
  （CIKM 2025 外部证据：损失改进不改 IC）。
- **实现引擎变更（跑前修正，2026-09-29）**：torch CPU 轮子安装被 Windows Smart App
  Control 拦截（WinError 4551，torch_python.dll；与 09-14 pyarrow arrow.dll 同族事件，
  CodeIntegrity 系统策略，非本仓可解）⇒ **改 numpy 手写两层 MLP + 解析梯度反向传播**
  （架构/损失/协议不变；gelu-tanh 近似及其导数、AdamW 解耦更新均手写），
  梯度正确性以数值梯度对照单测钉死。SAC 拦截本身登记 09 号（torch 在本机
  Python 3.13 venv 不可装 = "DL 不再投入"判决的环境侧成因之一）。

① 端到端组合层训练的外部证据（美股日频多空）不迁移到 A 股月频 top6 长多 +

   ——组合层目标本身的优化没有带来超越 GBDT 的排序能力；
③ SPO 病理兑现（换手 +6.2pp 超门槛，arXiv:2605.01176 文献警示成真）。
