# K 线择机入场探针预注册（2026-10-01，跑数前冻结）

> 来源：用户指令（2026-09-30）sequenced 路径第二项——"K 线择机入场"（与低谷加仓线
> **完全独立**：那条线改选股不改执行，本线改执行不改选股；两者叠加属两个 PASS 之后
> 的第三个预注册）。问题：生产入场 = 月锚点次日开盘（FILL_AT_OPEN）；对**同一选股流**，
> K 线条件化入场（等回调/等弱势再买）能否优于 t+1 开盘买入。
> 先验（诚实声明）：负——"月频 α 集中在最新信号"（平滑/持有期双 REJECT）+ 现金拖累
> （36补.3：2 万账户现金闲置 31% 已是超额上不去的三大物理约束之一）。本探针的设计
> 目标是**用最小成本把这条窄缝机械了结**：先量 oracle 包络（整个规则族的理论上界），
> 上界不够 bar 就一行条件臂都不用跑。

## 一、机制（冻结）

- **选股流（重建，两档）**：生产 `model_score` 月锚点打分 → PIT 可交易域
  （`PITEngine.tradable_mask`）→ chase 剔除（`ChaseGate.exclusions`，θ=生产值）→
  **主流 = top-6**（含行业帽 ≤2 只/行业，greedy 按 score；行业取 stock_basic 现值，
  非 PIT 近似，注记）；**稳健档 = top-20**（无行业帽）。两档同规则同判据，
  结论以主流为准、稳健档作稳健性参照。
- **入场日族（冻结）**：k=0 = t+1 开盘（= 生产基线）；k=1..10 = 锚点后第 k 交易日
  收盘。D=10 冻结（半个 21 日持有窗——延迟过半开始吃"最新信号"前置期；不加网格
  防参数搜索）。
- **条件化规则（冻结，机制驱动方向，无参数）**：锚点日收跌（adj_close[t] <
  adj_close[t−1]）⇒ t+1 开盘买入（条件在建仓前已知）；否则等窗口内**第一个收跌日**
  （adj_close[d] < adj_close[d−1]，d=1..10）以该日**收盘**买入；到 D 仍无 ⇒ 第 D 日
  收盘买入。方向依据 = 反转池 + chase6 证据（K 线刚跑起来的票是更差买入 ⇒ 等弱势
  而非追确认）。
- **不可买日规则（两臂同规则）**：(high==low)∧(pct_chg>5) 视为一字板不可买；
  固定 k 臂该日不可买则回退最近可买日收盘；条件臂死线同理回退。卖出 = 下一锚点
  t+1 开盘（复权价；停牌顺延 ≤5 个交易日，仍无则最后可得收盘——冻结近似）。
  整月无可用入场或卖出的股票-月从**两臂同时**剔除。
- **收益口径**：全复权价（raw × adj_factor）；月收益 = (S/E)×(1−0.003)² − 1
  （single_side_cost 两臂同率）；组合月收益 = 等权均值；Δ = 臂 − 基线（同基准
  同卖点，费用中性）。

## 二、判据（冻结）

- **包络引理（oracle 版）**：条件化规则对每只股票-月的入场价必然落在
  {t+1 开盘} ∪ {第 1..10 日收盘} 之内，故其逐股票-月收益差 ∈ 固定延迟族的逐股票
  包络 [min_k Δ_k, max_k Δ_k]；**组合级严格上界 = oracle 包络**（逐股票-月取
  max_k 后组合平均——固定 k 的组合级包络不是上界：逐股混选可超过任何单一 k）。
- **bar = +0.50pp/年**（部署地板，与低谷预注册同一常数同一理由：入场时点层的
  采纳必然动撮合域 = 引擎级接线，低于地板不值得开禁区）。
- **E 门（oracle 包络判死）**：oracle 包络（prod 窗年化）< bar ⇒ **DEAD（包络判死，
  线结清）**——10 日窗口内不存在能过部署地板的入场日，任何 K 线规则都一样，
  条件臂不跑。
- **条件臂判据（仅当 E 门过）**：
  - P1 = Δann(prod) ≥ +0.50pp/年 且 Δann(full) > 0（双窗同向）；
  - P2 = 模拟 NAV MDD 非劣（Δ ≥ −1pp，双窗）。
  - 判决（机械）：P1∧P2 ⇒ **PASS（进生产接线预注册）**；Δann(prod) ≤ 0 或 P2
    失败 ⇒ **REJECT（线结清）**；其余（E 门过但冻结规则未过 bar / 双窗异号）⇒
    **INDETERMINATE（线保留注记：包络有肉但冻结规则抓不到）**。拍板由人。
- 判据轴 = 双窗（无重训）；E 门在 prod 窗判。

## 四、限制

1. 选股流重建是生产管线的近似（行业映射非 PIT；无 hysteresis——config
   `hysteresis_buffer: 0` 无影响；涨停语义为启发式）。两臂同流同规则，Δ 口径干净；
   包络结论对选股流扰动稳健（top-6/top-20 双档互证）。
2. NAV 级等权模拟 vs 生产整手分配/超资防御——两臂同担，Δ 干净；采纳后须引擎级
   接线预注册 + 回放复核。
3. oracle 包络用逐股票-月事后最优 k，是**上限不是可达值**——E 门过 ≠ 条件臂会过。
4. D=10 与条件规则均为单点冻结，不做网格搜索；重开须新预注册。
5. 与低谷线独立：T1（若未来接线）改的是**买什么**，本线改的是**何时买**；
   叠加效应属第三个实验。
