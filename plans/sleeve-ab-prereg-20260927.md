# 周频袖套 A/B（31 vs 31+15）预注册（2026-09-27，跑数前冻结）

> 问题（用户指令"继续直至完成"）：二十三补筛出的 15 个 qlib158 候选因子加入袖套，
> 组合层是否有增量。判据 = 机械判决；生产采纳（袖套因子集变更 + replay 验证）另走流程。

## 一、两臂（冻结）

- **Arm A（控制）**：袖套现构型 31 因子——`weekly/scores.build_panel` 原样。
- **Arm B（候选）**：31 + **15 个筛选过门候选**（二十三补名单：KLEN/KLOW/KUP/CNTP5/
  CORD5/10/20/30/60/IMAX20/60/IMXD20/30/VSUMP60/VSUMD60）——同一 `build_panel` 的
  F/names 追加候选列；候选经引擎逐字求值 + 与 V0 同款 neutralize（实现已过 V0 ≥0.99 门）。
- **训练**：`weekly/scores.train(panel, cfg, seeds=[42,7])`——两臂**同种子同锚点**同进程
  （月度重训、36 月窗、禁运 3 锚点、horizon=5、50 轮；种子数 4→2 为算力减半，
  配对比较在同种子内成立，如实声明）。
- **锚点**：2018-01-01..2026-08-31 周锚点（~455 个）；评估读数窗 = 2021-01-01 起
  （重训热身后，~5.6 年，含 DEAD+ACTIVE 两体制）。

## 二、组合层简化模拟器（两臂逐规则相同，配对 Δ 有效）

每锚点 t（周五）：按分数 top-100 → band=2（排名跌出 102 才卖）→ **t+1 开盘调仓**，
双边成本 30bp × 换手，等权目标，现金不计息，无 lot 约束（简化声明：lot/停牌/一字板
细节两臂同缺 ⇒ 配对差有效；**生产采纳前须 replay_weekly 全保真验证**——F52 亦为研究
侧模拟器，先例同）。收益口径 = `forward_excess` 同源（相对 PIT 池等权的超额），
即组合收益序列**本身就是超额序列**。

## 三、判据（冻结）

- **P1 改善**：配对 Δ超额（每锚点 B−A，评估窗内）均值 > 0 且 t ≥ 2；
- **P2 回撤**：B 的组合超额序列 MDD 劣化 ≤ 2pp；
- **P3 换手**：|换手_B − 换手_A| ≤ 10pp/期；
- **判决词（机械）**：P1∧P2∧P3 ⇒ "PASS（进拍板）"；Δ均值 ≤ 0 ⇒ "REJECT（线结清）"；
  Δ均值 > 0 但 t < 2 ⇒ "INDETERMINATE（不可辨，延长窗口再测）"。

## 四、产出与语义

- runner：`scripts/oneoff/sleeve_ab_20260927.py`（训练 ~2×10-20 分钟，后台）；产物
  `experiments/sleeve_ab_20260927.json`；登记 05 号台账 二十四补。
- PASS 仍不直接改袖套——生产采纳 = replay 全保真验证 + 用户拍板（chase6 惯例）。

## 五、限制

1. 简化模拟器无 lot/停牌细节（两臂同缺，配对差有效；绝对水平有偏）；
2. 种子 2 个（同种子内配对；跨种子稳健性未覆盖——PASS 后的 replay 验证用生产 4 种子）；
3. 评估窗含 DEAD+ACTIVE，未分体制报告（可在产物中分窗复核）；
4. 15 候选全为价格形态族——与袖套 31 的族增量以 G3≤0.7 为界，真增量待组合层裁决。
