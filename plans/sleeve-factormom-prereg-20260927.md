# 周频袖套 · 因子动量/分块倾斜 A/B 预注册（2026-09-27，跑数前冻结）

> 来源：两频瓶颈综述创新 3（Gupta-Kelly 2019 / Cakici 2025 JBF 51 国 / 中国 JEF 2024
> "因子动量吸收股票动量"）+ 本仓 block_ic 实时原料（09-01 B1/B2 P0 = 因子动量为负的
> 实时读数，而袖套只能月末重训响应）。机制 = **每个重训点动态剔除"冷"分块**——
> 周频试点"block 告警→降权"。`app/weekly/blocks.py` docstring 明说分组接交易决策
> 须另立预注册——本文件就是那个预注册。

## 一、两臂（冻结）

- **Arm A（控制）**：袖套 31 因子静态（现构型语义）。
- **Arm B（候选）**：同面板，但**每个月度重训点**动态剔除"冷"分块：
  - **orientation（方向）**= sign(块内因子等权 IC 均值 over 训练窗全段)——训练窗
    = 与 train() 同款的 36 个月周锚点（real-time，只含 tr 内锚点）；
  - **trailing（近期）**= 块内因子等权 IC 均值 over tr 的**最后 12 个锚点**；
  - **冷** = oriented trailing IC < 0（近期符号与自身长期方向相反 = 分块动量为负）；
  - **剔除上限**：每重训点最多剔 **2 个块**（取 oriented trailing IC 最负的翻块），
    保持 ≥ 15 因子；剔除只影响该重训周期，下个重训点重新评估（无永久拉黑）。
- 两臂同种子 [42,7] 同锚点同进程；训练语义逐字复刻 `scores.train`（月度重训、36 月窗、
  禁运 3 锚点、horizon=5、50 轮），唯一差异 = Arm B 的逐点因子子集。
- 分块定义 = `app/weekly/blocks.py` 的 canonical BLOCKS（B1 流动性/规模、B2 波动、
  B3 动量、B4 短反转、B5 估值质量、B6 龙虎榜）。

## 二、组合层与判据（冻结）

- 组合层 = 24 补同款**配对简化模拟器**（top-100/band=2/t+1 开盘/双边 30bp，两臂同规则）；
  收益 = `forward_excess` 同源（相对 PIT 池等权）。
- 评估窗 = 2021-01-01 起（重训热身后）；锚点 2018-01-01..2026-08-31。
- **P1 改善**：配对 Δ超额（B−A）均值 > 0 且 t ≥ 2；**P2 回撤**：B MDD 劣化 ≤ 2pp；
  **P3 换手**：|Δ| ≤ 10pp。
- **判决词（机械）**：P1∧P2∧P3 ⇒ "PASS（进拍板）"；Δ均值 ≤ 0 ⇒ "REJECT（线结清）"；
  0 < 均值、t < 2 ⇒ "INDETERMINATE（延长观察）"。
- 机制活动度（触发次数/剔除的块/触发时段）作为**独立读数**如实列报——告警从未触发
  的窗口里两臂应逐位一致（自证）。

## 三、产出与语义

- runner：`scripts/oneoff/sleeve_factormom_ab_20260927.py`（只读零写库）；产物
  `experiments/sleeve_factormom_ab_20260927.json`；台账 二十八补。
- PASS ⇒ 生产接线（block 告警→降权接入月度重训）须 replay 全保真验证 + 拍板；
  REJECT ⇒ 线结清；INDETERMINATE ⇒ 季度复跑延长观察（同 24 补惯例）。

## 四、限制

1. trailing 12 锚点 / 剔除上限 2 块为冻结 v1 参数（修订须新预注册）；
2. 逐锚点 IC 用秩相关（与 block_ic 同口径），块内等权（不按模型重要性加权）；
3. 简化模拟器限制沿 24 补（lot/停牌两臂同缺）；
4. 冷判定在体制鞭打期会频繁翻转——上限 2 块是防whipsaw的护栏，如实读数。
