## 0. 深度思考：利用设计空间（为什么这样实践）

| 利用方式 | 判读 |
|---|---|
| A. 塞进月频模型链（倾斜/过滤/因子化） | **否**。触碰生产选股域 ⇒ 全套 A/B+重钉；且"干预层五连败"教训全在这一侧；事件窗（2-3 周）与月链节奏错配 |
| B. 剔除器（调出股负漂移） | **否**。v1 调出臂 t=−0.98 不显著，原料不够 |
| C. **独立卫星层（闲置现金座位）** | **是**。31% 整手闲置现金的天然座位；与模型链零耦合；机制=被动资金流（与全部已证伪信息族正交）；2 万零冲击 |
| D. 做空调出股 / 股指对冲 | **不可得**。融券接近停摆、股指期货/期权门槛 50 万 ⇒ 卫星层带 2-3 周市场 β（超额已对指数中性，绝对收益含 β） |

**"更优利用"四根杠杆**（v2 全部冻结为判据）：
1. **扩指数池**：000300/000905（半年）+ 000016 上证50（半年）+ 000688 科创50 / 000510 中证A500
   （季度）⇒ 事件批/年 4 → ~14（数据已验证可得）；
2. **退出时点**：v1 窗口止于生效日前一日，**漏掉生效日收盘的被动资金成交标记**（尾盘竞价
   mark-up）⇒ 测 W_B（持有至生效日收盘）vs W_A（v1）vs W_C（生效后 5 日，查反转）；
3. **公告日敏感性带**：ann ∈ {生效−18, −14, −10} ⇒ 若 CAR 稳定，−14d 近似不承重
   （真公告日校验仍是卫星实盘前置义务）；
4. **选股集中**：每批 1-2 个名额 ⇒ 用机制先验的流量压力代理 = 指数目标权重 / 流通市值
   （被动须买的金额占流通盘比例），取 top-2。

## 2. 判据（跑数前冻结）

### 2.1 探针 v2 读数（全部机械报告）

- **R1 主复现**：扩池后全指数纳入臂批级 t（30+ 批）≥ 2 且均值 ≥ +0.8%——不达 ⇒ 卫星层降级
  回"仅 300/905"或终止；
- **R2 窗口**：W_A / W_B / W_C 的批级均值与 t；**退出规则 = W_A 与 W_B 中批级均值大者**，
  若 W_B ≥ W_A − 0.2pp 则优先 W_B（尾盘竞价退出生靠可执行性）；
- **R3 敏感性带**：−18/−14/−10 三档纳入臂均值，最大最小差 ≤ 0.8pp ⇒ 近似不承重；
- **R4 子组（探索性，不用于选择）**：分指数、分前 20 日动量三档、分流通市值三档的均值——
  只报告，不作挑选依据（多重比较纪律）；
- **R5 账户级**：固定预算 5,000 元/批 × 每批 top-2（流量压力代理）× R2 退出规则，
  2019-2026 逐批模拟 ⇒ 年均元收益与对 2 万本金的 pp 贡献。

### 2.2 卫星层 GO / NO-GO（全部满足才建纸面轨）

- **G1**：R1 批级 t ≥ 2（可交易宇宙：300/905/016/510；688 仅旁注）；
- **G2**：R3 敏感性带 ≤ 0.8pp；
- **G3**：R5 成本后年均 ≥ +150 元（≈ 对 2 万 +0.75pp/年）——低于此不值得轨道维护；
- **G4**：W_A/W_B 两窗口结论同号（防窗口挑选）。

### 2.3 可交易性过滤（跑数前补充冻结）

- **科创板个股（688/689 前缀）= 50 万资产门槛 ⇒ 2 万账户不可实盘**。处理：
  - 000688 科创50 指数事件只进**研究读数**（R1 旁注，不进 GO 判据池）；
  - R5 账户级模拟与纸面轨：宇宙 = 300/905/016/510，且逐股剔除 688/689 前缀
    （A500 成分含 ~10% STAR）；
  - 创业板（300/301）保留（月频主盘本就持有深市创业板票）并在产物中标记占比；
- 卫星层判据（G1/G3/G4）一律在**可交易宇宙**上计算。

### 2.4 纸面轨规则（GO 后冻结；选股代理按 §2.5 修正）

- 预算：5,000 元/批（低于平均闲置 6,260 元；实盘前校验真实闲置现金）；
- 选股：每批 top-2 **流通市值最小**（见 §2.5 修正），等权分配；
- 入场 = 公告日后首个交易日收盘价 ×（1+滑点 0.1%）+ 买入费（`fees.trade_cost`）；
- 退出 = R2 选定窗口的期末收盘价 ×（1−滑点 0.1%）− 卖出费；
- 台账 `data/satellite_rebal/ledger.json`（独立于 paper_* 与 weekly 账本，互不污染）；
- 实现 `scripts/satellite_rebal_paper.py`（--scan/--run/--mark/--backtest 幂等模式）；
- 调度：Windows 计划任务每日 20:40 `--mark`（W2 同款 schtasks 模式，ASCII bat）；
- **首期纸面事件 = 2026-12 批**（公告约 2026-11 底；中证官网真公告日监控为实盘前置义务）。

### 2.5 选股代理修正（纸面轨开工前发现，冻结于跑 R5 定稿前）

原代理 weight/circ_mv 存在**定义性缺陷**：新纳入股在公告时点没有指数权重（权重来自
月末快照，晚于入场日）⇒ 代理在可用数据上退化为常数，不可实施。修正为
**"流通市值最小 top-2"**：同一需求/供给机制的需求端（weight×AUM）公告时不可得，
改用供给端（流通市值小 = 同等被动需求的价格冲击更大）；R4 的市值单调性（small
+2.84% / big −1.05%）与该机制**一致但已被看到** ⇒ 标记为部分数据污染风险，
R5 同时报告两规则（weight_proxy / mcap_asc）读数作对照，纸面轨采用 mcap_asc。

## 3. 诚实边界（跑数前写下）

1. 公告日仍是近似（−14d 带）⇒ 窗口头部含少量不可实现成分；真公告日逐批校验是实盘前置义务；
2. 季度指数的"定期调整"按月差分识别，若某 {3,9} 月差分实为临时调整 ⇒ 污染入批
   （批数报告可检）；A500 自 2024-09 发布，历史短（~7 批）；
3. W_B 的生效日收盘成交在实盘=参与尾盘竞价（被动资金主成交时点），纸面以收盘价近似 ⇒
   实盘滑点可能高于模型 0.1%（在 G3 门槛中留有余量）；
4. 选股代理（权重/流通市值）是机制先验不是数据挖掘产物，但若 R4 显示其反号，
   纸面轨照旧执行（判据纪律高于事后聪明），仅登记观察；
5. 卫星层带市场 β：2-3 周窗口内指数波动 ±5% 量级 vs 事件超额 ~1.5% ⇒ 单批绝对收益
   方差远大于均值；纸面轨必须按年滚动评估，禁止按单批判优劣；
6. 多重比较：R4 子组为探索性读数，不进任何判据；窗口/公告日选择按 2.1/2.3 冻结顺序。
