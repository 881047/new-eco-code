# 执行时点前移（t0 尾盘成交）—— 上界探针预注册（2026-10-02，跑判决前冻结）

> 触发：用户指令"探索炒股出路提升收益"。地图盘点：模型层 13 轮/干预层五连败/要约/转债/
> 打新均已有机械归宿；瀑布分解剩余可挽大块 = **建仓时点漂移 ~7pp/年**（信号日 t0 收盘出分、
> t0+1 开盘买入；K 线探针固定延迟族实测每晚一天买贵 0.62pp/股票-月且单调恶化 ⇒ 方向
> 指向"早买"）。**"提前执行"从未被测量**（K 线探针只测了延后 k≥1；51 补 oracle 方法论复用）。

## 一、假设与结构（冻结）

- **现行**：月末日 t0 收盘后出分（18:33 月链）→ t0+1 开盘买入。
- **候选（真实可行形态）**：t0-1 收盘数据打分 → **t0 尾盘集合竞价买入/卖出**（14:57-15:00）。
  打分数据全部为 t0-1 已结算日线 ⇒ 无盘中快照依赖，确定性可回测。
- **Phase 0（本预注册）= oracle 上界探针**：假设打分在 t0 收盘即时可得（实际不可行），
  量"把整个组合的敞口从 t0+1 开盘前移到 t0 收盘"能多吃多少隔夜漂移。**oracle 只证上界
  存在**（51 补方法论）；上界够大才立项 Phase 1 真实臂（t0-1 打分表重打 + 引擎缝
  anchor 平移，独立预注册）。

## 二、读数口径（冻结）

- 组合 = 每月月末 t0 的 model_score **top6 等权**（pin 实际持仓的近似：不含 PIT 域/chase
  剔除/整手约束，偏差方向登记不修正——上界探针要求简单透明）。
- 个股隔夜漂移 g_i = open_adj(t0+1)/close_adj(t0) − 1（复权口径，分红含入）。
- **组合隔夜超额** = mean_i(g_i, top6) − mean_i(g_i, 全市场 EW)（市场隔夜基准用全截面
  等权均值——bench 只有收盘序列，无开盘，注记）；窗口 = prod（2019-07 起 85 期）与
  full（115 期）双窗。
- **换手净效应（分离报告）**：进入名（新进 top6）隔夜漂移均值 − 退出名（掉出 top6）
  隔夜漂移均值——提前成交对换手部分是"卖早了也买早了"，净额不定号。
- 年度化 = 月均 × 12；t = mean/std·√n。

## 三、判据（冻结）

- **上界 ≥ +0.10%/月（≈ +1.2pp/年）**（组合隔夜超额，prod 窗主判）⇒ **GO**：Phase 1
  立项（真实臂：t0-1 打分 + anchor 平移缝 + exec_window="close"，独立预注册 + 重钉须拍板）。
- **< +0.05%/月** ⇒ **NO-GO 线结清**（提前执行无肉，登记）。
- 两者之间 ⇒ INDETERMINATE（需真实臂定夺，Phase 1 是否立项交拍板）。
- 换手净效应为负且幅度 ≥ 组合隔夜超额的 50% ⇒ 注记"真实臂收益将被换手净效应侵蚀"，
  GO 判决降级为 INDETERMINATE（诚实条款）。

## 四、去糟

- 不做条件择时（等回调/等冲高 K 线族已判死）；本假设是**无条件提前执行同一信号**，
  与 chase/择时族机制不同。
- 不改引擎、不写生产表、不建 pin——Phase 0 纯只读；Phase 1 才触碰禁区（A/B+重钉流程）。
