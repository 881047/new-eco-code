# 月度方案执行归因预注册（2026-09-23）：理论组合（锚点价）vs 实际组合（成交价）

> 只读。不改 `app/**`、不改成交口径、不换 pin、不动 pin 相关判据。
> 本文件只冻结**口径、公式与限制**；任何"要不要改执行时点"都是另一轮的事。

## 一、为什么要做

20260831 月度方案的股票部分**只有 5 只**（`plan` 表 `plan_type='stock'`，就是全部，不是抽样），
20260915 才成交。用户要的是把「按策略锚点价建仓的理论组合」与「按实际成交价建仓的实际组合」
之间的差别**拆干净**：损耗各来多少、由哪些票、哪类因素造成。

⚠️ **事前更正一个前提**（跑数前写死）：盘面看**亏的是理论组合**（决策价持有到现在 ≈ −1.8%），
**实际组合是正的**（≈ +3.7%）。所以本轮要量化的是"**理论为什么亏、实际为什么反倒赚**"，
而不是反过来给实际组合找亏损来源 —— 不许把结论包装成"实际亏损归因"。

## 三、口径与公式（跑数前冻结）

**共同分母**：理论建仓成本 `B = Σ q_i P^a_i`；实际动用本金 `F = Σ q_i P^f_i`。
两种组合都用 **B** 作分母 ⇒ 收益可比（未动用现金收益按 0 计，如实标注）。

- 理论（共同基准）：`R^th = Σ q_i(P^t_i − P^a_i) / B = Σ w^a_i · r^{a→t}_i`，`w^a_i = q_iP^a_i/B`
- 实际（共同基准）：`R^ac = Σ q_i(P^t_i − P^f_i) / B`
- 实际（按已投本金，界面常见口径）：`R^ac,inv = Σ q_i(P^t_i − P^f_i) / F`

**恒等式 1（零残差，逐股可加）**：

```
Δ = R^ac − R^th = Σ_i q_i(P^a_i − P^f_i)/B = Σ_i w^a_i · s_i,   s_i = (P^a_i − P^f_i)/P^a_i
```

⇒ 实际与理论的全部差异 **就是加权入场价差**（Perold 口径下 = 延迟收益 + 成交滑点），**没有别的项**。

**恒等式 2（Perold 三层，乘法精确）**：`(1+r^{a→t}_i) = (1+r^delay_i)(1+c^slip_i)(1+r^post_i)`
- `r^delay_i = P^o_i/P^a_i − 1`（决策 → 委托到达；理论持有而实际**没有**持有 ⇒ 实际"躲过/错过"的那段）
- `c^slip_i  = P^f_i/P^o_i − 1`（成交价相对开盘 arrival 的滑点，>0 = 成本）
- `r^post_i  = P^t_i/P^f_i − 1`（持有期收益）
- 加性近似 `r^{a→t}_i ≈ r^delay_i + c^slip_i + r^post_i + ε_i`；**交互项 ε 必须在表里列出，不许静默吞掉**。

**权重偏离（用户维度 2，Brinson–Fachler 算术分解，单层）**，基准 BM = 中证500 同期（成交→现在）：
- `Allocation_i = (w^f_i − w^T_i) · r^{BM}` ；`w^f_i = q_iP^f_i/F`
- `Selection_i  = w^T_i · (r^{f→t}_i − r^{BM})`
- `Interaction_i= (w^f_i − w^T_i)·(r^{f→t}_i − r^{BM})`
- 三者之和 = `R^ac,inv − r^{BM}`（精确，逐股可加）。沪深300 版本只作**稳健性对照，不参与判决**。

**市场/行业/风格（用户维度 4，三层加性，逐股）**：
`r_i = r_M + (r_IND,i − r_M) + (r_i − r_IND,i)` ⇒ 依次 = 市场项 / 行业项 / 个股特异项。
- `r_M` = 中证500 同期收益（窗口与所在组合口径一致）
- `r_IND,i` = 该股所属**申万 L2 行业等权篮子**同期收益（**剔除自身**）；成员 <3 只 ⇒ 标"行业样本不足"，
  **不许**编造或用别的口径顶替。
- 风格：按窗口起点 `circ_mv` 全市场分位打标签（小/中/大），并报告**小盘组合 vs 大盘组合**（各按流通市值
  分位分组等权）同期收益差，用于说明这个组合天然带的规模敞口值多少。

## 四、限制（先写死，不许事后放宽）

1. **样本 = 1 个方案、5 只票、1 次成交** ⇒ 任何"系统性"二字都不许用（若日后要做，需多期回算另立一轮）。
2. **未实现浮盈**，未扣卖出费用（佣金+印花税+滑点，粗估 0.2~0.3% 量级，只提示不入账）。
3. **不估 beta**：用篮子收益而非回归（自由度不够），因此"暴露"是会计式分解，不是风险模型。
4. 期间 `adj_factor` 五只**均无变化** ⇒ 无除权除息，未复权价比较与复权口径同解（脚本自检并写进产物）。
5. 要不要把执行时点从 09:31 改掉 ⇒ **改成交口径 = 换 pin 级**，本轮**不做**、也不据此建议，只在最后给出"若要验证需要几期样本"的量级判断。
