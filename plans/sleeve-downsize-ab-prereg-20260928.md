## 问题

生产袖套构型（top100 / band 8× / hyst 0 / 2×W5+1×pit / w=1.0）在 capital=20,000 下
能否缩容到小 top_n 而保住净超额？分散度损失（100 → 6-20 只）与 2 万整手约束
（`greedy_budget` + `fill_through`：买不起顺延、预算重分配）哪个占主导？

## 判据（冻结）

1. **G0 校准守卫（先决）**：A0 两套种子 full 窗 `excess_pp`/`mdd` 与
   `experiments/05_label/F52_live_vs_research_shape_result.json` 的 A0 读数
   |Δ超额| ≤ 0.05pp 且 |ΔMDD| ≤ 0.5pp ⇒ 引擎复现成立；不成立 ⇒ **全轮作废**，先修环境再重跑。
   （F52 在册读数：seedA 17.78pp/−0.366、seedB 17.47pp/−0.366。）
2. **P1 存续**：B2/B3/B4 至少一档在**两套种子**上 full 窗净超额 ≥ 同种子 A0 × 60%
   （即 seedA ≥ 10.67pp、seedB ≥ 10.48pp），且该档 MDD 不深于同种子 A0 + 5pp
   （即 ≥ −41.6%）。B5 只作观察（与月频车同构的极限档），不进 P1。
3. **P2 成本不爆炸**：过 P1 的档，换手 ≤ 同种子 A0 × 1.5（A0 ≈ 0.137 ⇒ ≤ 0.206）。
4. **P3 合成潜力（探索性，不设门槛）**：记录最优档周收益序列与月频车
   （`backtest_nav_daily` run `20260928_exe_full`）重采样周收益的 Pearson/Spearman 相关，
   供组合层合成分析（另文）。

## 判读规则

- G0 失败 ⇒ 本轮数字全部不产生证据效力。
- P1 ∧ P2 过 ⇒ 判 "2 万双车（月频 + 缩容袖套）经济上成立"，登记为纸面轨道候选；
  **不进生产、不改 config、不换 pin**（袖套纸面照旧 100 万口径跑）。
- P1 或 P2 不过 ⇒ 缩容线**结清**：分散度损失主导，2 万档袖套不可跑，登记后关闭此路。

## 多重比较与诚实性注记

- 6 臂 × 2 种子为一次预注册实验，臂是**结构性网格**（top_n 单调），不是搜索；
  P1 取"至少一档过"与文献先验（等权微盘小 n 集中组合历史有效）一致，判读时
  **必须同时报告未过档的读数**，不许只报最好档。
- 2 万档的已知乐观偏差：回测无"成交不到 1 手的名义碎股"问题（引擎整手），
  但**未模拟**涨跌排队的部分成交/开盘流动性冲击（slip 10bp 固定）——与月频车
  2 万实盘的已知口径相同，横向可比。
- 引擎机制注记：`fill_through=True` 时候选池 = top_n×5 顺延，`greedy_budget=True`
  时预算按剩余名额重分配（`F1b_weekly_open_overlap.py:176` 文档字符串，2026-09-12 加入）。
