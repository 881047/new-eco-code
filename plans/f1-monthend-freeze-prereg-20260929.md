# F1 月末行冻结预注册（2026-09-29，跑数前冻结）

> **假说与根因链**：`plans/model-rebuild-options-20260929.md` §5（commit 1e7b639f）——
> 上游 stock_basic 行业重分类（每天数行）→ industry_map（当前快照）逐日变 →
> 日频链 daily_engine 每天 upsert 最近 30 个交易日 factor 行（**含月末日**）→
> 月末行中性化值随覆盖日漂移 → 跨日全量重训特征不同 ⇒ 分数不可复现。
> 证据：20260831 月末行 75% 行跨日值变（09-22 备份 vs 现库），窗外月末零变化。
>
> **F1**：daily_engine 跳过月末日（月末行只归月度链写）。代码用 config 开关
> `daily_factor.monthend_freeze`（**缺省 False = 生产行为逐位不变**，与 chase.enabled
> 同款模式）；开启属特征口径变化 ⇒ 本预注册 + 用户拍板后才开。

## 实验设计（跑数前冻结）

### 实验一：根因复现（机制级验证）

用 **09-22 备份的 stock_basic 行业映射** + 相同原始行情（8 月零修订已证）+ **日频链同款
单行路径**（`neutralize(df.loc[[d]], ind)`）重算 20260831 截面的量价因子，与 09-22 备份
factor 表 8/31 行逐位对比。

- **判据 E1（复现成功）**：量价因子 ≥95% 的非 NaN 值**位级相等**（float64 存储比较），
  且残差形态（若有的话）不呈系统性乘性偏移。达成 ⇒ 根因链从"指纹推断"升级为
  **完全复现**，F1 的机制依据成立。
- **判据 E1-FAIL**：位级一致率 <95% ⇒ 覆盖日行业映射不是（唯一）漂移源 ⇒ F1 线结清，
  另找根因（fina ffill 源/lhb/列集）。

### 实验二：漂移对生产决策的实际影响（现役集成，不重训）

用生产 `lgb_latest_s*.txt` 集成（4 种子，不重训），分别对两个版本的 20260831 截面特征
打分：**版本 A** = 现库（漂移后）、**版本 B** = 09-22 备份（漂移前）。

- **判据 E2a（决策无影响）**：两版特征下 **top6 完全一致** 且逐股 score 秩相关 ≥0.999。
  ⇒ 漂移未影响过任何月度方案 ⇒ F1 价值 = 可复现性/工程健康（非收益）⇒ 实施可走
  轻量通道（仍须拍板，但 A/B 回测层免）。
- **判据 E2b（决策有影响）**：top6 任一不同 ⇒ 漂移已在实际改变月度方案 ⇒ F1 升级为
  **紧迫修复**，实施须配全量重训 + 重钉（完整 §1 流程）。

### 实施判据（实验一/二之后）

- E1 过 ∧ E2a ⇒ F1 代码合入（开关缺省关）+ 单测；**开关开启与月末行重算**留用户拍板
  （一次性把 8/31 行重算为月度口径版可选，不强制）。
- E1 过 ∧ E2b ⇒ 同上，另加"重算受影响月末 + 全量重训 + 重钉"必选路径。
- E1 FAIL ⇒ F1 线结清（改 daily_engine 无的放矢），根因轮继续。

## 结果（2026-09-29 实测回填，产物 experiments/05_label/f1_monthend_freeze_exp_0929.json）

### 实验一：E1 **FAIL** ⇒ F1 线结清

- 重算（09-22 备份行业映射 + 日频链同款单行路径）与备份 8/31 行的位级一致率**未达 95%**：
  一阶矩因子族位级全同（illiq/ret_max20/turnover_chg = 1.0），二阶矩/偏度族大面积不同
  （vol_60 0.33、skew_20 0.0、lhb_cnt20 0.0），mom 族 0.79~0.97。
- 判读：行业映射是漂移源**之一**（75% 行漂移与统一乘性指纹已证），但 9-22 当日的覆盖值
  还依赖其他无法事后完美重建的运行时状态（窗口滑动时代的列集/缓存路径/当日数据水位）
  ⇒ "跳过月末日"**不能**保证月末行回到某个确定版本 ⇒ F1 修复的机制依据不完整，
  **按冻结判据 F1 不实施**。

### 实验二：E2a **PASS** ⇒ 漂移对生产决策零影响（本轮最重要的产出）

- 现役 4 种子集成（不重训）对漂移前/后两版 20260831 特征打分（4,395 只，生产同款域）：
  **top6 完全一致**（000571/001260/002724/300548/603036/603097）、Spearman 0.999932。
- 判读：6e-5 级特征漂移在**生产打分链**（当日 factor 行 → 现役集成 → top6）上从未
  改变过任何月度方案。"跨日不可复现"的确切危害被重新定性：
  1. 生产**决策**稳健（本实验）；
  2. 不可复现只发生在**重训输出**（训练输入的微小漂移 → 新模型参数微变 → 分数微变）
     ——影响的是**研究对比**（跨日实验的臂间可比性），不是生产方案；
  3. 该危害已被既有纪律（"重训类实验必须当日对照臂"，09-16 起）完全覆盖。

### 总判决

**F1 证伪（按预注册判据线结清）**：修复的必要性不成立——机制不完整（E1）+ 危害
不达生产（E2a）+ 已有纪律兜底。09-16 悬案最终定级：**已定性（数据级漂移，机制部分
复现）、危害可控（决策零影响）、修复价值不足（F1 结清）**。daily_engine 一行未动。
后续若重开：须先定位第二漂移源并把重算对齐到覆盖日的完整运行时状态（成本高），
或出现漂移实际改变 top6 的证据（E2b 形态）。
