## 1. 改法（不换 pin 的硬前提）

`app/backtest/engine.py::_exec_side` 新增形参 `exec_window: str = "close"`，
由 `run_backtest` → `_load_inputs` 透传。

- **缺省时行为必须逐位不变**（`exec_window="close"` 等价于旧默认路径），这是不换 pin 的前提。
- 显式参数**优先于** `FILL_AT_OPEN` 全局开关：显式 `"open"` ⇒ 开盘价；`"vwap_tail"` ⇒ 尾盘 1h；
  `"vwap"` ⇒ 全日 VWAP。控制臂 C 显式传 `"open"`，与现役 pin（全局 True）等价 ⇒ G0 应逐位一致。

## 2. 三条防假盈亏硬规矩

1. **复权只乘一次**：所有窗口价一律先取**未复权** `px`，返回时统一 `px * av`
   （与 `_exec_side` 现返回式一致）。min60 是 `adjustflag=3`（**不复权**），
   与 `daily` 裸价同基准 ⇒ **绝不二次乘 `adj`**。
2. **单位自检闸门 G1**：逐日比对 `vwap_tail` 与 `close`、`vwap_daily`。
   差异中位数 **>50bp** 或异常格占比 **>1%** ⇒ W2 臂判「数据不可用」，**不进判决**（不是判负，是判未测）。
   （A 股 `amount` 单位千元、`volume` 单位手 ⇒ VWAP = `amount*10/vol`，须自检确认量级正确。）
3. **封板判定必须随窗口换**（否则一次改两个变量）：
   - `close` → 收盘封板（现状）
   - `open` → 开盘一字板（现状 `FILL_AT_OPEN` 分支）
   - `vwap*` → **全天封死**：买 `low ≥ limit_up − eps` / 卖 `high ≤ limit_dn + eps`
     （`high`/`low` 全史可得）

### 3.1 双种子集的显式覆写（必须留痕）

组合层档默认要求双种子集，其理由是**训练随机性**带来的种子噪声（本仓实测 ±3.5pp/年）。
执行层 A/B **不改训练、不改打分表** ⇒ 种子噪声这条路径不存在 ⇒ 双种子集无意义。

**替代判据**（本预注册写死）：

- 逐期月度收益**配对差 t 检验** `|t| ≥ 2`（按 `trade_date` 严格配对，**不得**按净值排序配对）；
- **双窗同号**：`p2020` 窗与 `full` 窗（W3 有全史）的 Δ 符号必须一致；
- 两者同时满足才算过 G2。理由与替代方案在本文件与台账留痕。

### 3.2 止损线

W2 / W3 相对控制臂 C 的 Δ **均 < +1.0pp** ⇒ **执行窗口作为 alpha 来源结清**，
