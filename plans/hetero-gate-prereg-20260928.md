# 预注册：异构信息门禁（P2 股东户数 + P3 隔夜-日内）

> 冻结时间：2026-09-28　状态：**判据已冻结，待执行**
> 性质：**门禁层**（单因子档 S1–S5），**不改生产、不换 pin、不重训**
> 过闸者才进 P4 组合层准入（双种子集重训 + `portfolio_admission_gate`）

---

## 1. 为什么是这两族

项目供给端的头号失败模式是「**量价同源面上挖到的必然是已知因子的影子**」（gp_000 与
size 的 ρ=0.951、LLM r3 点名因子 ρ=1.0、新 50 因子 90% 方差仅 25 个有效维）。
⇒ 破局只能靠**异构信息**，且必须机械过同一道门禁，不许"看起来有逻辑"就放行。

- **P2 股东户数**：`holder_num` 190,622 行（2016-03 起，5,563 只），
  `app/factors/holder_factors.py` 已封装 `holder_chg_1q`/`holder_chg_4q`，
  仅因 `compute_all(include_new=False)` 未启用。**零补数成本。**
- **P3 隔夜-日内**：只需日频 `open/pre_close/close`（2013 起全史）。
  **关键简化 —— 不必受 min60 的 2020-01 起点限制。**
  外部机制：A 股独有「隔夜负收益 + 日内正溢价」（上证 2010 以来隔夜均 −0.087%/日、
  日内均 +0.100%/日，源于 T+1 把逆向选择成本压到买方）；中信建投 32 个隔夜-日内
  因子 + 领先滞后策略年化 14.99%/alpha 11.34%。

## 2. 候选清单（跑数前写死，跑后不许增删）

### 族 A · 股东户数（2 个）
| ID | 定义 | 方向 |
|---|---|---|
| `holder_chg_1q` | −(log 户数 环比) | 户数减少（集中）→ 因子为正 |
| `holder_chg_4q` | −(log 户数 同比四个季度) | 同上 |

### 族 B · 隔夜-日内（8 个）
`ovr_d = open_t/pre_close_t − 1`、`intr_d = close_t/open_t − 1`，全部用 `×adj` 复权价。
窗口 W ∈ {20, 60} 交易日。

| ID | 公式 | 经济含义 |
|---|---|---|
| `ovr_mean_20` / `ovr_mean_60` | `mean(ovr_d_adj)` | 隔夜持续跳空 ⇒ 后续回落 |
| `oi_spread_20` / `oi_spread_60` | `mean(intr_d_adj) − mean(ovr_d_adj)` | **核心候选**：隔夜-日内价差强度 |
| `intr_rev_20` / `intr_rev_60` | `−mean(intr_d_adj)` | 日内溢价反转 |
| `close_pos_20` / `close_pos_60` | `mean((close−low)/(high−low))` | 收盘在日内区间的位置（尾盘 strength） |

**规模剥离版为第一版（写死，不是事后补救）**：
`x_adj = x_d − 当日截面均值(x_d)`，再对 `std(x_d)_W` 标准化。
理由：隔夜跳空的截面差异主要由流动性/规模驱动，减掉当日截面均值即剥掉共同规模因子。
**只有 `close_pos` 不剥离**（它本来就是日内区间位置，与规模无直接关系）。

## 3. 判据（照搬现役门禁，不调门槛）

| 轴 | 门槛 |
|---|---|
| **S1 强度** | DEAD 区 `|head_excess| ≥ 0.3%/月` |
| **S2 显著** | DEAD 区 `|t| ≥ 2` |
| **S3 同号** | DEAD 与 ACTIVE 区 head 同号 |
| **S4 非影子** | 与现役 26 因子 `|ρ|max ≤ 0.7` |
| **S5 时效** | IC 半衰期 ≥ 2 个调仓周期（月频 ⇒ ≥2 月） |

门禁区：DEAD 2020-09-01~2023-12-31 / ACTIVE 2024-01-01~2026-08-31。

**覆盖体检（跑数前冻结）**：每期截面非 NaN 占比 < 50% ⇒ 记「覆盖不足」，
**不否决**（沿 S4 惯例：未测不否决）。但需在台账写明，因为覆盖不足会让 t 值虚高。

## 4. 分支动作

- **PASS** ⇒ 进 P4（影子表 + 双种子集重训，判据 P1/P2/P3）
- **S4 FAIL（疑似影子）** ⇒ **只允许一次**残差化重测：对 `log(total_mv)` + `illiq` + 行业
  做截面回归取残差，**解释变量只允许这三个**，且残差版必须**重跑全套 S1–S5**。
  禁止"两个版本挑好看的"；台账必须写明「通过的是残差版」。
- **REJECT** ⇒ 线结清，写入 `docs/know/14` 的已结清清单，勿重测。

## 5. 诚实预判

- **族 A（股东户数）**：本线最可能过闸（季度 log 差分取负、`ann_date` 对齐已实现）。
- **族 B（隔夜-日内）**：**预期通过率 < 20%**。日频信号喂月频持有，S5（半衰期 ≥2 月）
  几乎必然拦掉大部分；且隔夜收益截面差异主要由流动性/规模驱动，S4 也会拦。
  **这是 S5 存在的意义，不是门禁太严。**

## 6. 硬约束

- **不改生产**：不调 `compute_all(include_new=...)`，不改 `factor` 表，不动 `model_score`。
  只在门禁脚本内存里装载因子面板。
- **不换 pin**：门禁层用 `gate.forward_return`（朴素前向收益），完全不经过回测撮合，
  故与 P1.5 的撮合口径无关。
- 产物：`experiments/hetero_gate_20260928.json`。
