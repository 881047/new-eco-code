> 思路："因子按半衰期分层 → 长半衰期因子配长持有、短半衰期因子快速换手"），依赖创新②

## 一、度量（跑前冻结，纯曲线推导）

设因子持有 H 个月（月频锚点不变，信号在持有窗内老化 0..H−1 期）：

- **毛边缘** G(H) = mean(IC_0..IC_{H−1})（S5 衰减曲线的 HEAD 段均值，H ≤ 6）；
- **月均换手** τ(H) = 1/H（相对月频全换手）；
- **盈亏平衡单边成本** c*(H) = (IC_0 − G(H)) / (1 − 1/H)，H≥2——真实单边成本低于 c* 时
  延长持有净改善（推导：net(H) > net(1) ⟺ c < c*(H)；G 无衰减时 c* ≤ 0 ⇒ 任何正成本下
  延长都严格更优）。**参考成本 c_ref = 0.003**（= config `single_side_cost`，生产回测在用
  口径，非发明数字）。判 "延长可行"（viable）：c*(2) ≥ c_ref 或 c*(3) ≥ c_ref。

## 二、范围与读数（跑前冻结）

- 范围 = S1-S5 官方重测里**有完整曲线**的面板：31 在池因子全量 + bank S1-S4 过档且
  有 npz 者（与 S5 测量域一致）；数据源 = `experiments/single_factor_retest_s5_20260927.json`
  的 `ic_curve_dead`（DEAD 区判定，ACTIVE 照记）。
- **R1 可行性（判定）**：池 31 中 viable 占比 ≥ 1/3 ⇒ "存在可行的延长持有层"，产出
  分层候选名单（长 HL 高持有层 / 短 HL 月频层）供组合层 A/B 预注册；否则探针结清。
- **R2 连贯性（验证②读数的决策价值）**：冻结预测——**HL≥4 组的 viable 占比应高于
  HL≤2 组**（半衰期长的因子更该延长持有）。若反向 ⇒ S5 读数对持有期决策无增量，
  如实登记（②仍作门禁过滤器有效，但不作分层依据）。
- **R3 名单（读数非判决）**：逐因子 c*(2)/c*(3)/viable/所属层，登记入产物。

## 四、限制

1. G(H) 用秩 IC 近似毛边缘，未含头部非线性（head 与 IC 可异号——S1/S3 与组合层档的职责）；
2. 曲线删失于 L=5（HL>6 不细分），H 只测到 3（月频生产的最小改动步长）；
3. c_ref 是回测口径的常数，真实冲击成本随换手规模变化——组合层 A/B 才是终审；
4. bank 候选的 viable 读数只作"周/日频臂"的远期参考（本仓月频生产不直接消费）。
