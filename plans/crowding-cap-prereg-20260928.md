# 拥挤度暴露约束 A/B 预注册（2026-09-28，跑数前冻结）

> 来源：两频综述 L3（锁死资本路径）+ 29 补处方 3。机制 = **block_ic P0 连续 2 期 →
> 该分块暴露上限**——不是收益预测（因子动量 REJECT 的反面），是**风险上限**。
> 判据 = 2024-02/2026-09 型尾部事件的回测重现。v1 只做 B1（规模/流动性——微盘拥挤
> 的诊断中心），实现 = 评分表层剔除（零引擎改动，沿 txt2 先例）。

## 一、机制（冻结）

- **分块 IC 序列（real-time）**：B1 成员（size/amount_log/illiq）在每个月末锚点 t 对
  naive 21 日前瞻收益的秩 IC（≥200 只）→ 块 IC_t = 三成员均值。
- **冷判定**：long_t = mean(IC over [t−24 月, t−1 月])，recent_t = mean(IC over
  [t−6 月, t−1 月])；**冷_t = recent_t × sign(long_t) < 0 且 |long_t| ≥ 0.01**。
- **约束激活**：cold_t ∧ cold_{t−1} ⇒ **下一个月**候选池剔除**流通市值最低五分位**
  （当月截面前 20% 分位以下，按 circ_mv）。
- 实现 = 评分表层：生产 `model_score` 在激活月的**最小市值五分位股票行删除** →
  隔离表 → 生产引擎回测。生产表一字不动。

## 二、判据（冻结）

- **P1（主判据）**：处理臂 MDD 相对 pin（20260927_excl5 在册）改善 ≥ 2pp（prod 窗——
  2024-02/2026-09 型尾部在窗内）；
- **P2（非劣）**：excess_ann ≥ pin − 1.5pp（双窗）；
- **P3（触发合理性）**：激活月占比 ∈ [5%, 40%]，且激活月集中在市场压力段（2022/
  2024-02/2026-09 邻近——活动日志如实列报）。
- **判决词（机械）**：P1∧P2∧P3 ⇒ "PASS（进生产接线预注册）"；MDD 改善 < 1pp 或 P2
  失败 ⇒ "REJECT（线结清）"；其余 ⇒ "INDETERMINATE"。拍板由人。

## 三、产出与语义

- runner：`scripts/oneoff/crowding_cap_20260928.py`（写一张隔离表 crwd_cap + 引擎双窗
  回测）；产物 `experiments/crowding_cap_20260928.json`；台账 三十五补。
- PASS ⇒ 生产接线预注册（engine/config 门控）⇒ 拍板；REJECT ⇒ 线结清。

## 四、限制

1. v1 只约束 B1（诊断的拥挤中心）；B2/B4 的扩展须新预注册；
2. 最小市值五分位是暴露上限的粗实现（真因子暴露上限需组合优化）；
3. 冷判定窗 24/6/阈值 0.01 为冻结 v1；
4. 评分表层剔除与引擎内过滤的等价性由双臂同引擎保证。
