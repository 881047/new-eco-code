# LLM 自主挖因子循环 r3 预注册：生成端约束 + 去相关 + 错误摘要反馈（2026-09-26，跑数前冻结）

> 依据：全球检索综述 `plans/llm-mining-survey-20260926.md`（Hubble/AlphaAgent 机制）；
> r2 瓶颈：20 提案 17 静态非法（85%）。判据跑前冻结；0 PASS 仍为基准预期。

## 一、本轮唯一要证明的事

**生成端约束 + 错误摘要反馈能否把静态失败率从 85% 压下来**——这是机制级可测判据
（Hubble 报告零崩溃/104 候选，我们的对照基线是 r2 的 17/20）。因子层面的门禁六判据
照旧，PASS 与否不是本轮的成功定义。

## 二、机制（相对 r2 的三处增量，全部冻结）

1. **生成端约束（Hubble 式）**：prompt 新增 ①受控词汇表（$ 变量 12 个 = build_panel
   实际可求值键 + vwap；算子 = 工厂求值器注册表全集）②3 条合法样例 + 2 条非法样例
   （附原因）③明确"非法 = 浪费名额，逐算子核对后再输出"。
2. **AST 三层校验器（跑在 LLM 之后、工厂之前）**：①变量白名单 ②算子白名单 + arity
   （对照 expr.py 注册表）③复杂度上限（节点 ≤24、树深 ≤4）。非法者记**错误分类**
   （未知算子/未知变量/arity 错/超复杂度/前视）进反馈，不进厂。
3. **去相关预筛（AlphaAgent 式）**：每候选算与 31 现役因子的逐锚点截面 Spearman ρ，
   **|ρ|max > 0.7 ⇒ 标记"影子"**（照常进厂登记读数作证据，但组合层讨论终止——
   gp_000 教训制度化）。
4. **反馈升级（Hubble 式）**：迭代 2 prompt = 迭代 1 读数 + **错误分类分布** + 本轮
   合法/非法样例各 2 条。
5. **KG 降噪域平行读数**：沿用 r2（剔 kg_resonance+kg_pagerank_ind 拥挤前十分之一），
   报告用不参与判据。
6. **预算**：2 迭代 × ≤10 = ≤20 条；分母 = 20（单域）+ 降噪读数对已过静态的候选计
   双域（保守 ≤40）；N_used = max(分母, 在册+分母)。

## 三、判据（冻结）

- **机制判据（本轮主判据）**：静态失败率 ≤ 40%（r2 = 85%，即 20 条里非法 ≤8 条）。
  达成 ⇒ 生成端约束被证实有效，机制进入常规化；未达成 ⇒ LLM 直写 DSL 在本仓
  判"不可行"，后续轮必须换载体（受控变换算子集扩展或代码沙箱）。
- **因子判据（照旧，非本轮成功定义）**：标准六判据；PASS = POOLED = 资格非可用；
  "影子"标记的候选不进组合层讨论。
- **去相关预筛的判读**：|ρ|max ≤ 0.7 的候选数 ≥ 5 ⇒ 去相关筛有效压缩了影子空间。

## 四、产出

- runner：`scripts/oneoff/llm_mine_loop_r3.py`（r2 + 校验器 + 反馈升级）；
- 产物：`experiments/llm_mine_loop_r3_20260926.json`（两轮提案/读数/错误分类/
  去相关表/降噪域对比/静态失败率对照）；
- 判决登记：05 号 十三补；机制结论同步 13 号 §八。

## 五、限制

1. 样本仍是 2 迭代 × 10 条，失败率的置信区间宽（40% 门槛是方向性的）；
2. LLM 幻觉的外部主张（QuantaAlpha IC 0.1501 等）均未经本仓测量，不构成本轮预期；
3. 门禁六判据与生产打分零改动；LLM 输出不进任何生产链路。
