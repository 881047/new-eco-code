# 月频波动率缩放层 A/B 预注册（2026-09-27，跑数前冻结）

> 来源：两频瓶颈综述（plans/two-frequency-bottleneck-survey-20260927.md）创新 1——
> Moreira-Muir 2017 精华 + Cederburg 2020 OOS 教训。目标 = 月频"回撤时间结构未管理"
> 瓶颈（全史 MDD −43.4%）。机制 = **权益缩放（只减不加，无杠杆），不碰模型/选股**。
> 本轮 = 研究层判据：在 pin 的日线 NAV 上做逐期线性缩放叠加；生产接线若 PASS 另走
> 引擎参数预注册 + replay 验证（两段式，与 factor_exclusions 采纳同款纪律）。

## 一、机制（冻结）

- 基础序列 = pin **20260927_excl5**（prod 窗）与 **20260927_excl5_full**（全史）的满仓
  日线 NAV（`backtest_nav_daily` 精确 run_date 匹配）。日收益 r(d) = nav(d)/nav(d−1) − 1。
- 缩放因子（**全部 real-time，只用过去数据**——Cederburg 教训的制度化）：
  在每个月度调仓期起点 p：
  - σ_est(p) = 期前 63 交易日基础日收益年化波动（×√252）；
  - σ_base(p) = σ_est 在期前 252 交易日的滚动均值（自身基线，非全样本）；
  - **w(p) = clip(σ_base(p)/σ_est(p), 0.5, 1.0)**——高波动期减仓、低波动期不打折
    （长-only 无杠杆 ⇒ 只减不加；下界 0.5 防过度空仓）。
- 叠加路径：缩放期内日收益 r'(d) = w(p) × r(d)（未缩放部分现金收益计 0，保守）；
  w 期内恒定；期边界 = trade_date 的自然月切换（月末锚点语义下与调仓期一致）。
- 前导空窗：σ_base 不足 252 日 ⇒ w=1.0（等价不缩放），如实声明。

## 二、判据（冻结）

- **P1（主判据）**：叠加 MDD 相对基础改善 ≥ 5pp，prod 与 full **至少一窗达标**且另一窗
  劣化 ≤ 2pp；
- **P2（非劣）**：叠加年化收益 ≥ 基础 − 1.5pp（两窗）；
- **P3（触发合理性）**：w<1 的期数覆盖率 ∈ [15%, 60%]——过低 = 机制未触发，过高 =
  永久降杠杆而非"管理"。
- **判决词（机械）**：P1∧P2∧P3 ⇒ "PASS（进生产接线预注册）"；两窗 MDD 改善均 <2pp 或
  P2 失败 ⇒ "REJECT（线结清，登记勿重测）"；其余 ⇒ "INDETERMINATE"。拍板由人。
