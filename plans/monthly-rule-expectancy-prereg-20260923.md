# 月度选股规则「长期期望是否为正」回测预注册（2026-09-23）

## 一、目的（单一，只判一件事）

判：**现行月度选股规则（按 `model_score.score` 取 top-k 等权、月度换仓）在历史上是否存在统计上可辨的
正期望**。
- **不挑最优 k**（F56 已证明同类构型里挑最佳 ≈ 抛硬币，PBO=0.434）⇒ k 之间只报差异与单调性；
- **不判"该怎么改"**，只给"期望是否为正 / 是否可辨"这两个数；
- 起因：20260831 方案的归因（05 号 §5.22）显示理论组合 −1.76% 里约 88% 是市场 beta、
  选股只差 −0.21pp（n=5，噪声级）⇒ **"期望到底是不是正的"这一格目前是空的**，先用 116 期历史把它填上。

## 三、规则（最容易事后凑参数的地方，全部先钉死）

1. **选股**：每期按 `score` **降序**取前 **k** 只；k ∈ **{5, 10, 20, 30, 50}**（5 = 现行，其余 = "扩只数"候选）。
2. **权重**：**等权**（现行方案权重 0.163~0.232 已接近等权；等权避免引入第二个自由度）。
3. **建仓价**：锚点后**第一个开市日的开盘价**（T+1 开盘 ⇒ 与"实际执行"同尺，且避开锚点收盘不可成交）。
4. **换仓**：持有到下一锚点后的第一个开市日，按开盘价全卖全买（月度换仓）。
5. **补位**：建仓日无开盘价 / 停牌 / 上市不足 60 交易日 的票**剔除后顺位补足**（与生产选股域一致）。
6. **不可成交的处理**：建仓日有开盘价即视为可成交 ⇒ **这是乐观偏差**；但**所有 k 臂同受此偏差**，
   而本轮主要判的是"期望符号与可辨性"及 k 之间的**相对**差异 ⇒ 影响可比性不至于失控（如实写进产物）。

## 五、判据（主判据，跑数前冻结）

记月收益序列 `{r_t}`（t = 1..n，n = 可用持有期数，预期 115）：
- 均值 `m = mean(r)`；`t = m / (s/√n)`（`s` 为样本标准差）；
- 相对基准的**配对**差 `d_t = r_t − r^{BM}_t`（配对可削时间抽样方差，项目已有先例）。
- **判决**：
  - `m > 0 且 t ≥ 2.0` ⇒ 判「**存在正期望**」；
  - `t < 2.0` ⇒ 判「**不可辨**」——**不得**写成"没有正期望"或"期望为负"（测不出 ≠ 没有，这条写死）；
  - 若 `m ≤ 0` ⇒ 判「**未见正期望**」（同样不许引申为"期望为负"，除非 `m < 0 且 t ≤ −2.0` ⇒ 才判「存在负期望」）。
- **不挑最优 k**：k 只报 `m / t / 胜率 / MDD` 与相互差异，不设"选哪个 k"的判决格。

## 六、稳健性（不判决，只报告）

- 分两段：**2017-01 ~ 2021-12** 与 **2022-01 ~ 2026-08**；
- 报告：月收益中位、胜率、年化（×12 与几何两种都给）、最大回撤；
- 基准对照：同口径下中证500、沪深300 的 `m / 胜率 / MDD`。

## 七、限制（先写死）

1. **前视偏差**：只用当期可得的 `score`（分数在换仓日开盘前已知，与生产一致）；锚点=打分日期。
2. **乐观偏差**：未建模涨跌停无法成交与停牌（见 §三.6）；两档资金都报，且各臂同偏差。
3. **不含现金收益、不含分红再投资细节**（红利已通过 `adj_factor` 部分体现，残差计入限制）。
4. **样本 115 期、单规则** ⇒ 结论只覆盖"这条规则"，不外推到别的打分或别的市场。
5. 本轮**不改任何东西**（不改选股只数、不改权重、不改执行时点）—— 那些都属换 pin 级，需另立预注册 + 用户拍板。
