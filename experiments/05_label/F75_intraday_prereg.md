# F75 预注册 —— 日内（baostock 60min）因子的信息含量检验

写于 **2026-09-15 夜**、数据采集开工之前：**任何日内因子读数都还没算过**（当晚只测过可达性/行数/耗时，
没看过任何因子与收益的关系）。

## 0. 这一轮要回答的问题

baostock 60min 分钟线（2020-01-02 起）里，有没有本项目现有 31 个日频因子**拿不到的信息**，
且该信息在**组合层**（top100 等权）能变成超额？

## 1. 数据与口径（冻结）

- 源：`data/baostock_min60/<ts_code>.parquet`（baostock 60min，`adjustflag=3` 不复权）
- 范围：沪深 5,443 只（2020 起在 `daily_basic` 出现过的票，含期间退市）；北交所无（缺口已登记 09 号）
- 锚点：与生产周频一致（每周最后交易日）；因子只用**锚点日及其前 4 个交易日**的 bar（无前视）
- 标签：与生产一致 = `forward_excess`（开→开 5 日超额，减当日可交易池等权）
- 中性化：与生产 die 一致（`fe.neutralize`：2%/98% winsorize → 行业去均值（W5 快照）→ z-score）
- ⚠️ bar 时段约定（10:30/11:30/14:00/15:00 收）**待数据质量检查确认**；若实际不同，
  如实登记修正（且明确"这是口径更正、不是放宽判据"）

## 2. 因子定义（冻结；**只做 3 条** —— 每多做一条都在消耗统计预算）

在锚点日 T：

1. **`id60_late_vol_share`** = 最后一根 60min bar 成交额 ÷ 当日 4 根成交额之和，取 T−4..T **五日均值**
   （尾盘成交占比 = 收盘前集中交易的画像；A 股收盘集合竞价与尾盘调仓是已知的行为偏差位置）
2. **`id60_late_ret`** = 最后一根 bar 收益 `close/open − 1`，取 T−4..T **五日和**
   （尾盘方向性收益 = 知情交易/机构调仓的代理）
3. **`id60_close_vs_dayvwap`** = `close_T / VWAP_T − 1`，`VWAP_T = Σamount / Σvolume`（当日 4 根求和；
   baostock volume 单位=股、amount=元），取 T−4..T **五日均值**
   （收盘价相对当日成交均价的位置 = 买卖压失衡）
   ⚠️ **退化警告**：若最终实现落到"用日频 amount/vol 算全日 VWAP"，这条**必须**登记为"日频即可得"，
   不得当作分钟线带来的新信息。只有把**尾盘分段**并进去才算真增量。

方向：三条**都不预设符号**，由门禁判"两区同号 + 正向"。

## 3. 判据（冻结，跑之前写死）

1. **KGD 五项**（`app/models/expert.py`；死区 2020-09~2023-12）：死区 head ≥ 0.5%/月、|t| ≥ 2、
   死区与活跃区**同号**、Bonferroni p < 0.05、与在役基线秩相关 < 0.95；
2. **经济门槛（门禁 v2）**：`head_bar ≥ 0.5%/月 + 自换手 × 往返真实费率`（成本算不出 ⇒ 判否）；
3. **撞车硬闸**：同公式 / 同 id 异公式 / 同名异源 / 值面板 ρ≥0.999 ⇒ 拒跑（`bank.check_duplicate`）；
4. **累计分母**：`N_used = max(本批 3, 累计 + 3)`，累计取 `alpha_bank` 行数（当前 ≥171）；
5. **组合层判决（仅当 1~4 全过才跑）**：top100 等权 + 8× 退出带 + 生产构型，**两套种子**、
   **两轴**（超额 + MDD）都不劣，配对检验 + F70 噪声尺（集合差 10% 量级、t<1.6 不算证据）。

## 4. 判读（写于跑之前）

- **全否** ⇒ 与 `die_flow`（Tushare moneyflow：KGD 过、组合层无用）同类 ⇒ **日内这条线结清**，
  **5min 不采**（省 11 天 / 4.3 亿行）。
- **任一条过 1~4** ⇒ 才谈 Stage 2（补 5min / 进模型），且仍要过第 5 条。
- 无论结果，**不许**用"再多试几条因子"的方式找显著性（累计分母会罚，且违反 `01` #13）。

## 5. 已知限制（写于跑之前，避免事后找借口）

- 分钟线**只有 2020-01 起** ⇒ 死区仅 2020-09~2023-12（40 个月）、活跃区 2024-01~2026-08；
  **历史长度不足 12 年**，与现有 651 锚点面板不可直接比大小。
- 60min 只有 **4 根/日** ⇒ 尾盘粒度与日内路径被压扁；5min 才能做更细的微结构。**这是自觉取舍**。
- 不复权价（`adjustflag=3`）：与日频复权因子/停牌口径需在实现时对齐并登记（对齐方式不许改变
  生产标签 —— 标签仍是 F73 判定的未复权口径）。
- 采集阶段的吞吐实测：批量连续拉取单票 **25~60s（均值≈34s）** ⇒ 全市场 ≈5 天（含工作窗限制）。
