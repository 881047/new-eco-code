# 机器学习与建模方法论（模型、标签、验证、融合的科学做法）

> 定位：金融预测的"工程科学"层。核心不是模型越新越好，而是**标签、验证、过拟合控制**。
> 与本项目相关：现役 LightGBM（leaves 31 / min_data 200 / lr 0.05 / 50 轮）、
> 2×W5+pit 融合、F22/F47 结论、模型族替换与 stacking **全部被否**（`05`/`13`）。
> 证据标签见 `20` 号文件。

## 一、金融 ML 的五个特殊性（决定了教科书方法要改造）

1. **低信噪比**：月度股票收益的样本外可解释比例通常远低于 1%（Gu-Kelly-Xiu, 2020）；模型很容易学到噪声；
2. **非平稳/时变**：分布、因子有效性、制度、参与者结构都在变；"训练集与测试集同分布"不成立；
3. **有效样本少**：截面相关 + 时间自相关 ⇒ 名义 n 很大，**有效独立样本**很小；
4. **对抗性/反身性**：你的信号被交易后会衰减（alpha decay）；市场参与者会适应；
5. **目标错配**：机器学习优化预测误差，投资优化**组合收益/风险**，两者不是一回事（预测准 ≠ 赚钱）。

**推论** [J]：在金融里，"更复杂的模型"通常不是瓶颈；**标签设计与验证协议**才是。

## 二、学习问题设定：先定目标，再选模型

| 目标 | 目标变量 | 损失 | 适用 |
|---|---|---|---|
| 回归 | 未来超额收益 | MSE/MAE/Huber | 预测幅度，但被极端值主导 |
| 分位/排序 | 横截面排名/分位 | 排序损失、IC 近似 | 选股（只关心谁是头部） |
| 分类 | 涨/跌、超阈值 | 交叉熵/AUC | 事件、方向 |
| 生存分析 | 到事件的时间 | 部分似然 | 违约/退市/持有期 |
| 组合优化 | 直接优化组合 | 效用/Sharpe | 端到端，但样本效率差、易过拟合 |

**关键问题**：

- **损失与目标错配**：MSE 对极端收益敏感，但策略只买 top-N；IC 好 ≠ 头部收益好
  （本项目已三次实证 IC 与头部收益反相关，`01` #2）；
- **训练目标与判决目标分离**：训练可以优化预测，判决必须在**组合层两轴**（超额 + MDD）；
- **标签 horizon**：太短 ⇒ 换手与成本高；太长 ⇒ 样本更少、暴露漂移。本项目用 5 日（周频）与 21 日（月频）。

## 三、偏差-方差、正则化与模型复杂度

- **[T] 偏差-方差分解**：见 `22` 第一节；
- **[T] 正则化**：L2（岭）、L1（LASSO）、弹性网、dropout、权重衰减、数据增强（金融里谨慎）、
  early stopping（**在金融里要小心**：验证集本身有噪声，早停会选到运气好的轮数，本项目明确禁 early stopping）；
- **[T] 贝叶斯方法**：先验强度 = 正则化强度；后验预测分布天然包含参数不确定性；
- **样本量直觉**：参数数量应与**有效样本量**匹配；在低信噪比下，容量大的模型需要更强的先验/正则。

## 四、模型族：假设、优势、失败模式

| 模型族 | 假设/归纳偏置 | 优势 | 金融里的失败模式 |
|---|---|---|---|
| 线性/岭/LASSO | 线性、稀疏 | 稳定、可解释、样本效率高 | 非线性交互被漏掉；LASSO 在相关特征间随机选择 |
| GLM/Logistic | 单调链接函数 | 概率输出、可解释 | 非线性/交互需手工构造 |
| 树/随机森林 | 轴对齐切分、局部常数 | 缺失值天然处理、非线性 | 外推差；对分布漂移脆弱 |
| GBDT（XGB/LGBM/Cat） | 加性树、贪心分裂 | 表格数据强、正则项多 | 过拟合小样本；参数敏感；外推差 |
| 核方法/SVM | 核诱导相似度 | 小样本非线性 | 大规模慢；核/参数难选 |
| MLP/深度学习 | 多层非线性 | 表示学习、可扩展 | 数据饥渴、易过拟合、不稳定 |
| 序列模型（RNN/LSTM/TCN/Transformer） | 时序依赖/注意力 | 长依赖建模 | 金融序列短、噪声大；注意力易过拟合 |
| 图神经网络 | 关系结构 | 供应链/股权/资金网络 | 图是估计的、时变的；数据难得 |
| HMM/状态切换 | 离散潜状态 | 制度识别、可解释 | 状态数主观；实时滤波 vs 事后平滑 |
| 矩阵分解/自编码器 | 低维因子结构 | 降维、风险因子 | 因子可解释性差；过拟合 |
| 高斯过程 | 平滑先验 | 不确定性量化 | O(n³)；核选择主观 |
| 强化学习 | MDP + 奖励 | 直接优化决策序列 | 样本效率极低、奖励设计难、回测幻觉（见 4.1） |

**本项目经验（已核实）**：XGBoost / CatBoost / MLP / Transformer 等模型族替换 10+ 轮全否，
共同失败方式是**削掉 2024-25 唯一真实收益段**；LightGBM 的现役超参在全史口径上局部最优（F47）。
这不证明"其他模型永远不行"，但证明**在当前数据/标签/验证协议下，替换模型族不是主要矛盾** [J]。

### 4.1 深度学习的现实边界

- **[E] Gu, Kelly & Xiu (2020)**：树模型与神经网络在月度截面预测中优于线性模型，
  但样本外 R² 仍在**远低于 1%** 的量级；收益主要来自少数极端预测；
- **[E] 微观结构深度学习**（DeepLOB, Zhang et al., 2019；Sirignano-Cont, 2019；Kolm et al., 2023）
  在**高频订单簿**任务上有效，因为它们有海量样本、明确标签、短预测窗；
  **不要把高频 DL 的成功外推到月频选股**；
- **RL 的陷阱**：奖励设计、模拟器偏差、非平稳市场、样本效率；回测里的"策略"常常在实盘失效
  （Nevmyvaka et al., 2006 是执行类应用；交易类 RL 的公开稳健案例很少）；
- **成本**：训练/调参/维护成本要计入研究预算；本机是 CPU（`06`），大模型不可行。

## 五、标签设计：金融 ML 最容易出错的地方

**常见标签**：

| 标签 | 形式 | 特点 |
|---|---|---|
| 固定 horizon | open(t+1+H)/open(t+1) − 1 | 简单；重叠 ⇒ 样本相关 |
| 超额标签 | 减去票池等权/行业均值 | 本项目采用；直接学相对强弱 |
| 三重障碍 | 上/下障碍 + 时间障碍（López de Prado） | 含路径信息；参数（障碍宽度）需定 |
| Meta-labeling | 先判断方向，再学"是否该下注" | 可提升精确率；两层都要验证 |
| 排序标签 | 横截面分位/排名 | 与"只买头部"目标一致 |
| 波动率缩放 | 收益/波动率 | 让不同波动环境可比 |

**样本权重与重叠** [T/J]：

- 重叠标签（同一未来窗口被多个样本使用）⇒ 样本不独立 ⇒ 有效样本量被高估；
- López de Prado 的"唯一性权重/顺序自助"用平均唯一性给样本降权；
- 时间衰减权重：近期样本更重要，但会放大近期噪声；
- **本项目没有显式处理重叠权重** ⇒ 这是一个已知的统计保守性问题（F28/F38 的显著性已按更保守处理）[J]。
  **更正（2026-09-19）**：F76 已把并发度落成实测（月频标签并发 c̄=1.0610，u 均值 0.9427）；
  F76b 又把"唯一性权重"补救在双种子 A/B 上实测 ⇒ **effect_indistinguishable，不采纳**
  ——统计上保守性存在，但补救换不来可分辨的改善，且同配置换种子的年化噪声（5.9pp）
  远大于候选效应。见 `05` 号。

## 六、特征工程：把"数据"变成"可学习信号"

**基本原则**：

1. **平稳化**：价格→收益/比率；水平值→差分/分位；避免趋势泄漏；
2. **截面标准化**：按**当日**横截面做（不是全样本）z-score/分位；
3. **中性化**：行业/风格去均值——注意**线性中性 ≠ 尾部中性**（F40 实证）；
4. **极值处理**：winsorize 的窗口与分位是研究者自由度；稀疏面板会被 2%/98% 规则**整行归零**
   （本项目 F35 踩过，`09` 第四节）；
5. **缺失值**：缺失本身可能是信号（未上榜/未披露）；LightGBM 原生处理，但不要用未来值填补；
6. **PIT 对齐**：财务用披露日，公告用公告日，指数成分用生效日（`09`）；
7. **特征数量**：候选越多，多重检验越重；先验 + 经济机制 > 暴力特征挖掘。

**本项目 31 因子**的分类（见 `13` 二）：价量 22 / 财务 6 / 龙虎榜 3。
**注意**：因子清单本身是历史试错的结果；新增因子必须先查 `05` 是否已证伪。

## 七、验证协议：随机 CV 为什么在金融里是错的

**错误做法**：

- 随机 K-fold：训练集含未来样本 ⇒ 前视；
- 时间序列 split 但不留间隔：重叠标签让训练/验证窗口共享未来信息 ⇒ 泄漏；
- 用同一留出集反复调参 ⇒ 留出集变成训练集（本项目 F28 已一次性开封，后续只算方向）。

**正确做法**：

| 协议 | 用途 |
|---|---|
| 滚动/扩展窗 walk-forward | 模拟真实再训练 |
| Purged K-fold + embargo | 剔除与测试期重叠的训练样本，并留禁运期（López de Prado） |
| 嵌套 CV | 外层评估、内层调参；避免调参污染评估 |
| 组合 purged CV（CPCV） | 生成多条回测路径，估计 PBO |
| 留出集一次性 | 最终判决；开封后失效 |

**本项目现状**：`trainer._train_window` + `EMBARGO=3` 个锚点（5 日标签跨期需要）；
训练窗与生产复用同一函数。**更正（2026-09-19）**：CPCV/PBO 已补做——F56 实测 PBO=0.434
（S=8/16，不通过 ⇒ 参数搜索的过拟合概率高，见 `05`）；**F56b 又补了 purge 验证**：
预注册门 |ΔPBO(S=16, purge=1)|<0.05，实测 0.0172 ⇒ PBO 高**不是标签泄漏**，结论不变
（副产品：PBO 是秩分位统计，单个尾锚就能让 PBO(S=8) 动 0.057——**引用 PBO 必须同时
写明 S 与行集**）。嵌套 CV 仍未做 ⇒ 内层调参的多重比较问题 [J] 依旧在册。

## 八、过拟合检测：把"漂亮回测"当嫌疑人

**必查清单**：

1. **PBO/DSR**（`22` 第三节）：参数搜索的过拟合概率；本项目 F38 不通过；
2. **参数敏感性**：邻域参数是否同样好？只有单点好 ⇒ 可疑（F47 的六格结清是正面例子）；
3. **子样本稳定性**：分年度/分市值/分行业/分制度阶段；
4. **安慰剂/随机基准**：随机标签、随机选股、打乱特征的对照（本项目 `exp_null_random.py`）；
5. **消融实验**：逐个去掉特征/中性化/die，看贡献是否单调合理；
6. **成本敏感性**：滑点 5/10/20/50bps 下是否仍成立；
7. **交易可行性**：涨跌停/停牌/整手/容量约束下是否仍成立；
8. **多重检验计数**：把"看过的所有尝试"登记为 N（`22` 3.3）。

**红线**：任何"只在这个窗口/这个参数/这个子样本好"的结果，默认按噪声处理 [J]。

## 九、集成与融合：为什么"多模型平均"经常不奏效

**[T] 方法**：

- Bagging：降方差（随机森林）；
- Boosting：降偏差（GBDT）；
- Stacking：用元模型学基模型权重——**必须在样本外训练元层**，否则二次过拟合；
- 简单平均/分位平均：最稳的基线，但要求基模型误差不太相关。

**[E] 本项目的融合教训**：

- 2×W5+pit（分位排名加权，2:1）是全史最好的组合（F22）；
- 单 die 有效 ≠ 融合有效：尾部加权单 die +3.1/+2.0pp，按 2:1 融合后消失（F29/F31）；
- 异构融合器（等权/R1 门控/R2 相对动量/**stacking**）全否；
  stacking 在 72 期对齐窗 **3.62% vs 基线 19.67%**、月回撤 −37.98% vs −19.66%；
- **机制解释** [J]：元层训练样本太少 + 基模型高度相关 + 融合层把 2024-25 段的结构变化学成噪声。

**结论**：融合层本身是一个模型，必须像主模型一样接受验证与多重检验；不要因为"集成通常有效"就先验相信。

## 十、可解释性与诊断：SHAP 也会骗人

- **特征重要性**：树模型的 split-based importance 偏好高基数/相关特征；
- **SHAP**：加性归因，默认特征独立；相关特征下会把贡献分配给任意一个；对过拟合模型解释得头头是道；
- **部分依赖/ALE**：展示边际关系，但相关特征下不可信；
- **消融**：最可靠的因果式检查——去掉/替换特征，看 OOS 表现；
- **稳定性选择**：多次子样本选择，保留稳定特征。

**用途**：解释是给**研究者**找 bug 的，不是给模型"背书"的。一个漂亮的 SHAP 图不能证明模型有效 [J]。
