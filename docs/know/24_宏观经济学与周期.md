# 宏观经济学与周期（从政策到截面收益的传导链）

> 定位：解释"宏观变量为什么可能影响股票收益"，以及**为什么宏观择时在统计上极难**。
> 本文件不提供择时信号；它提供：指标地图、传导机制、识别陷阱、可检验假设。
> 与本项目相关：`app/regime.py` 已存在（测试覆盖率 60%），但宏观信号尚未进入生产判决。
> 证据标签见 `20` 号文件。宏观数据的**发布日期与修订**问题见 `09`（PIT）。

## 一、宏观分析的三个层次

```
增长（产出/就业/消费/投资）
    ↕
通胀（CPI/PPI/工资/房价）
    ↕
流动性与信用（货币/社融/信贷/利率/汇率）
```

**[J] 分析顺序**：先判断"增长与通胀的状态"，再判断"政策如何反应"，最后才判断"资产价格反映了多少"。
直接跳到"宏观数据 → 买什么"是信噪比最差的用法。

## 二、国民核算与主要指标

**[T] GDP 三种核算法**：生产法（增加值）、收入法（要素收入）、支出法（消费+投资+净出口）；
理论上相等，实际有统计误差。

**中国常用月度/季度指标**：

| 指标 | 频率 | 看什么 | 陷阱 |
|---|---|---|---|
| GDP | 季 | 总量/结构/平减指数 | 同比为主；基数效应；季调口径 |
| 工业增加值 | 月 | 生产端景气 | 同比；春节错位 |
| PMI（统计局/财新） | 月 | 环比扩散指数（50 为荣枯线） | 是环比情绪，不是增速 |
| 社零 | 月 | 消费 | 同比；汽车/石油权重扰动 |
| 固定资产投资 | 月 | 投资（累计同比） | 累计口径；基建/地产/制造业拆分 |
| 进出口 | 月 | 外需/价格效应 | 美元计价；基数与价格 |
| CPI/PPI | 月 | 通胀/上游价格 | 食品/能源扰动；翘尾因素 |
| 社融/新增信贷 | 月 | 信用扩张 | 领先性有时滞；口径多次调整 |
| M1/M2 | 月 | 货币活期化/流动性 | M1 口径 2025 起调整（见官方公告）[U] |
| 工业企业利润 | 月 | 盈利周期 | 同比；上游集中 |

**通用陷阱**：

1. **同比 vs 环比**：同比受基数影响，环比受季节影响；中国官方月度数据**同比**为主，季调序列不总是可用；
2. **累计 vs 当月**：固定资产投资等是累计同比；直接做环比会错；
3. **修订（revision）**：初值、修正值、最终值差异可能很大；回测必须用**当时可见**的版本（PIT）；
4. **发布滞后**：GDP、社融等有固定发布日历，但市场提前交易预期；
5. **口径变更**：统计口径调整（如 M1 纳入个人活期存款等）会让历史序列不可比——**用之前先查公告** [U]。

## 三、货币、信用与政策

### 3.1 货币创造

**[T] 信用货币事实**：银行贷款创造存款，货币不是"央行发行后被乘数放大"的简单单向过程；
货币乘数在现实中不稳定。央行控制的是**基础货币价格/数量**与**监管/宏观审慎条件**。

### 3.2 政策工具

**中国（中国人民银行）**：

| 工具 | 作用 | 备注 |
|---|---|---|
| 公开市场操作（OMO，7 天逆回购为主） | 短期流动性/政策利率 | 利率走廊下沿附近 |
| MLF/买断式逆回购等 | 中期流动性/报价基准（历史上） | 工具与定位会调整，以最新公告为准 [U] |
| LPR（1Y/5Y） | 贷款定价基准 | 由报价行报价，与 MLF/OMO 关系随改革变化 |
| 存款准备金率 | 数量型工具 | 降准释放长期流动性 |
| 再贷款/再贴现/结构性工具 | 定向支持 | 科技/绿色/普惠/地产等 |
| 汇率管理/逆周期因子 | 汇率与资本流动 | 目标是"有管理的浮动" |

**海外**：联邦基金利率 + 资产负债表（QE/QT）；欧央行负利率历史与 APP/PEPP；
日本 YCC/QQE（2024 年后退出 YCC、加息——具体以当时公告为准 [U]）。

**[T] 泰勒规则（Taylor, 1993）**：i = r* + π + α(π − π*) + β·产出缺口；
它是政策描述/基准，不是精确决策函数；各国权重与目标不同。

### 3.3 传导渠道

| 渠道 | 机制 | 对股票的含义 |
|---|---|---|
| 利率/贴现率 | 无风险利率 ↓ ⇒ 估值 ↑ | 成长/长久期资产更敏感 |
| 信贷 | 贷款可得性 ⇒ 投资/消费 | 银行、地产、周期行业 |
| 汇率 | 出口竞争力/外资流入 | 出口链、外资重仓 |
| 资产价格/财富 | 房价/股价 ⇒ 消费 | 消费板块 |
| 预期/信号 | 政策立场本身是信息 | 风险溢价整体变化 |

**陷阱**：**政策意图与政策效果不是一回事**；传导有时滞、有阻塞（资产负债表衰退、信贷需求不足）；
市场往往提前交易"预期中的政策"，数据发布时反而是"卖事实"（`22` 事件研究）。

## 四、通胀与财政

**[T] 菲利普斯曲线（预期增广）**：π_t = E[π_t] + κ(y_t − y*) + 供给冲击；
短期通胀与产出缺口正相关，长期货币中性。

**[T] 货币数量论**：MV = PY；长期通胀与货币增长相关，短期关系不稳（V 不稳定）。

**[T] 财政可持续性**：债务/GDP 的动态 Δd ≈ (r − g)/(1+g)·d − 基本盈余；
当 r > g 时，需要持续基本盈余或通胀/重组来稳定债务。

**[E] 财政-货币协调**：财政扩张 + 货币宽松的组合对通胀/汇率/资产价格的影响取决于
产出缺口、汇率制度与央行独立性；历史样本有限 ⇒ 先验弱。

**中国财政特殊性**：中央+地方、一般公共预算+政府性基金（土地财政）、地方债务与化债政策、
专项债节奏；对基建/地产/银行的影响是宏观到行业的主要通道 [E]。

## 五、经济周期：四种周期与两种识别方法

### 5.1 周期叙事（从业框架，非学术共识）

| 周期 | 长度（经验） | 驱动 |
|---|---|---|
| 基钦（库存） | 3~4 年 | 库存/需求错配 |
| 朱格拉（资本开支） | 7~11 年 | 设备投资周期 |
| 库兹涅茨（建筑/地产） | 15~25 年 | 人口/城市化/地产 |
| 债务周期 | 长短不一 | 信用扩张与去杠杆（Dalio 框架，[J] 非学术共识） |

**美林时钟**（增长/通胀四象限）是流行的从业框架，但实证上不稳定、样本依赖强 [E/J]。

### 5.2 统计识别

- **[T] 动态因子模型**：用大量指标提取少数共同因子（Stock & Watson, 2002）；
- **[T] VAR/FAVAR**（Sims, 1980；Bernanke-Boivin-Eliasz, 2005）：脉冲响应与方差分解；
- **[T] Markov 切换**（Hamilton, 1989）：数据驱动状态划分；
- **[T] Nowcasting**：混频数据 + Kalman/桥方程（Giannone-Reichlin-Small, 2008），
  目标通常是**当前季度 GDP**，不是未来收益；
- **[U] DSGE**：理论一致但拟合/预测争议大（Romer, 2016 的批评）；用作情景分析而非信号源。

**共同陷阱**：

1. 周期划分是**事后**的，实时点最不确定（端点问题）；
2. 样本里只有少数几个完整周期 ⇒ 统计功效极低；
3. 结构变化（人口、全球化、地产模式、政策框架）让历史规律不可外推；
4. 用"修正后数据"回测宏观策略 = 前视（`09`）。

## 六、宏观到资产价格的映射

### 6.1 贴现率-现金流分解

**[T] 价格 = 未来现金流的贴现和**。宏观变量的影响必须落到：

- **无风险利率**（贴现率）；
- **风险溢价**（贴现率）；
- **现金流增长**（盈利）；
- **现金流不确定性**（风险）。

**读法**：同一个宏观数据（如 CPI 超预期）可能通过多条渠道作用于不同资产，
符号取决于"当前处于什么状态"⇒ **不存在全局固定的宏观-资产映射** [J]。

### 6.2 经验规律（证据强弱不一）

| 规律 | 证据 |
|---|---|
| 收益率曲线倒挂领先衰退（美国样本） | [E]，但时滞与假阳性都存在 |
| 通胀上行期价值/能源/金融相对占优 | [E]，样本依赖 |
| 实际利率上行压制成长/长久期 | [E] |
| 信用利差走阔领先风险资产下跌 | [E]，但时点难把握 |
| 股债相关性随通胀状态切换 | [E]，1970s 正、2000s 负、近年再变 |
| 宏观因子对截面收益的解释力 | [E] 弱且不稳定，远不如市场/规模/价值因子 |

## 七、中国宏观的特殊性（[E]/[J]）

- **多目标政策**：增长、就业、通胀、汇率、金融稳定、产业政策同时存在 ⇒ 单一泰勒规则拟合差；
- **五年规划与产业政策**：对行业轮动有实质影响，但提前识别政策力度极难；
- **三大引擎**：地产、基建、出口；对应地产链、财政链、出口链；
- **社融/M1 的领先性**：历史上与经济活动/市场有相关性，但领先期不稳定、口径多次调整 [E/U]；
- **双轨利率**：政策利率与市场利率（DR007/国债收益率）并存，传导有时滞；
- **数据质量**：地方数据、季调、修订、口径调整；用之前查原始发布（`09`）。

## 八、与本项目的映射与可检验假设（全部未验证）

**现状**：`regime.py` 已存在但未进入生产判决；覆盖率 60%（`14`）。宏观择时的成本：
增加一层模型风险 + 参数拟合 + 时点依赖，而收益信噪比极低。

**可检验假设** [J]（任一条都要预注册 + 两轴 + 成本口径）：

1. **状态条件化**：在"信用扩张/收缩"两种状态下，现役 W5 因子的 IC/头部收益是否有稳定差异？
   （先做诊断，不做择时）
2. **风格交互**：社融/PMI 的变化方向与小盘/价值风格收益的交互项是否显著（HAC + 聚类）？
3. **风险预算**：宏观状态只用来调**风险预算**（敞口/波动目标）而不是选股，是否改善 MDD 而不损超额？
4. **nowcasting 对照**：用实时（PIT）宏观数据构造的 nowcast 与用修正后数据的 nowcast，
   策略表现差多少？——这个差值就是"前视成本"的度量。

**红线**：任何宏观信号不得使用**事后修正数据**或**未来才知道的发布日历**；
不得以"宏观要有用"为前提倒推参数。
