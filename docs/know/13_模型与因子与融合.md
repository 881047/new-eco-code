# 模型、因子与融合（"为什么是这套、试过什么不管用"）

来源：`app/models/trainer.py`、`app/weekly/scores.py`、`app/factors/factor_engine.py`、
`app/weekly/plan.py` 实读；因子数取自 2026-09-11 打分存档实开（`scores_20260911.npz`）。

> 模型方法论（标签/验证/过拟合/融合/可解释性）见 `27_机器学习与建模方法论.md`；
> 本文只写本项目现状与被否方向。

## 一、两条生产线（别混）

| | **月频基线**（生产 `model_score`，pin 用它） | **周频袖套**（终端主策略） |
|---|---|---|
| 代码 | `app/models/trainer.py` + `daily_score.py` | `app/weekly/scores.py` + `plan.py` |
| 标签跨度 | `HORIZON = 21`（约一月） | `HORIZON = 5`（周） |
| 训练窗 | 36 个月滚动（**exp_train_months 判决：60/120/999 全否**，全期 −11~−18pp、长窗臂 IC 反而更高但收益崩 —— 追 regime 是收益来源不是缺陷，路径正式关闭；见 `experiments/05_label/exp_train_months_result.json`） | `TRAIN_MONTHS = 36` + **禁运 3 个锚点**（`EMBARGO=3`） |
| 集成 | 4 种子 × 50 轮，分位排名均值 | `SEEDS=(42,7,123,2024)`、`ROUNDS=50` |
| 因子面板 | `factor` 表（月频截面） | 31 因子 × 5819 股 × 651 锚点（20140103→20260911） |
| 产物 | `models/lgb_YYYYMM*.txt` + `model_score` 表 | `data/weekly/scores_<asof>.npz`（含 meta） |

**共同点**：LightGBM `objective=regression / metric=rmse`；现役超参
`num_leaves=31 / min_data_in_leaf=200 / lr=0.05 / feature_fraction=0.8 / bagging=0.8(freq=1) / lambda_l2=1.0 /
deterministic=True + 固定 seed`；**固定轮数、不开早停**（2026-09-04 实测：早停平均只长 27 棵树、近期退化成单树桩）。

## 二、特征（周频面板 31 个）

- **价量 22**：`rev_5`、`mom_20/60/120/250`、`vol_20/60`、`skew_20`、`ret_max20`、`turnover_20`、
  `turnover_chg`、`amount_log`、`illiq`、`bias_20/60`、`high_52w`、`low_52w`、`beta_250`、`size`、`ep`、`bp`、`dv_ttm`
- **财务 6**：`roe`、`netprofit_yoy`、`or_yoy`、`grossprofit_margin`、`debt_to_assets`、`eps_yoy`
- **龙虎榜 3**：`lhb_net20`、`lhb_org_net20`、`lhb_cnt20`（稀疏，未上榜 = NaN，LightGBM 原生处理缺失）

两个**意图锁**（别"修正"）：

- `rev_5` 用近端窗口 `[T−5,T]`，动量系列统一从 `T−5` 起算 —— 反转窗与动量窗**有意不重叠**。
- 财务因子用披露日 `ann_date` 对齐到**其后第一个交易日**；缺披露日用法定截止日保守估计（宁可滞后，不可前视）。

## 三、标签与中性化

- **周频标签**：`forward_excess = open(t+1+H)/open(t+1) − 1`，再减**当日可交易票池等权均值** ⇒ 学的是**超额**。
- **月频标签**：`trainer.forward_return`（复权收盘，窗口内退市/停牌回退到最后一个有效价），再减同行业均值。
- **中性化顺序**（`fe.neutralize`）：截面 2%/98% winsorize → 行业去均值 → z-score。
  行业口径：`W5` die 用**当前快照**（与生产同源）；`pit` die 用**申万一级 PIT**（`neutralize_pit`）。
- 稀疏事件面板会在这个 winsorize 上整行归零 ⇒ 必须用专用实现（见 09 号）。

## 四、多路打分怎么合成

## 五、被否掉的模型层方向（别重跑，详见 05 号）

- **模型族替换**（XGB / Cat / MLP / Transformer）：10+ 轮全否，共同失败方式 = 削掉 2024-25 那段收益。
- **异构融合器**（等权 / R1 门控 / R2 相对动量 / stacking）：全否。stacking 对齐窗 72 期
  **3.62% vs 基线 19.67%**、月回撤 −37.98% vs −19.66% ⇒ 不封装。
- **尾部加权**（F29/F31）：单 die 有效（+3.1/+2.0pp），按 2:1 融合后消失。
- **风格残差化**（F40）：线性正交 ≠ 尾部中性（size 倾斜搬家而非消失）。
- **超参网格**（F47/F47b/F47c，六格结清）：现役**全史局部最优**；唯一"全史持平、ACTIVE 更好"的是
  C4（leaves 127）—— 按判据不采纳，且 **2026-09-14 用户拍板结清，不进生产**（见 05/14 号）。
- **qlib 官方配方**（leaves 210-250 / λ2 580，见 06 号）也没打过现役（C5 14.69/13.75 vs 18.00/17.30）。
- **"负因子反用 / 让所有因子一起干活"**（F58~F65，2026-09-13 夜~09-14 早）：四轮用法（剔除 / 倾斜 /
  当特征 / 符号对齐后等权合成）+ 生产构型两套种子独立 A/B **全否** ⇒ **不上线**。
  ⚠️ 术语（**因子方向对齐 / 极性统一 / 符号调整**）与"要不要为此改模型层"的实测结论见 **§七** ——
  那是这条线唯一还值得读的部分（它同时给了一把"噪声标尺"）。
- **风险模型配权 / 约束凸优化**（F71，2026-09-14 早，理论层 26 号 §2）：逆波动率与最小方差
  （cvxpy 精确解、单票 ≤3%、换手预算 0.25/0.50）在连续 harness 上把全史 MDD 降了 2.5~3pp，
  但 **留出集毛超额 12.2~12.9pp vs 等权 17.72pp（−4.8~−5.6pp）** ⇒ 判据不通过、**结清**。
  机制与 F54/F55/F68 同一条：**α 在高波动的微盘尾部，风险模型做的第一件事就是把它削掉**。

## 七、因子极性（方向对齐 / 极性统一 / 符号调整）

**标准术语（用户 2026-09-14 给定）**：把每个因子的方向统一成"分越高越好"的过程，标准叫法是
**因子方向对齐 / 极性统一 / 符号调整**（三个词说同一件事的不同侧面）。它只在**对符号敏感的环节**
上起作用：等权/IC 加权合成、线性打分、人工门禁的方向判定。

**本项目实测（F70，2026-09-14 早；生产面板 + 生产 `scores.train`，4 种子 × 50 轮 × 153 个重训点全跑）**：

| 臂 | 做了什么 | FULL IC | 相对 `A_BASE` 的 top100 重叠 | 逐票秩相关 |
|---|---|---|---|---|
| `A_BASE` | 原样（保真对照） | 0.0854 | — | — |
| `B_ALLNEG` | **31 个因子全部取负**后重训 | 0.0856 | 均值 **87.4%**（最低 75%） | 0.949 |
| `C_SIGN` | 按**极性表**取负 24 个负极性因子后重训 | 0.0855 | 均值 **87.6%**（最低 75%） | 0.950 |

头部超额（top100 等权 − 同截面等权，%/期；配对差相对 `A_BASE`）：FULL 0.590 → 0.609/0.605pp
（**+0.019/+0.015pp，t=1.44/1.15**）、ACTIVE 0.250 → 0.290/0.298pp（+0.040/+0.047pp，t=1.15/1.51）——
**都不显著**。

⇒ **两条结论都要留着**：

1. **"树模型对符号不变 ⇒ 极性统一是 no-op"这个机制判断被实测推翻**（我原本的推理是"取负只把
   候选切分镜像 ⇒ 逐票不变"）。真实情况：LightGBM 的**分箱/直方图/并列判定不是符号对称的**，
   同一份数据取负重训会落到**另一组解**上 —— 单重训点单种子最明显（top100 只重合 **72%**、
   Spearman 0.905），4 种子分位排名集成后收敛到 **87%**。
2. **但符号不携带信息**：三臂的三段 IC 几乎逐位相同（FULL 0.0854/0.0856/0.0855、
   DEAD 0.0865/0.0868/0.0870、ACTIVE 0.0725/0.0728/0.0727）⇒ 取负只是把模型换到
   **另一个等价质量的解**上。即 **"极性统一"在模型层既不是收益来源、也不是损失来源**。

**⇒ 回答"要不要为极性统一改造模型层"：不需要。** 改与不改，模型拿到的信息一样（IC 不变），
只是换一组持仓（~12%）—— 生产不该被这种无信息的重排扰动；而"负因子反用"本身在组合层已四次
实测 + 独立 A/B 全否（F58~F65）。

**⚠️ 副产品：一把"解噪声"标尺（可复用）**。一次**信息量不变**的模型扰动就能
① 让 top100 换掉 **12.4%**（单种子单重训点 **28%**），而生产每周自然换手是 **13.7%**；
② 在头部超额上"造出" **+0.02pp/期（t≈1.4）** 的**假象**。
⇒ **top100 层 10% 量级的集合差异、t<1.6 的收益差，都不能当"改善"的证据**（判改善仍须走配对检验
加两轴判据）。以后审任何"换名类/重训类"实验都可以拿这条当量级参考。

**极性表（生产 31 因子；死区 2020-09~2023-12、5 日标签、头部 10% 超额符号；样本内）**：
**负极性 24 / 正极性 7**。负极性名单 = `mom_20/60/120/250`、`bias_20/60`、`size`、`vol_20/60`、
`turnover_20`、`turnover_chg`、`roe`、`grossprofit_margin`、`netprofit_yoy`、`or_yoy`、`eps_yoy`、
`amount_log`、`high_52w`、`low_52w`、`skew_20`、`ret_max20`、`beta_250`、`lhb_net20`、`lhb_cnt20`
（正极性 7 个：`bp`、`ep`、`dv_ttm`、`debt_to_assets`、`illiq`、`rev_5`、`lhb_org_net20`）。
读法：在本项目的截面与窗口里，**"动量"实际是反转、"质量"是反向、"规模"越小越好** ——
与 F67（超额活在微盘段）互相印证。⚠️ 这张表**只用于解释与人工合成实验**；生产不用它（树自己定方向），
完整读数（含每个因子的头部超额与 t）在 `experiments/05_label/F70_polarity_invariance_result.json`。

**极性表只能用在训练前（反例，别踩）**：把**已拟合**的生产归档模型（`data/models/ens/lgb_202608_s*.txt`）
喂 `−X`，输出立刻被打乱 —— **Spearman −0.27~−0.42、top100 只剩 5% 重合** ⇒ 谁在**推分/线上**改符号，
等于让模型读错方向。（这条是 F70 第一版把"推分端取负"误当成"极性统一"留下的检查 —— 我做错一次，
所以写下来防复发。）


## 八、因子生命周期仪表盘（2026-09-25 首次全库读数；`scripts/factor_lifecycle_monitor.py`）

调研来源：`plans/neweco-model-innovation-survey-20260925.md`（行业标准循环 = 挖掘 →
IC/半衰期/拥挤度监控 → 因子库迭代）。本节为**研究层事实表**：只读监控，不改生产打分；
红黄绿灯是事实标签不是判据——任何"降权/剔除"动作仍须 §一 纪律（A/B + 预注册）。

⚠️ **同日 bug 修正记录**：初版 `load_close_grid` 只加载 t+21 目标日价格 ⇒ 月末与网格行
靠巧合配对（95 期命中 15）、|IC| 系统性抬高约 2 倍 ⇒ 首版读数作废（同源 bug 曾令
alpha_pool 筛查误报"0/189 通过"）。修复后 = 全日历区间加载；教训：**按日期索引查行
的网格配对，先断言行数 = 期望期数**。

口径：`factor` 表 31 因子 × 月末（152 期）；标签 = `trainer.forward_return` 同式
（21 开市日复权收益，含退市回退）；逐月 Spearman rank IC；**强度保持比** =
|近12月IC| / |此前长窗IC|（<1 衰减、负值 = **符号翻转**）；**拥挤比** = 近12月
|多空(20%−20%)| / 此前同口径。⚠️ 近12月窗 = 2025-09..2026-09（n=12），读数会漂。

**修正版全库结论：12 红 + 2 黄 + 17 绿 —— 因子库正处风格迁移中段**
（与 B0ctl20"2020+ 超额 ≈ 0"互证：老盘的超额集中在前段历史）。
