# 知识地图与文献路线（理论层入口）

> 本文件是**理论层（20~29 号）的总入口**。生产层（01~14 号）回答"本项目现在是怎么做的、动它有什么后果"；
> 理论层回答"这个做法背后的数学/经济机制是什么、边界在哪、学术界试过什么、还可能是哪里错"。
> 两层冲突时：**代码与产物 > 生产层 > 理论层**。理论不能直接上线，只能产生可检验假设。

## 一、证据标签（本系列所有文档通用）

每条重要结论都尽力标一个标签，避免把"教材定理"和"某篇论文的经验结论"和"我的判断"混在一起：

| 标签 | 含义 | 可信度 |
|---|---|---|
| **[T]** | 定理/恒等式/定义（数学上可证明，不依赖数据） | 高，但要注意前提条件 |
| **[E]** | 有公开实证文献支持的规律 | 中；样本期、市场、方法都可能改变结论 |
| **[J]** | 本知识库作者的推断/判断（未单独立项验证） | 低~中；必须写成可检验假设才能用 |
| **[U]** | 未核实/有争议/开放问题 | 不许当依据引用 |

数值引用规则不变：**任何数字必须带窗口/口径/来源**；理论层的经典文献只保证"作者/年份/标题/期刊"级别，
不保证逐页结论数值——要引用具体数值时必须回到原文。本系列关键文献的元数据于 **2026-09-13** 用
OpenAlex/Crossref 抽查过（标题、年份、DOI 可对上；在线优先年份可能与期刊卷年不同）。

## 四、按任务的阅读路线

**路线 A：想改选股模型/加因子**（最常见）
`27`（标签/验证/过拟合）→ `23`（异象与复制危机）→ `22`（多重检验）→ `05`（先查是否已证伪）→ `01`（预注册）。

**路线 B：想改风控/仓位/组合构型**
`26`（风险度量、Kelly、回撤控制）→ `11`（本项目口径）→ `01`（两轴判决）→ `05`（F2/F25/F37 的教训）。

**路线 C：想改执行/成交/成本模型**
`25`（冲击成本、执行算法）→ `10`（A股制度与费用）→ `04`（产物与账本）→ `08`（换 pin 规矩）。

**路线 D：想加宏观/择时/风格轮动**
`24`（宏观框架与信噪比）→ `22`（时间序列与伪回归）→ `23`（因子视角）→ `14`（未结事项）。

**路线 E：想碰衍生品/波动率**
`28`（定价与对冲）→ `25`（成本）→ `26`（风险预算）→ `10`（A股可用工具与保证金制度）。

**路线 F：新会话接手**
`14` → `01` → `02` → 按需要跳生产层；理论层只在"要设计新方案"时读。

## 五、理论 → 生产的转换协议（不过这道闸的理论不许上线）

1. **写成可检验假设**：必须能回答"如果假设为真，哪个可观测量会怎么变"；
2. **先查证伪台账**（`05`）：已否掉的方向不重跑，除非有新证据；
3. **预注册判据**（`01`）：窗口、基准、成本口径、样本外标记、通过阈值、候选数量 N；
4. **最小实验**：先跑最便宜、最可能失败的实验（负结果也是产出）；
5. **两轴判决**：超额 **和** 最大回撤一起看；
6. **独立复核**：换实现/换人/换数据口径各做一次（见 `06` 的外部 Agent 纪律）；
7. **回写台账**：进 `05`（结论）与 `07`（若是事故）；若改口径/流程，走 `08` 换 pin 三步同步。

## 六、怎么读一篇量化论文（14 问清单）

按顺序问；任何一问答不上来，这篇论文的结论就只能当"线索"，不能当"依据"。

1. **Universe**：股票池是什么？含不含微盘、退市、ST？市值加权还是等权？
2. **Sample**：样本期多长？覆盖了哪些市场状态（牛/熊/震荡、制度变更）？
3. **Data vintage**：用的是初值还是修正后数据？有没有 PIT（时点）处理？
4. **Look-ahead**：财报、公告、指数成分、宏观数据是否按**可得时点**对齐？
5. **Costs**：扣了多少交易成本？冲击成本怎么估？容量多大？
6. **Trading**：换手多少？成交假设（收盘/开盘/VWAP）？涨跌停/停牌怎么处理？
7. **Multiple testing**：作者试了多少个因子/参数？有没有 DSR/PBO/Bonferroni 类修正？
8. **Out-of-sample**：样本外是真留出、滚动，还是"全样本回测"？
9. **Replication**：别人复制出来了吗？发表后是否衰减（McLean-Pontiff）？
10. **Mechanism**：经济机制是什么？风险补偿、行为偏差、制度摩擦，还是数据伪影？
11. **Robustness**：换权重、换断点、剔极值、换子样本后还在吗？
12. **Statistical vs economic**：显著吗？扣成本后还赚钱吗？这两问是分开的。
13. **Capacity**：策略规模上去后收益衰减多快？谁在对面交易？
14. **Incentives**：作者/机构的利益立场？论文是否为了发刊而挑了最好看的那半？

## 九、本理论层的边界（没覆盖什么）

- **高频/超低延迟工程**：FPGA、内核旁路、共置机房、逐笔重建全链路；25 号只讲经济机制与成本模型。
- **信用衍生品/结构化产品的高级定价**：23/28 只到 Merton、强度模型与基本对冲。
- **加密资产/DeFi**：制度与微观结构差异太大，不混入 A 股框架。
- **纯宏观预测的完整 DSGE 建模**：24 号只讲与资产价格相关的部分。
- **中文文献的系统覆盖**：本层以英文经典 + 中国监管原文为主；中文实证文献需要另建专题。
- **任何"直接可抄的 alpha"**：本层不提供因子公式合集——已发表因子在 A 股的边际价值极低且拥挤 [J]。
