# 组合优化与风险管理（给定预测，怎么下注、怎么活下来）

> 定位：从"预测信号"到"持仓权重"的转换层，以及风险度量/约束/归因。
> 与本项目相关：两轴判决（超额 + MDD）、杠杆被否（F2）、风险刻度是一根斜线（F25/F37）、
> 现金拖累（F24）、top-N + 退出带构型（`13` 六）。
> 证据标签见 `20` 号文件。

## 一、均值-方差：理论上正确，工程上危险

**[T] 基本问题**：max_w wᵀμ − (γ/2) wᵀΣw，或给定目标收益最小化方差；
含无风险资产时，最优组合 = 切点组合 + 无风险资产（两基金分离）。

**[E] 估计误差主导**：Merton (1980)、Michaud (1989)、DeMiguel et al. (2009) 反复指出：
μ 的估计误差远大于 Σ 的估计误差；把样本均值直接塞进优化器，会得到**极端、集中、换手高**的权重，
样本外表现常常不如等权。**优化器会放大你没意识到的估计误差**。

**[T] 约束的价值**：Jagannathan & Ma (2003) 证明，即使约束是"错的"，
只要有卖空限制/权重上限，也能显著改善样本外表现——因为它限制了误差放大的方向。
**含义**：约束不是为了"合规"，本身就是正则化。

**工程结论** [J]：

1. 收益预测要比协方差预测**更保守**（收缩、排序、只取 top-N）；
2. 权重约束（单票上限、行业上限、换手上限）必须有；
3. 任何优化器上线前先和"等权/排名权重"对照，打不过就不用（本项目目前就是规则化 top-N）。

## 二、协方差的估计：N/T 问题是核心

**样本协方差的问题**：

- N（资产数）与 T（期数）同量级时，样本协方差**病态**，最小特征值被压低、最大特征值被抬高；
- 求逆会放大噪声（`21` 第五节的 Marchenko-Pastur）；
- 缺失数据、停牌、新股、退市导致非平衡面板。

**解决路径**：

| 方法 | 思路 | 备注 |
|---|---|---|
| 因子风险模型 | Σ = BΣ_fBᵀ + D | 大幅降维；暴露矩阵质量决定成败 |
| 收缩（Ledoit-Wolf） | 向结构化目标（常数相关/单因子）收缩 | 有闭式解；实证稳健 |
| EWMA/GARCH/DCC | 让协方差随时间变 | 危机时反应快，但参数多 |
| 贝叶斯/因子先验 | 给 Σ 一个先验 | 需要设定先验强度 |
| 随机矩阵去噪 | 截断/收缩噪声特征值 | 需要估计噪声谱 |

**检验清单**：Σ̂ 是否对称、正定？条件数多大？换窗口后权重跳多少？
把 Σ̂ 换成**故意加噪**的版本，结论还稳定吗？（压力测试估计误差）

## 三、收益预测的收缩与融合

- **横截面收缩**：把原始预测压缩到均值附近（按排名/分位映射），降低极端预测的权重；
- **[T] Black-Litterman (1992)**：以市场均衡隐含收益为先验，把主观观点按置信度融合；
  观点可以是绝对/相对、带不确定性；
- **贝叶斯组合**：后验收益 = 先验精度与数据精度的加权；数据少时先验主导；
- **多模型融合**：加权平均/分位数平均/堆叠；**权重必须样本外估计**，
  否则融合层会二次过拟合（本项目 stacking 全否，见 `13`/`27`）。

## 四、稳健优化与约束体系

**[T] 稳健优化**：把 μ、Σ 的不确定性写成集合（椭球/区间/场景），在**最坏情况**下优化；
代价是保守，收益是避免"参数微小变动导致权重爆炸"。

**必须显式建模的现实约束**：

| 约束 | 原因 |
|---|---|
| 单票/行业/风格上限 | 误差放大、合规、风险集中 |
| 换手上限/交易成本 | 成本是确定的，alpha 是不确定的 |
| 持仓数上限/最小权重 | 整手、费用地板、管理成本（本项目 `10` 三补） |
| 现金/整手/可交易域 | 实际可投（PIT 六层，`09`） |
| 做空/杠杆限制 | A 股制度 + 项目已否杠杆（F2） |
| 回撤/波动目标 | 两轴判决中的第二轴 |

**求解**：QP/SOCP 用于凸约束；含基数/整手/非线性成本时用 MIQP 或启发式 + 可行性修复。
**陷阱**：不可行问题、解不唯一、求解器容差导致约束越界、目标函数里混了不同量纲（收益 vs 成本）。

## 五、风险度量：从方差到尾部与路径

| 度量 | 定义/性质 | 用途与弱点 |
|---|---|---|
| 波动率 σ | 收益标准差 | 对称；不区分上下行 |
| VaR | 分位数损失 | 不次可加；不描述超过阈值的损失 |
| ES/CVaR | 超过 VaR 的条件均值 | **[T] 一致性风险度量**（Artzner et al., 1999）；可用 LP 优化（Rockafellar-Uryasev, 2000） |
| MDD | max(1 − nav/cummax) | 路径依赖；对起止点敏感 |
| CDaR | 回撤的条件均值 | Chekhlov et al., 2005；可凸优化 |
| Ulcer Index | 回撤的 RMS | Martin & McCann, 1989 |
| 偏度/峰度 | 高阶矩 | 尾部与非线性 |
| EVT | 极值理论拟合尾部 | 样本极少；模型风险高 |

**[J] 选择原则**：

1. 目标函数如果只写方差，优化器会去卖尾部保险（short volatility）——这是历史反复发生的爆仓模式；
2. 用 ES/CVaR 比 VaR 稳健；用 MDD 更贴近体验但**路径依赖、样本内过拟合风险高**；
3. **多度量同时看**（两轴），不要用一个数当唯一目标。

## 六、风险预算：波动率目标、风险平价与分散化

| 方法 | 核心 | 证据/争议 |
|---|---|---|
| 波动率目标 | 把组合波动调到目标水平 | Moreira-Muir (2017) 报告改善；Cederburg et al. (2020) 质疑其稳健性与可实施性；Harvey et al. (2018) 支持波动率目标改善尾部 |
| 风险平价/ERC | 各资产风险贡献相等（Maillard et al., 2010） | 不用估计 μ；对相关性估计仍敏感 |
| 最大分散化 | 最大化分散化比率（Choueifaty-Coignard, 2008） | 权重可能极端；需约束 |
| 分层风险平价 HRP | 聚类 + 递归平分（López de Prado, 2016） | 稳定但非最优化；对距离度量敏感 |
| 杠杆厌恶/风险平价批判 | Asness et al. (2012) | 风险平价可能只是"债券 beta + 杠杆" |

**共同点**：都不预测收益，只分配风险；因此在低信噪比环境下比"预测收益再优化"稳健，
但也**放弃了 alpha 信息**。本项目是"信号排序 + 风险刻度"混合体（F25）。

## 七、仓位管理：Kelly 与它的危险

**[T] Kelly 准则（Kelly, 1956）**：最大化长期对数财富；离散两值下注：

```
f* = (p·b − q) / b        （b = 赔率，p = 胜率，q = 1−p）
```

连续近似（超额收益 μ−r、波动 σ）：

```
f* ≈ (μ − r) / σ²
```

**性质**：长期增长率最大；但**回撤可以非常大**、对参数估计极度敏感；
估计误差下"全 Kelly"会导致过度下注 ⇒ 实务用**分数 Kelly**（1/4~1/2）[E/J]。

**Kelly 与杠杆的关系**：f* > 1 意味着需要杠杆；本项目 F2 已证伪 1.5×/2.0×（杠杆在 alpha 未转正前禁）。
**但要注意**：F2 否的是"在既有信号上放大敞口"，不等于"Kelly 框架错误"——
两者的问题不同：前者是杠杆效应，后者是下注规模估计 [J]。

**参数不确定性下的 Kelly**：应在 (μ, σ) 的后验上做期望/稳健优化，
而不是把点估计当成真值；否则会系统性下注过大（本项目 F25 的线性敞口关系是同一类问题的实证版）。

## 八、回撤控制与止损

- **[T] CPPI**（Black & Jones, 1987）：把资产分成"风险仓 + 安全垫"，风险仓 = m ×（总资产 − 底线）；
  理论上限制回撤，但**跳空/流动性危机时失效**；
- **[T] OBPI**：用期权复制下限；成本 = 放弃上行；
- **[T] Grossman-Zhou (1993)**：连续时间下控制回撤的最优策略；假设连续交易、无摩擦；
- **[E] 止损的实证**：本项目 415 只次事件研究显示"扛胜过割"；A/B 年化 −25.76% ⇒ 固定/动态止损已关闭（`05`）；
- **原因**：止损把"波动"变成"已实现损失"，在均值回复/噪声主导的市场里损害收益；
  但在**趋势/基本面恶化**场景下止损是必要的——关键在于区分噪声与信息 [J]。

**替代思路**（未验证）：用**波动率目标/风险预算**做连续降杠杆，而不是离散止损；
用**回撤约束优化**（CDaR）替代"触发式清仓"。

## 九、绩效评价与归因

- **[T] Sharpe (1966, 1994)**：SR = (E[R] − R_f)/σ；对非正态/自相关要用修正版（SR 的 iid 假设）；
- **Sortino**：只罚下行波动；
- **Calmar**：年化收益 / |MDD|；本项目 F39 用的是"年化 ÷ |回撤|"；
- **信息比率（IR）**：主动收益 / 跟踪误差（Grinold-Kahn）；
- **[T] Brinson 归因**（Brinson-Hood-Beebower, 1986）：配置效应 + 选择效应 + 交互；
- **因子归因**：把收益回归到市场/size/value/momentum 等因子，看残差 alpha；
- **成本归因**：显性费用、滑点、冲击、机会成本分列（`25`）；
- **多重检验**：绩效评价本身也要 DSR/PBO（`22`），否则"最好的那个回测"没有统计意义。

## 十、与本项目的映射与可检验假设

**已核实事实**：F2 杠杆被否；F25 敞口与超额近似线性（R²=0.955）、MDD 同步上升；
F37 提高投入率至 0.993 但 MDD −32%→−41% ⇒ 未采纳；F24 现金拖累 −6.9pp；
F41 满仓全史 +18.00/+17.30pp、MDD −36.9%，但留出集 +10.38/+11.80pp（t=1.15/1.28 不显著）；
F45 留出集月均 +0.84/+0.93pp、月 σ≈3.48pp；现役构型 top100/8×/0σ/1.5×（`02`/`13`）。

**可检验假设** [J]（全部未验证，需预注册）：

1. **风险预算层**：在选股信号不变的前提下，用"波动率目标"或"回撤预算"替代固定敞口，
   能否在不降低全史超额的前提下改善 MDD？（注意 F25 的教训：风险刻度不是 alpha）
2. **约束优化**：把 top100 + 退出带换成"带单票/行业/换手约束的凸优化"，
   在**同成本、同可交易域**下两轴表现如何？
3. **尾部度量**：现役组合的 ES(5%)、CDaR 与 MDD 的关系；是否在某些年份有隐藏的尾部集中？
4. **Kelly 校准**：用 F41/F45 的收益分布反推隐含下注规模，与现行 w=1.0 是否一致？
   若不一致，差在参数不确定性还是风险偏好？

**红线**：

- 任何"提高收益"的改动都要回答它是否只是**提高风险刻度**（F25/F37 的教训）；
- 任何风险模型/约束改动都是**换 pin**（`08`），不得静默改判据。
