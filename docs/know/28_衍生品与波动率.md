## 二、期货：定价、基差与展期

**[T] 持有成本模型**：F = S · e^{(r − q)T}（r 无风险利率，q 股息率/便利收益）；
商品期货还要加仓储、保险、便利收益。

**关键量**：

- **基差** = 现货 − 期货；**基差风险** = 对冲工具与现货不完全同步；
- **展期收益（roll yield）**：期货贴水（backwardation）时多头赚展期，升水（contango）时亏；
- **股指期货贴水**：A 股 IC/IM 长期贴水反映对冲需求/融券约束/市场情绪；
  贴水是对冲成本，也是"市场情绪/拥挤度"的潜在信号 [E/J]；
- **保证金与强平**：杠杆的路径依赖——即使方向最终正确，中途也可能被强平 [T]。

**[T] 最小方差对冲比率**：h* = Cov(S, F)/Var(F)；对冲后剩余风险 = 基差风险。
动态对冲（滚动调整）会引入交易成本与路径依赖。

## 三、期权定价：从二叉树到随机波动率

### 3.1 无套利边界与二叉树

- **[T] 看涨期权上下界**：max(S − K e^{−rT}, 0) ≤ C ≤ S；看跌类似；
  put-call parity：C − P = S − K e^{−rT}（欧式、无摩擦、无股息）；
- **[T] 二叉树（CRR, 1979）**：离散复制；步数 → ∞ 收敛到 BSM；可处理美式提前行权。

### 3.2 Black-Scholes-Merton

**[T] BSM 公式**（无股息欧式看涨）：

```
C = S·N(d1) − K·e^{−rT}·N(d2)
d1 = [ln(S/K) + (r + σ²/2)·T] / (σ·√T)
d2 = d1 − σ·√T
```

**假设**（每一条都是风险源）：几何布朗运动、常数波动率、无摩擦、可连续对冲、无股息、
无跳跃、借贷利率相同、无套利。

**Greeks**：

| Greek | 含义 | 风险 |
|---|---|---|
| Delta ∂C/∂S | 方向暴露 | 非线性（gamma） |
| Gamma ∂²C/∂S² | delta 的变化率 | 靠近到期/平值时爆炸 |
| Vega ∂C/∂σ | 波动率暴露 | 波动率曲面变化 |
| Theta ∂C/∂t | 时间衰减 | 卖方的主要收益来源 |
| Rho ∂C/∂r | 利率暴露 | 长久期期权更敏感 |

### 3.3 波动率曲面与模型扩展

- **[E] 隐含波动率微笑/偏斜**：不同行权价的隐含波动率不同（股票指数通常左偏），
  说明 BSM 的常数波动率假设被拒绝；
- **局部波动率（Dupire, 1994）**：σ(S,t) 校准到整个曲面；能拟合价格但动态对冲表现差；
- **随机波动率（Heston, 1993）**：波动率自身是均值回复过程；能产生微笑；
- **跳跃扩散（Merton, 1976）**：加泊松跳跃解释短期偏斜；
- **粗糙波动率**：Hurst 经验上低（Gatheral 等），但估计/检验争议大 [U]；
- **数值方法**：蒙特卡洛、有限差分、傅里叶变换（Carr-Madan）；美式用 LSM/树。

**陷阱**：模型能拟合今天的曲面 ≠ 能预测明天的曲面；**校准参数不稳定**是常态 [J]。

## 四、波动率：可预测性最强的"资产"

### 4.1 波动率度量

| 度量 | 定义 | 特点 |
|---|---|---|
| 已实现波动率 RV | 高频收益平方和 | 依赖采样频率；微观结构噪声 |
| EWMA | σ²_t = λσ²_{t−1} + (1−λ)r²_{t−1} | RiskMetrics 经典 λ≈0.94（日频） |
| GARCH 族 | 条件方差模型 | 见 `22` 5.3 |
| HAR | 日/周/月 RV 回归（Corsi, 2009） | 长记忆、参数少、稳健 |
| 隐含波动率 IV | 期权价格反解 | 前瞻 + 风险溢价 |
| 波动率风险溢价 VRP | IV − 后续 RV | 通常为正（卖方补偿）[E] |

**[E] 核心经验事实**：

1. 波动率有聚集性、均值回复、长记忆；
2. **波动率可预测性远强于收益率可预测性**；
3. IV 通常高于后续 RV（VRP），但危机时 IV 可能低估尾部；
4. 波动率与收益的相关性通常为负（杠杆效应），但状态依赖。

### 4.2 波动率交易与产品

- **方差互换**：公平执行价 ≈ 风险中性下已实现方差的期望；可用期权组合复制（model-free）；
- **VIX 类指数**：隐含方差的无模型度量（CBOE VIX 方法）；境内波动率指数历史/发布状态需查最新公告 [U]；
- **策略**：跨式/宽跨式（做多波动）、日历价差（期限结构）、方差风险溢价（卖波动，尾部风险极高）、
  delta 对冲后的 gamma/vega 交易；
- **ETF/ETN 类波动率产品的路径依赖与展期损耗**：长期持有与指数收益不一致 [E]。

## 五、对冲：从 delta 到尾部

| 对冲目标 | 工具 | 关键风险 |
|---|---|---|
| 市场 beta | 股指期货/ETF | 基差、贴水、保证金 |
| 行业/风格 | 行业 ETF/期货（有限） | 工具不完整、相关性漂移 |
| 波动率 | 期权/variance swap | 模型风险、流动性、尾部 |
| 尾部 | 虚值 put/尾部策略 | 长期负 carry；时点极难 |
| 汇率/利率 | 对应期货/互换 | 基差、政策、资本管制 |

**动态对冲的成本**：连续对冲假设在离散时间 + 交易成本 + 跳跃下不成立；
gamma 大的头寸在跳空时损失可能远超模型预测。

## 六、可转债（A 股特有的混合工具）

**结构**：债底（信用债）+ 看涨期权（转股权）+ 条款（转股价、下修、强赎、回售）。

**定价要素**：正股价格/波动率、转股价、信用利差、剩余期限、赎回/回售条款、流动性。

**交易特性**：

- T+0 交易（与股票 T+1 不同）；
- 无涨跌幅限制？——转债有 20%/30% 临时停牌机制（以最新交易规则为准）[U]；
- 强赎条款会造成"转股/卖出"的时限压力；
- 转债与正股的套利/对冲需要考虑融券可得性（已受限）。

**风险**：信用违约、强赎、流动性骤降、条款博弈、估值模型误差。

## 七、衍生品在量化策略中的四种用法

1. **对冲（hedging）**：剥离不想要的 beta/行业/风格，保留 alpha；
2. **表达（expression）**：用期权表达非线性观点/尾部保护；用期货加杠杆（本项目已否杠杆，F2）；
3. **信号（signal）**：基差/贴水、隐含波动率、期权持仓/情绪、期货持仓量；
4. **融资/资本效率**：用期货替代现货（basis trade、现金管理）。

**共同风险**：保证金/强平、对手方、流动性、模型风险、制度变化、成本被低估。

## 八、与本项目的映射与可检验假设（全部未验证）

**现状**：周频策略只做 A 股现货多头（+ 现金），不交易衍生品；执行在现货开盘价（`10`）。

**候选方向** [J]（依次需要数据、成本模型、预注册）：

1. **基差信号**：IC/IM 贴水变化是否包含市场风险偏好/拥挤度信息，能否在**不增加杠杆**的前提下
   改善风险预算或风格配置？
2. **对冲实验**：在留出集上，用 IF/IC 对冲袖套的市场 beta，风险调整后是否改善？
   必须计入贴水成本、保证金与基差风险。
3. **波动率目标**：用 IV/已实现波动率作为风险预算输入（不是方向信号），
   检验 MDD 是否改善（与 `26` 的假设 1 合并）。
4. **转债/期权数据**：现有数据源是否覆盖？覆盖度、PIT、条款数据质量如何？（先做数据诊断，不建策略。）

**红线**：

- 衍生品带杠杆与强平机制，**风险刻度与现货完全不同**；不得用现货回测的两轴结论直接外推；
- 任何衍生品数据/策略上线前，先查数据源与合约细则，并把保证金/强平建模进账本；
- 制度类问题以交易所最新规则为准，本文件的品种描述可能过期 [U]。
