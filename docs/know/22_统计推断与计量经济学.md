## 一、估计：从样本到参数

### 1.1 四类估计框架

| 框架 | 核心 | 优点 | 前提/弱点 |
|---|---|---|---|
| 矩估计（MM） | 用样本矩匹配总体矩 | 简单、稳健 | 效率低；矩条件选择主观 |
| 极大似然（MLE） | 最大化似然 | 渐近有效 | 分布假设错则偏；边界问题 |
| GMM | 用工具变量/矩条件 | 不要求完整分布；可处理内生性 | 权重矩阵选择；弱识别 |
| 贝叶斯 | 先验 + 似然 → 后验 | 小样本稳定、可量化不确定性 | 先验主观；计算成本 |

**[T] MLE 渐近性质**：在正则条件下，θ̂ 一致、渐近正态、达到 Cramér-Rao 下界（渐近有效）。
"正则条件"包括：参数可识别、真实参数在参数空间内部、对数似然足够光滑、信息矩阵非奇异。

**[T] GMM**（Hansen, 1982）：θ̂ 一致且渐近正态；有效性由最优权重矩阵 W = S⁻¹ 给出，
其中 S 是矩条件的长期方差（HAC 估计）。**弱工具变量时 GMM 的有限样本分布严重偏离正态** [E]。

### 1.2 偏差-方差与收缩

**[T] 分解**：对 y = f(x) + ε，E[(y − f̂)²] = σ² + bias(f̂)² + var(f̂)。
金融预测里 f 的信噪比极低，**稍微增加偏差换取大幅降方差通常是划算的**（岭回归、收缩、简单规则）。

**[T] 收缩/正则化**：

- 岭回归（L2）：系数先验 N(0, τ²)；牺牲无偏换方差；
- LASSO（L1）：自动稀疏；但相关特征间会随机选一个；
- 弹性网：L1 + L2；相关特征组更容易一起保留；
- 层次贝叶斯：不同组共享先验强度（部分池化）。

**[E] 收缩的实证价值**：Ledoit-Wolf 类协方差收缩在组合优化中通常优于样本协方差（`26`）；
DeMiguel et al. (2009) 发现等权（1/N）在不少数据上难被均值-方差打败——原因是估计误差而非理论错误。

## 二、假设检验：p 值不是"假设为真的概率"

**[T] 定义**：p 值 = 在 H0 为真时，观测到"至少同样极端"结果的概率。它**不是** P(H0 | data)。

**[T] 两类错误与功效**：显著性水平 α = P(拒绝 H0 | H0 真)；功效 1−β = P(拒绝 H0 | H1 真)。
样本量公式（双侧、均值差 Δ、方差 σ²）：

```
n ≈ (z_{1−α/2} + z_{1−β})² · σ² / Δ²
```

**[E/J] 本项目锚点**：留出集月 σ≈3.48pp；要在 2×SE 下分辨 "+10pp/年 ≈ +0.83pp/月"，
需要约 **70 个月**（F45，见 `02`/`11`）。这就是"8~12 周纸面运行在统计上证明不了超额"的算术来源。

**[T] 常见检验**：Wald（用估计值和协方差）、似然比 LR（比较似然）、拉格朗日乘子 LM（在约束下看梯度）。
三者渐近等价，但有限样本表现不同；边界参数（方差=0、相关系数=±1）要用非标准分布。

**p 值误用清单** [E]：

1. **可选停止**：边跑边看，显著就停 ⇒ 实际 α 远高于名义 α；
2. **多重比较**：试 N 个因子，至少一个"显著"的概率随 N 上升（见第三节）；
3. **HARKing**：先看结果再编假设（Hypothesizing After Results are Known）；
4. **p-hacking**：换窗口、换权重、换极值处理直到 p < 0.05；
5. **把不显著当"没效果"**：低功效研究只能证明"证据不足"，不能证明"效应为零"；
6. **把显著当"有用"**：统计显著 ≠ 扣成本后经济显著（`20` 第 14 问）。

## 三、多重检验与回测过拟合：本项目最相关的一节

### 3.1 控制什么

| 指标 | 控制的错误 | 适用 |
|---|---|---|
| FWER | 至少一次假阳性 | 少量、致命性检验（如生产阈值） |
| FDR | 假阳性占所有显著发现的比例 | 大量筛选（因子动物园） |
| DSR | "最好的那个 Sharpe 是不是从 N 次尝试里抽出来的" | 回测策略选择 |
| PBO | 回测最优策略在样本外的排名/表现分布 | 参数/策略搜索 |

### 3.2 方法清单

- **Bonferroni**：α/N；简单、保守，尤其当检验相关时；
- **Holm**：按 p 值排序逐步拒绝；比 Bonferroni 有功效优势，仍控 FWER；
- **Benjamini-Hochberg（BH）**：控 FDR；适合"发现"而非"上线";
- **White Reality Check**（2000）：对多个策略/模型做数据窥探校正，用 bootstrap 得到最大统计量的零分布；
- **Hansen SPA**（2005）：White 检验的改进版，允许"差策略"存在，更贴近真实搜索；
- **Romano-Wolf**：stepdown 多重检验，兼顾相关性与功效；
- **DSR**（Bailey & López de Prado, 2014）：输入 = 试了多少次、收益非正态性、样本长度、方差；
  输出 = "校正选择偏差后 Sharpe > 0"的概率；
- **PBO**（Bailey et al.）：把回测切成组合，看样本内最优在样本外的排名分布；
  高 PBO ⇒ 参数选择本身是过拟合；
- **最小回测长度**：给定试错次数与目标 Sharpe，反推需要多长的样本才有判别力。

**[J] 本项目的历史结论**：F38 的 DSR 在 N=7 与 N=25 下都不通过（0.876/0.850、0.597/0.544，门槛 0.95，
用的是 w=0.873 的 IR）⇒ **候选数与选择偏差已经吃掉了显著性**。这不是"策略不行"，而是
"以现有样本量和试错次数，无法把它和运气区分开"。任何新方向必须**事前登记 N**，并对 N 打折。

### 3.3 交易策略的隐藏试错

除显式实验外，以下都算"试错次数"，必须计入 N [J]：

- 数据清洗/缺失值处理/极值窗口的选择；
- 特征集、标签 horizon、训练窗长度、中性化方式；
- 组合构型、持仓数、退出规则、费用假设；
- 中途看过的中间结果（即使没写进报告）。

**工程做法**：把每次"看数"当成一次检验登记（本项目 `05`/`07` 的做法就是这个意思）。

## 四、重采样方法：不依赖正态的推断

| 方法 | 适用 | 关键假设 |
|---|---|---|
| iid bootstrap | 独立样本 | 可交换性 |
| block bootstrap | 时间序列 | 块长 > 依赖长度 |
| stationary bootstrap | 平稳序列 | 随机块长；需要调参 |
| wild bootstrap | 异方差/面板 | 乘性扰动；适合聚类 |
| permutation | 可交换的零假设 | 处理/标签可交换 |
| jackknife/sub-sampling | 稳健估计 | 样本量足够、可重采样 |

**陷阱**：

- 时间序列用 iid bootstrap ⇒ 破坏依赖结构 ⇒ 置信区间过窄；
- 块长太短 ⇒ 低估长期相关；太长 ⇒ 有效样本少；
- permutation 在金融里常用于**标签置换**：若置换后仍显著 ⇒ 前视或静态风格暴露（本项目 F32b 判为后者）；
- bootstrap 的 p 值在边界/非光滑统计量（如最大 Sharpe）上要特别小心。

## 五、时间序列：从平稳性到波动率

### 5.1 平稳性与单位根

- **[T] 弱平稳**：均值/方差恒定，协方差只依赖滞后；
- **ADF**（单位根检验，H0 = 有单位根）、**PP**、**KPSS**（H0 = 平稳）——两类检验的零假设相反，
  结论冲突时要看功效与样本；
- **[E] 伪回归**（Granger-Newbold, 1974）：两个独立单位根过程回归会得到高 R² 和"显著" t 值 ⇒
  必须做协整或差分；
- **[E] 结构突变**：参数随时间变（政策、制度、技术），全样本回归的"平均效应"可能谁都描述不了。

### 5.2 ARMA / VAR / 协整

- **ARMA(p,q)**：自回归 + 移动平均；ACF/PACF 定阶；信息准则（AIC/BIC）；
- **VAR**：多变量 AR；Granger 因果检验是"预测增量"而非哲学因果；
- **脉冲响应**：变量受冲击后的动态路径；顺序（Cholesky）会影响结果；
- **协整**（Engle & Granger, 1987；Johansen, 1991）：非平稳变量存在长期均衡 ⇒ 误差修正模型（ECM）；
  配对交易的理论基础 [E]，但**交易成本与结构变化会吃掉大部分统计套利空间**。

### 5.3 波动率模型

| 模型 | 形式/直觉 | 特点 |
|---|---|---|
| ARCH (Engle 1982) | σ²_t 取决于过去残差平方 | 波动聚集的起点 |
| GARCH (Bollerslev 1986) | σ²_t = ω + αε²_{t−1} + βσ²_{t−1} | 简洁、稳健；稳态条件 α+β < 1 |
| EGARCH / GJR | 杠杆效应（负冲击放大波动） | 非对称 |
| 随机波动率（SV） | 波动率自身有随机扰动 | 更贴近理论；估计复杂 |
| HAR (Corsi 2009) | 用日/周/月三个尺度预测已实现波动 | 实证效果好、参数少 |
| 隐含波动率 | 期权市场的前瞻波动 | 含风险溢价；需模型反解 |

**稳定结论** [E]：**波动率可预测性远强于收益率可预测性**。这解释了为什么风险管理比择时更可行。

### 5.4 状态空间、Kalman 与状态切换

- **[T] 状态空间**：观测方程 + 状态方程；Kalman 滤波给出线性高斯下的最优递归估计；
- **Markov 切换**（Hamilton, 1989）：参数在若干状态间切换；状态是潜变量；
- **陷阱**：状态数是研究者选的；平滑估计（事后）比实时滤波好看得多 ⇒ 回测容易前视；
- **实时 vs 修正**：宏观数据/状态估计的"最终值"在实盘时不可得（PIT 问题，见 `09`/`24`）。

## 六、截面与面板：因子检验的正确姿势

### 6.1 Fama-MacBeth 两步法

1. 时间序列回归估计每只股票的 beta/暴露；
2. 每期做横截面回归 r_i = γ₀ + γ₁β_i + ε_i，得到 γ 序列；
3. 对 γ 序列做 t 检验。

**修正**：Shanken (1992) 指出第一步估计误差会让第二步标准误偏小；
自相关与异方差要用 HAC；**分组排序法**（portfolio sorts）也会受微盘、等权、断点选择影响。

**分组法的经典陷阱** [E]：

- 微盘股主导等权组合的超额收益（Hou-Xue-Zhang 2020 的复制危机核心之一）；
- 断点（30/70 分位）是研究者自由度；
- 市值加权后很多"异象"消失或大幅衰减；
- 交易成本与容量对小盘组合更致命。

### 6.2 面板标准误

**[E] Petersen (2009)**：公司效应（时间序列相关）与时间效应（截面相关）会同时存在；
标准误应至少双向聚类，或使用 Fama-MacBeth/HAC；不聚类会把 t 值抬高数倍。

**[E] DiD 的序列相关**（Bertrand, Duflo, Mullainathan, 2004）：政策评估中同一单位多期观测导致
标准误严重低估 ⇒ 聚类或块 bootstrap。

### 6.3 因果推断工具箱（政策/事件研究）

| 方法 | 识别来源 | 关键假设 |
|---|---|---|
| 事件研究 | 事件窗异常收益 | 无混淆事件、正常收益模型正确 |
| DiD | 处理组 vs 对照组前后差 | 平行趋势；无同期冲击 |
| IV | 工具变量 | 相关性 + 排他性；弱工具诊断 |
| RDD | 阈值附近的断点 | 连续性；带宽选择 |
| 合成控制 | 用加权对照组构造反事实 | 处理前拟合好；无溢出 |

**金融应用**：监管变更、指数纳入、政策冲击、退市/ST 事件。
**共同陷阱**：预期效应（市场提前反应）、同期政策叠加、样本小、研究者自由度。

## 七、高维与机器学习计量

- **[T] LASSO**（Tibshirani, 1996）：L1 惩罚；变量选择一致性需要"不可表示条件"等较强假设；
- **[T] 弹性网**（Zou & Hastie, 2005）：处理相关变量组；
- **自适应 LASSO**（Zou, 2006）：两步加权，改善选择一致性；
- **因子增广回归**（Stock & Watson）：用少数主成分捕捉共同因子；
- **[T] 双重机器学习**（Chernozhukov et al., 2018）：用 ML 估计 nuisance 函数 + 正交化矩条件，
  得到 √n 一致的因果参数；需要交叉拟合（cross-fitting）；
- **post-selection inference**：先选变量再推断会低估不确定性；要么样本拆分，要么专门校正；
- **因子动物园**（Feng, Giglio & Xiu, 2020）：用双重选择 LASSO 从大量候选因子中筛选，
  发现多数"新因子"在控制已有因子后不显著。

## 九、统计工作流（照这个顺序做，顺序错了结论就废）

1. **写下假设**（经济机制 + 可观测预测）；
2. **登记数据与口径**（窗口、股票池、PIT、成本）；
3. **登记判据**（主要指标、阈值、N、样本外）；
4. **看数据质量**（缺失、极值、断点、单位、修订）；
5. **主检验**；
6. **稳健性**（子样本、换权重、换断点、换成本、安慰剂/置换）；
7. **多重检验校正**（DSR/PBO/Bonferroni-FDR，取决于搜索规模）；
8. **经济显著性**（扣成本、容量、可交易性）；
9. **报告**：窗口/基准/成本口径/样本外标记 + 失败与边界；
10. **回写台账**（`05`/`07`/`08`），更新知识库。
