# A股市场生态与制度（制度如何塑造异象与风险）

> 定位：把"中国市场不是美国市场的复制品"写成可核对的结构性事实与机制假设。
> 与本项目相关：训练域=选股域（排除科创板/北交所）、PIT 六层过滤、微盘/壳价值/涨跌停/
> 程序化交易监管都会直接影响策略的有效性与容量。
> 本文件只写机制与时间线；**具体条款以交易所/证监会最新原文为准**。证据标签见 `20` 号文件。

## 一、市场版图与上市制度

| 层次 | 板块 | 关键特征 |
|---|---|---|
| 场内 | 上交所主板、科创板（688/689） | 科创板注册制试点；±20%；STAR 有做市制度 |
| 场内 | 深交所主板、创业板（300/301） | 创业板注册制；±20% |
| 场内 | 北交所 | 服务创新型中小企业；±30%；整手与沪深不同 |
| 场外 | 新三板（基础层/创新层） | 北交所的后备层；流动性与披露差异大 |
| 场外 | 区域性股权市场 | 不在本项目范围 |

**上市制度演进**：核准制 → 注册制。
科创板（2019）试点注册制 → 创业板（2020）→ 北交所（2021）→ **全面注册制**（2023-02-17 制度规则发布，
2023-04-10 首批主板注册制企业上市）[E]。
**含义**：上市供给增加、壳价值下降、退市常态化 ⇒ 小市值/亏损股的定价逻辑发生变化 [J]。

## 三、投资者结构与行为生态

**[E] 结构性事实**（具体比例逐年变化，引用数字前查交易所/证监会统计）：

- A 股个人投资者交易占比长期较高，换手率显著高于成熟市场；
- 公募基金有相对排名/考核压力，行为与散户不同但并非完全理性；
- 外资（QFII/沪深港通）持股集中在少数龙头，信息披露频率已下调（见时间线）；
- 量化私募/程序化交易规模在 2019 年后快速增长，监管随之加强；
- 游资/龙虎榜交易制造短期价格冲击与"席位效应"。

**行为含义** [E/J]：

- 追涨杀跌、处置效应、有限注意在 A 股可能更强；
- 短期反转/换手/波动类因子的有效性可能与散户结构相关；
- 当量化规模上升、监管收紧或披露变化时，这些因子的收益会衰减或改变形态；
- **任何依赖散户行为的异象都必须做制度/规模变化前后的分样本检验**。

## 四、政策市与监管周期

**[E] 政策对 A 股的实质影响**：

- 发行/退市/减持/交易制度直接改变供给与流动性；
- 产业政策（五年规划、专项支持）影响行业景气与估值；
- 货币/财政政策通过流动性、信用与风险偏好传导（`24`）；
- 监管对程序化交易、两融、北向披露的调整会改变策略的可行域。

**[J] 但"政策市"不等于"政策可预测"**：

- 政策目标多元（增长/就业/风险/产业/汇率），同一工具在不同状态下的含义不同；
- 事件样本少、结构突变多，统计上难以建立稳定映射；
- 市场往往提前交易预期，"政策落地"可能反而是卖点（`22` 事件研究）。

**研究方法**：政策文本 + 事件窗 + 分样本；必须用当时可得信息（PIT），不能用事后解读。

## 五、壳价值、退市与微盘生态

**[J] 机制链**：

```
上市资格稀缺（历史） → 借壳/重组预期 → 小市值/亏损股获得"壳价值"支撑
注册制 + 退市常态化 + 减持约束 → 壳价值下降 → 微盘/低价股的定价重构
```

**证据** [E]：

- 注册制与退市改革后，A 股"小市值+亏损"组合的收益结构发生变化；
- 微盘股在流动性收缩时跌幅更大（流动性风险，`25`）；
- 借壳/重组事件的超额收益随监管周期波动。

**对本项目的含义**：

1. 若策略超额部分来自微盘/壳价值，**它可能随制度变化消失**；
2. 剔除微盘后的对照实验（`22`/`23` 的假设）是必须做的稳健性检查；
3. ST/退市/长期停牌的处理必须走 PIT（本项目 `09` 六层过滤已覆盖名称与停牌，但要持续核对）。

## 六、流动性与交易制度对策略的约束

| 制度 | 对策略的约束 |
|---|---|
| T+1 | 无法日内平仓；隔夜风险不可控；高频/做市策略受限 |
| 涨跌停 | 一字板无法成交；接近涨跌停时的磁吸效应；执行顺延 |
| 融券/转融通受限 | 多空策略、对冲、套利容量受限 |
| 整手/最小报价单位 | 小资金无法精细配权；低价股有效价差高 |
| 程序化交易监管 | 报告义务、异常交易监控、频繁撤单风险 |
| 北向披露调整 | 跟风型"外资流向"信号失效 |
| 减持/再融资规则 | 大股东行为与供给冲击改变 |

**读法**：制度既是**摩擦**（成本、限制），也是**异象来源**（套利受限导致错误定价持续）。
两者会随制度变化同时改变 ⇒ 分样本检验是唯一可靠的做法 [J]。

## 七、数据生态与 PIT（与 `09` 交叉引用）

| 数据 | 来源 | 坑 |
|---|---|---|
| 行情/复权 | Tushare/AkShare | 复权因子、停牌、退市、ST 名称链 |
| 财务 | 定期报告/预告/快报 | 披露日、修正、重述、法定截止日 |
| 股东/龙虎榜 | 交易所披露 | 披露滞后、口径变化、稀疏 |
| 两融/北向 | 交易所/港交所 | 披露频率与范围已变（2024-08-19） |
| 宏观 | 统计局/央行/海关 | 发布滞后、修订、季调、口径变更（`24`） |
| 政策/公告 | 证监会/交易所 | 文本非结构化；需要 PIT 时间戳 |

**原则**：任何数据集都要问"**当时能不能看到**、**看到的是哪个版本**、**多久更新一次**"。

## 八、A 股因子的经验证据（谨慎版）

**先说结论**：A 股因子文献数量庞大、口径差异极大、发表偏差严重；
本知识库**不收录**具体因子收益率数字。以下只列方向性经验 [E/U]：

| 方向 | 经验 | 备注 |
|---|---|---|
| 市值/小盘 | 历史上有较强的小盘效应 | 与壳价值、微盘、流动性高度纠缠 |
| 反转（短中期） | A 股短期反转通常强于动量 | 与散户结构/交易制度相关 |
| 动量（中长期） | 不稳定，弱于海外 | 涨跌停/T+1/换手结构影响 |
| 价值/质量 | 阶段性有效 | 行业结构（金融/周期权重）影响 |
| 换手/波动 | 低换手、低波动有正溢价倾向 | 与流动性/情绪相关 |
| 分析师/预期 | 修正方向有信息 | 覆盖度与数据质量限制 |
| 事件类 | 预告/回购/减持等有短期效应 | 本项目 F3/F26/F27/F35/F42 已多次证伪周频用法 |

**本项目已有的证伪登记**（`05`）：13 个免费数据族周频 0 通过（09-13 夜补测第 11/12/13 族后合计 13 族，仅 2 族过统计门禁且组合层无用）；
月频事件因子 0/8；holder_chg_4q 是唯一过统计判据但组合层失败的因子。
**这些负结果的优先级高于任何"教科书说这个因子应该有效"**。

## 九、监管与合规红线（做策略前必须确认）

1. **程序化交易报告**：达到报告标准的账户/策略要报告；异常交易行为（频繁撤单、拉抬打压、
   自成交等）会被监控——具体标准见交易所细则；
2. **交易制度**：T+1、涨跌停、整手、融券限制；不得在回测中绕过；
3. **信息披露**：不得使用内幕信息；另类数据需确认合法性；
4. **减持/限售**：涉及大股东/董监高的数据与交易限制；
5. **投资者适当性**：衍生品/两融/科创板/北交所有门槛；
6. **本项目的定位**：纸面运行 + 个人账户，当前不涉及申报义务的判断；
   若资金/频率上升，**先做合规评估再上线** [J]。

## 十、与本项目的映射与可检验假设

**已核实事实（项目内）**：

- 训练域=全市场，选股域排除科创板（含 689）与北交所（`01` #7）；
- PIT 六层过滤：上市 60 日、停牌、ST/退、板块、市值分位、流动性（`09`）；
- 周频按开盘价成交、一字板顺延、T+1 校验（`10`）；
- F24：毛超额一半以上是 size 风格；实施缺口 −9.0pp（`05`）；
- 现役构型 top100/8×/0σ/1.5×（2 万档为 top6/1.0/0.20σ）（`13` 六）。

**可检验假设** [J]（全部未验证，需预注册）：

1. **微盘对照**：剔除最小 30% 市值后，F41/F45 的超额与 MDD 如何变化？
2. **壳价值代理**：构造"小市值+亏损+低成交+高换手"篮子，检验它在袖套超额中的暴露；
3. **制度分样本**：以 2024-04-30（退市新规）、2024-08-19（北向披露）、2024-10-08（程序化新规）
   为断点，检验因子的稳定性（注意：断点后样本很短，只能当方向）；
4. **涨跌停效应**：统计袖套信号股中"次日一字板"的比例与顺延成本，量化制度摩擦的实际代价；
5. **ST/退市重估**：把 ST/退市前后样本单独归因，看它们对超额与回撤的贡献（`09` 已过滤，但历史影响仍值得分解）。
