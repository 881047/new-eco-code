# 市场微观结构与交易成本（成交价、冲击成本与容量从哪来）

> 定位：回测里最容易被低估的不是 alpha，而是**成交**。本文件解释价差、冲击、执行与容量的机制，
> 以及 A 股制度的特殊约束。
> 与本项目相关：开盘价成交、10bps 滑点、一字板顺延、费用地板 ≈0.102% 往返、F24 实施缺口 −9.0pp、
> G3 资金投放率（见 `10`/`03`/`02`）。
> 证据标签见 `20` 号文件。

## 一、市场结构基础

**订单类型**：

- 市价单：保证成交、不保证价格；消耗流动性；
- 限价单：保证价格、不保证成交；提供流动性；有**逆向选择**风险（成交时往往对你不利）；
- 止损/条件单：触发后转市价，可能在流动性真空中滑价；
- 冰山/隐藏单：只显示部分数量；
-  IOC/FOK/Post-Only：交易所层面的成交条件（A 股规则相对简化）。

**撮合机制**：

| 机制 | 特征 | 价格发现 |
|---|---|---|
| 连续竞价 | 逐笔撮合，价格优先、时间优先 | 高频、连续 |
| 集合竞价 | 集中撮合一个价格 | 开盘/收盘价；抗操纵性较好 |
| 做市商报价 | 做市商双边报价 | 海外/科创板做市制度 |

**[E] 订单簿的形状**：买卖档位、深度、价差共同决定"立即成交的边际成本"；
流动性是**状态变量**——危机时价差扩大、深度蒸发（流动性共性/commonality）。

## 二、价差与信息：三个经典模型

### 2.1 Roll 模型（1984）

**[T] 直觉**：买卖价差导致成交价在买卖价之间跳动，相邻价格变化出现负自相关。
若 Δp 的一阶自协方差为负，价差估计：

```
有效价差 ≈ 2 · √( −Cov(Δp_t, Δp_{t−1}) )
```

前提：有效价格随机游走、价差恒定、无信息冲击。**不满足时估计会失真**（正自相关、漂移、跳跃都会破坏）。

### 2.2 Glosten-Milgrom（1985）

**[T] 直觉**：做市商面对知情交易者与噪声交易者，报价必须覆盖**逆向选择成本**。
价差 = 订单处理成本 + 库存成本 + 逆向选择成本。
含义：**价差不是纯摩擦，它包含信息租金**；信息越多，价差越大。

### 2.3 Kyle（1985）

**[T] 直觉**：知情交易者会隐藏在市场订单流里，价格随**净订单流**线性调整：

```
Δp = λ · (净订单流) + 噪声
```

λ（Kyle's lambda）是**价格冲击系数**：单位订单流推动价格多少。
λ 随信息不对称上升、随流动性（噪声交易量）下降。

**相关度量**：PIN/VPIN（信息交易概率）、订单流不平衡 OFI（Cont-Kukanov-Stoikov, 2014）、
Amihud 非流动性 = |收益|/成交额（Amihud, 2002）。

## 三、流动性的度量与共性

| 维度 | 指标 | 备注 |
|---|---|---|
| 宽度 | 报价价差、有效价差 | 即时成本 |
| 深度 | 各档挂单量、盘口金额 | 大单能吃掉多少 |
| 弹性 | 冲击后的恢复速度 | 冲击的持久性 |
| 及时性 | 成交速度、撤单率 | 高频/算法环境 |
| 价格冲击 | Kyle λ、Amihud、回归冲击曲线 | 规模成本的核心 |

**[E] 流动性共性**：个股流动性随市场整体流动性同向波动（尤其在危机时）；
这意味着"流动性风险"不能通过分散化完全消除 [E]。

## 四、价格冲击：从线性到平方根

### 4.1 冲击的组成

```
总冲击 = 临时冲击（买卖价差 + 即时消耗，会恢复）
        + 永久冲击（信息 + 库存效应，不恢复或慢慢恢复）
```

**[T] Almgren-Chriss (2000)**：临时冲击随**执行速度**线性增长，永久冲击随**累计成交量**增长；
在"冲击成本 vs 波动风险"之间做最优权衡，得到最优执行轨迹（通常介于 TWAP 与前置执行之间）。

**[E] 平方根律**：经验上，大单的冲击成本近似

```
冲击 ≈ Y · σ · √( Q / V )
```

Q = 订单量，V = 市场成交量，σ = 波动率，Y 为经验常数（不同市场/时段估计不同，量级为 O(1)，不是普适常数）。
含义：**冲击随规模的 1/2 次方增长**，而非线性；这直接决定策略容量。
（Tóth et al., 2011；Bouchaud 等的后续工作；常数与适用区间有争议 [E/U]。）

### 4.2 传播子模型

**[E] 冲击不是瞬间消失的**：一笔成交对后续若干笔/若干秒的价格都有影响，
影响核（propagator）通常按幂律衰减；"执行完就结束"的假设会低估成本。

### 4.3 容量估算

**容量 ≈ 可交易成交量中你能安全占的比例 × 该比例下的成本容忍度**。
经验起点：单日参与率 < 10%~20% 成交量，冲击仍可能达数十 bps；
**成本随规模上升、alpha 随规模衰减** ⇒ 容量曲线通常是凹的。

## 五、执行算法与实现缺口

**常见执行方式**：

| 方式 | 目标 | 风险 |
|---|---|---|
| TWAP | 时间均匀 | 不跟成交量，冲击大 |
| VWAP | 跟随成交量分布 | 预测误差；逆向选择 |
| POV（参与率） | 固定成交量占比 | 流动性差时拖长 |
| IS（实现缺口） | 最小化总成本（价差+冲击+风险） | 需要风险厌恶参数 |
| 流动性搜寻/暗池 | 减少信息泄漏 | 成交不确定；A 股不可用 |

**[T] 实现缺口（Perold, 1988）**：

```
IS = (实际成交均价 − 决策时价格) × 成交数量 + 未成交部分的机会成本
```

**关键点**：成本要按**决策时价格**度量，而不是按"第一笔成交价"；未成交的机会成本也是成本。
项目里"开盘价成交 + 10bps 滑点"是 IS 的一种简化，漏掉了"顺延造成的机会成本"与"冲击随规模变化" [J]。

## 六、做市与高频：库存风险与速度

**[T] Avellaneda-Stoikov (2008)**：做市商的最优报价 = 保留价格（考虑库存）± 价差；
库存偏离目标时向反方向偏移报价；风险厌恶与波动率决定价差宽度。

**[E] 高频竞争**：延迟优势会被军备竞赛吃掉（Budish, Cramton & Shim, 2015 的"频繁批量拍卖"提议）；
速度优势的收益具有**赢家通吃**特征。

**A 股语境**：程序化交易有报告与异常交易监控要求（见第八节）；
个人/小资金的优势不在速度，而在**容量小的策略**与**低频信号** [J]。

## 七、日内模式与价格发现

- **[E] U 型成交量**：开盘和收盘成交量高，中间低（海外尤其明显）；
- **[E] 隔夜 vs 日内收益**：两者统计性质不同；隔夜收益包含信息积累与情绪，日内包含流动性与做市行为；
- **[E] 收盘集合竞价**：沪深两市自 **2018-08-20** 起统一通过 14:57~15:00 收盘集合竞价产生收盘价
  （上交所此前为最后一笔交易前一分钟成交量加权），影响尾盘流动性与收盘价；
- **[E] 价格发现份额**：不同市场/工具（现货 vs 期货）对信息的贡献可以用 Hasbrouck 信息份额度量。

**陷阱**：日内模式会随制度/算法演化；用 2015 年的日内规律做 2026 年的执行假设是危险的 [J]。

## 八、A 股微观结构与制度约束（与 `10`/`29` 交叉引用）

| 制度 | 微观结构后果 |
|---|---|
| T+1 | 当日买入不可卖 ⇒ 日内反转/做市策略受限；隔夜风险无法日内平掉 |
| 涨跌停（主板 ±10%、创业/科创 ±20%、北交 ±30%） | 流动性黑洞、磁吸效应（接近涨跌停时加速）、一字板无法成交 |
| 最小报价单位 0.01 元 + 整手 | 低价股的有效价差占比高；小资金整手约束 |
| 融券限制 + 2024-07-11 起暂停转融券 | 卖空成本高/不可得 ⇒ 多空策略受限，反向套利弱 |
| 程序化交易监管（2024 规定，2024-10-08 施行） | 报告、异常交易监控、频繁撤单风险 |
| 北向披露调整（2024-08-19 起） | 实时资金流数据不再可得；跟风型信号失效 |
| 龙虎榜/公开信息 | 游资行为的可见痕迹；但披露滞后、易过拟合 |

**读法**：制度约束既限制策略，也**创造**局部的错误定价（套利受限）。
但制度会变——任何依赖制度的异象都必须做**制度变更前后的分样本检验** [J]。

## 九、交易成本建模实务

**显性成本**（可直接算）：佣金、印花税、过户费、交易所规费、融券费。

**隐性成本**（要建模）：

1. 买卖价差（即时成本）；
2. 临时冲击（与参与率、波动率相关）；
3. 永久冲击（信息泄漏）；
4. 时机成本（延迟成交的价格漂移）；
5. 机会成本（涨跌停/停牌/流动性不足导致未成交）；
6. 税费与制度成本（如可转债/期货的差异）。

**回测常见错误**：

- 用收盘价成交（含未来信息；A 股尤其严重）；
- 固定滑点不随规模/波动/流动性变化；
- 忽略未成交的机会成本（顺延的"隐形收益"）；
- 忽略冲击对后续价格的反身影响；
- 用"零成本换手"评估高频策略。

## 十、与本项目的映射与可检验假设

**现状（`10`）**：佣金万 2.5（最低 5 元）、印花税卖出 0.05%、过户费 0.001%、滑点 10bps；
往返费率地板 ≈0.102%；周频按开盘价成交，一字板/停牌顺延。

| 现象 | 可能的微观结构解释 | 可检验假设 |
|---|---|---|
| F24 实施缺口 −9.0pp | 现金拖累 + 整手/价格上限 + 顺延机会成本 | 把缺口按"未成交/现金/滑点/时机"分解，逐项归因 |
| 开盘价成交假设 | 09:32 执行档用实时行情；回测用开盘价 | 用分钟级数据估计 09:30~09:35 的实际冲击与延迟分布 |
| 10bps 滑点 | 对 100 万纸面账户可能偏低/偏高？ | 用成交额参与率 + 平方根律估算分档滑点（小/中/大资金） |

A/B → 预注册 → 重钉 → 提交带 Δ。不得在"修 bug"的名义下静默改成本口径。
