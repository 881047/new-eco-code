# 数学与统计（本项目实际用到的那些，含"什么时候会骗人"）

> 系统理论见 `21_数学基础与随机过程.md` 与 `22_统计推断与计量经济学.md`；
> 本文只写本项目实际用到的口径、算术与实证教训。

## 一、报数口径

- **算术年化 vs 复利年化**：分解贡献时用「平均每期 × 每年期数」的算术年化，因为**可相加**；
  复利年化单列。混用两个口径做加减 = 假读数。
- **超额** = 策略年化 − 基准年化（同窗口、同成本口径、同起止日）。
- **MDD** = `min(nav / nav.cummax() − 1)`（负数）。
- 任何超额必须同时给：窗口 / 基准 / 成本口径 / 样本外标记。

## 二、显著性

- **HAC（Newey-West）t**：重叠标签会让朴素 t 虚高；lag 取 `ceil(horizon/5)+1`
  （5 日标签 → lag 2；21 日 → lag 6）。
- **IC**：横截面秩相关。**本项目三次实证 IC 与头部（策略真买的 top 6~100）收益反相关** ⇒
  IC 只作参考，判决一律在组合层两轴做。
- **Bonferroni / DSR 回答的是不同问题**：同一份 t=4.28 在 N≤1000 的 Bonferroni 下仍显著
  （"超额>0"成立），而 DSR 问的是"这个 IR 是不是从 N 次尝试里抽到的最好那条"
  （本项目 F38 判它**不通过**）。
- **样本量算术**（本项目 F45 用）：月均超额的标准误 `SE = σ/√n`；要在 2×SE 下分辨
  "+10pp/年 ≈ +0.83pp/月"，需要 `n = (2σ/0.83)²`。留出集 σ≈3.48pp/月 ⇒ **约 70 个月**。
  这就是"8~12 周纸面在统计上什么都证明不了"的来历。

## 三、中性化的陷阱（F40 实证）

- 把信号对风格做**线性**残差化，只能保证"全截面线性无关"，**不保证尾部无关** ——
  实测：残差化后按残差取前 100 只的篮子，size 倾斜从 **−0.91σ 翻成 +0.36σ**（搬家而非消失），
  平均 |z| 反而由 0.33 升到 0.42。
- 结论：**秩相关口径的"仍显著"不等于组合层能赚钱**（F32b 的 +0.0279 → F40 的组合层否）。

## 四、训练/评估的无前视条件

- 标签只看未来（`open(t+1+H)/open(t+1) − 1` 相对当日票池等权）；特征只用 ≤ 锚点的数据。
- 截面标准化按**当日的横截面**做，不用全期统计量。
- 训练窗与生产**复用同一函数**（`trainer._train_window`），并留 **embargo = 3 个锚点**
  （5 日标签跨期 ⇒ 至少 3 才能切断与评估期的重叠）。
- 置换检验（打乱训练标签）后若残余 IC 显著 ⇒ 要么前视、要么**静态风格暴露**（F32b 判为后者）。

## 五、组合层的两条硬教训

1. **融合不单调**（F22/F29/F31）：单 die 有效 ≠ 融合有效；加 die 常稀释。
2. **风险刻度是一根斜线**（F25/F37）：加敞口同时抬超额与回撤，超额÷|MDD| 比值变化很小
   ⇒ 那不是 alpha，是杠杆；判决必须两轴一起看。
