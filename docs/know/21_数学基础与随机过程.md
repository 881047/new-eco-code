# 数学基础与随机过程（量化用得到的那些，含前提与陷阱）

> 定位：本文件是**工具层**，不是数学教材。每个小节只保留"量化里真的会用到的定理/公式 + 前提条件 + 常见误用"。
> 证据标签见 `20` 号文件；[T] = 可证明的定理，[E] = 实证规律，[J] = 判断。
> 阅读顺序建议：先看每节末尾的"量化用途"，需要推导时再回教材。

## 一、概率与测度：一切定价与风险的底座

**[T] 基本对象**：概率空间 (Ω, F, P)；σ-代数 F 是"可问的问题"的集合；随机变量是可测映射；
条件期望 E[X|G] 是 G-可测的、满足 ∫_A E[X|G] dP = ∫_A X dP 的随机变量。

**[T] 条件期望四条性质**（每次推导都要用）：

1. 塔性质：E[E[X|G]|H] = E[X|H]，当 H ⊆ G；
2. 可测量可提出：E[YX|G] = Y·E[X|G]，若 Y 是 G-可测；
3. 独立性：X ⊥ G ⇒ E[X|G] = E[X]；
4. 单调/控制收敛在条件期望下同样成立（需可积性条件）。

**[T] 测度变换（Radon-Nikodym）**：若 Q ≪ P，则存在密度 dQ/dP = Z ≥ 0，使 E_Q[X] = E_P[ZX]。
金融含义：**风险中性测度** Q 下的折现价格是鞅；Girsanov 定理给出把漂移"改掉"的密度（见第四节）。

**陷阱**：

- 条件期望是**随机变量**，不是数；"E[X|G] 等于某个数"只在 G 平凡或 X⊥G 时成立；
- 条件期望只几乎必然唯一：改动零测集不影响结论，但**逐点数值实现会变**；
- 厚尾分布下不一定存在期望/方差。金融数据里"样本均值存在"不代表"总体均值存在"。

**量化用途**：定价（测度变换）、风险（条件分布）、贝叶斯（后验 = 条件分布）、状态空间（滤波 = 条件期望）。

## 二、收敛、极限定理与"大样本"到底什么时候可用

**[T] 四种收敛**：几乎必然（a.s.）⇒ 依概率 ⇒ 依分布；L^p 收敛 ⇒ 依概率。
没有"依分布 ⇒ 依概率"；也没有"依概率 ⇒ a.s."（除非子列）。

**[T] 大数定律**：独立同分布且 E|X| < ∞ ⇒ 样本均值 → 总体均值（a.s.）。

**[T] 中心极限定理（CLT）**：iid、有限方差 σ² ⇒ √n(X̄_n − μ) →_d N(0, σ²)。
等价地：X̄_n 的标准误 SE = σ/√n。

**[T] Delta 方法**：若 √n(θ̂ − θ) →_d N(0, V)，则 √n(g(θ̂) − g(θ)) →_d N(0, g'(θ)² V)（g 可微）。
多维时用 Jacobian：V_g = J V Jᵀ。

**什么时候会骗人**：

- **厚尾/无限方差**：稳定分布（α < 2）下 CLT 不成立，收敛速度极慢，t 检验失效 [E]；
- **强相关**：时间序列/重叠样本的有效样本量远小于名义 n，必须用 HAC 或 block bootstrap（见 `22`）；
- **参数边界**：θ 在边界上（如方差为 0、权重为 0）时渐近分布不是正态（Chernoff 型）；
- **弱工具变量/弱识别**：有限样本分布远离正态，常规 t 检验不可靠 [E]。

**量化用途**：标准误、置信区间、t 统计量、组合权重的渐近分布。本项目 HAC lag 取 `ceil(horizon/5)+1` 就是这条线的工程化（`11`）。

## 三、鞅、停时与"没有免费午餐"

**[T] 鞅**：E[X_{t+1}|F_t] = X_t。下鞅/上鞅对应 ≥ / ≤。
Doob 分解：适应的可积过程可拆成"鞅 + 可预测的漂移"。

**[T] 可选抽样定理（OST）**：在适当条件下（有界停时，或一致可积），E[X_τ] = E[X_0]。
**没有这些条件时 OST 不成立**——这正是"加仓摊平/加倍下注"的数学陷阱：它把破产路径的损失推到零测集或无限时间。

**[T] 无套利与鞅**：市场无套利 ⟺ 存在等价鞅测度（在适当的无摩擦、可交易假设下）。
这是资产定价第一定理；第二定理把"市场完备"与"测度唯一"联系起来。

**量化含义**：

- "预测收益"= 找偏离鞅的过程；"风险溢价"= 在真实测度下的漂移，不是套利；
- 任何正期望系统的前提是**下注规模有限**且**不违约**；Kelly 与风险约束（`26`）是这件事的工程化；
- 择时/止损策略天然是停时问题，条件不满足时"回测赚了"可能只是幸存路径 [J]。

## 四、随机过程：从布朗运动到跳跃与自激

### 4.1 马尔可夫与泊松

- **[T] 马尔可夫性**：给定现在，未来与过去独立；转移核 P_t(x, A)。
- **[T] 泊松过程**：独立增量、到达强度 λ；间隔服从指数分布；到达次数 ~ Poisson(λt)。
- **[T] 复合泊松**：到达时带上随机跳跃幅度，用于跳跃-扩散与信用违约建模。

量化用途：订单到达、违约事件、跳跃风险、状态切换（HMM，见 `22`）。

### 4.2 布朗运动与 Itô 引理

**[T] 标准布朗运动 W_t**：W_0 = 0；独立增量；W_t − W_s ~ N(0, t−s)；路径连续但几乎处处不可微；
二次变差 [W]_t = t（这是随机微积分与普通微积分分岔的根源）。

**[T] Itô 公式**：X_t 满足 dX_t = μ_t dt + σ_t dW_t，f(t, x) 光滑，则

```
df(t, X_t) = (∂_t f + μ_t ∂_x f + ½ σ_t² ∂_xx f) dt + σ_t ∂_x f dW_t
```

多出来的 ½σ²∂_xx 项不是形式主义：它来自二次变差，是期权定价与凸性修正的核心。

**[T] Girsanov**：把漂移 μ 改成 r 的测度变换密度 Z_t = exp(−∫θ_s dW_s − ½∫θ_s² ds)，
θ_s = (μ_s − r)/σ_s。含义：**风险中性不是"世界真的没有风险"，而是把漂移重标定**。

**[T] Feynman-Kac**：抛物型 PDE 的解 = 某个扩散过程的期望折现。它把"解 PDE"和"蒙特卡洛模拟"连接起来。

### 4.3 均值回复与 Ornstein-Uhlenbeck

**[T] OU 过程**：dX_t = θ(μ − X_t) dt + σ dW_t，θ > 0。则

```
E[X_t] = μ + (X_0 − μ) e^{−θt}
半衰期 = ln 2 / θ
平稳方差 = σ² / (2θ)
```

量化用途：配对交易、利差、波动率/利率的均值回复、Kalman 滤波的状态方程。
陷阱：参数 θ 的估计对样本期极敏感；离散采样下 θ 与 σ 不能同时在高频极限下无偏识别（见 `22` 的单位根/采样问题）。

### 4.4 跳跃、Hawkes 与波动率过程

- **[T] Lévy 跳跃过程**：连续部分 + 跳跃部分；跳跃幅度分布与到达强度决定尾部；
- **[E] Hawkes 自激过程**：λ(t) = μ + ∫ φ(t−s) dN(s)，成交/波动具有"事件激发事件"的聚集性；
- **[E] 波动率聚集**：大波动后面跟着大波动（GARCH 类模型的经验基础）；
- **[E] 长记忆/粗糙波动率**：已实现波动率衰减接近幂律；Gatheral 等提出"波动率是粗糙的"（Hurst ≈ 0.1），
  但估计方法、样本与模型设定仍有争议 [U]。不要把它当作已定论的事实。

量化用途：尾部风险、执行成本（冲击随波动放大）、波动率预测（`28`）。

## 五、线性代数与矩阵分析：截面数据的骨架

**[T] SVD**：A = U Σ Vᵀ，奇异值非负且降序；rank、条件数、低秩近似都由它给出。
PCA = 对中心化矩阵做 SVD；第 k 个主成分的解释方差 = σ_k² / Σσ_i²。

**[T] 特征分解**：对称矩阵 A = QΛQᵀ；半正定 ⇔ 所有特征值 ≥ 0；协方差矩阵必须半正定。

**[T] 条件数与稳定性**：cond(A) = σ_max/σ_min；求解 Ax=b 的相对误差上界 ≈ cond(A)×机器精度。
病态矩阵下，"求逆"在数值上等于放大噪声。

**[T] 伪逆与最小二乘**：A⁺ = VΣ⁺Uᵀ；x = A⁺b 给出最小范数最小二乘解。

**[T] Sherman-Morrison**：(A + uvᵀ)⁻¹ = A⁻¹ − A⁻¹uvᵀA⁻¹ / (1 + vᵀA⁻¹u)。
用途：增量更新协方差/回归；前提是分母不为 0。

**[T] 常用矩阵微积分**：

```
∂(xᵀAx)/∂x = (A + Aᵀ)x
∂ tr(AX)/∂X = Aᵀ
∂ ln det(X)/∂X = X^{−ᵀ}
∂ tr(XᵀAX)/∂X = (A + Aᵀ)X
```

**[T/E] 随机矩阵理论**：对 N×T 的 iid 噪声矩阵，当 N/T → γ ∈ (0,1]，
样本协方差特征值谱收敛到 Marchenko-Pastur 分布，支撑区间约 [(1−√γ)², (1+√γ)²]（单位方差）。
含义：**N 与 T 同量级时，样本协方差的最大特征值会被噪声推高，最小特征值被压低**；
直接对样本协方差求逆会放大噪声（组合优化里的经典病根，见 `26`）。

**量化用途**：PCA/因子降维、风险模型、协方差收缩、组合优化、特征正交化、NMF/聚类。
**陷阱**：相关性与协方差不是一回事；标准化后做 PCA 与未标准化结果不同；PCA 的"因子"符号/旋转不唯一。

## 六、凸优化、对偶与算法

**[T] 凸集/凸函数**：任意两点连线仍在集合内；f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)。
凸优化的**局部最优 = 全局最优**，这是它相比深度学习最值钱的性质。

**[T] 拉格朗日对偶与 KKT**：在 Slater 条件（存在严格可行点）下，凸问题的强对偶成立；
KKT 是最优性的充要条件（凸 + 约束资格）。对偶变量 = 约束的边际价格（影子价格）。

**[T] 常见塔形**：

| 类型 | 目标/约束 | 量化例子 |
|---|---|---|
| LP | 线性目标 + 线性约束 | CVaR 优化、L1 收缩（可转 LP） |
| QP | 二次目标 + 线性约束 | 均值-方差、带换手惩罚的组合 |
| SOCP | 二阶锥约束 | 稳健组合、跟踪误差约束 |
| SDP | 半正定约束 | 协方差稳健估计、最坏情况风险 |

**[T] 算法谱系**：

- 梯度下降：凸且 L-光滑下 O(1/k)；强凸下线性收敛；
- 加速梯度（Nesterov）：O(1/k²)；
- 牛顿法：局部二次收敛，但每步要解 Hessian 线性系统；
- 内点法：LP/QP/SOCP 的多项式时间算法；
- 近端/ADMM：适合可拆分的非光滑问题（L1、总变差、分布式优化）。

**非凸的现实**：基数约束（最多持 K 只）、整手约束、交易成本的非线性、某些风险度量会产生非凸可行域；
精确求解常是 NP-hard。工程上要么凸松弛，要么启发式 + 事后检验可行性 [J]。

**量化用途**：组合优化（`26`）、执行优化（`25`）、稳健/收缩估计、模型融合的权重约束。
**陷阱**：无解与不可行是两回事；解不唯一时"最优权重"可能随求解器版本跳变；
数值容差会静默改变约束（例如"非负权重"在 −1e−12 处被接受）。本项目 `12` 号记录过精度漂移问题。

## 七、数值方法与蒙特卡洛

**[T] 浮点事实**：IEEE 754 只有有限精度；两个相近大数相减会产生灾难性抵消；
求和顺序影响结果（Kahan 求和/成对求和可缓解）；`float32` 的有效位数约 7 位十进制。

**[T] 蒙特卡洛误差**：估计量标准误 ≈ σ/√N；要达到 10 倍精度需要 100 倍样本。
方差缩减：对偶变量、控制变量、重要性抽样、分层抽样、公共随机数。
拟蒙特卡洛（Sobol/Halton）在高维光滑问题上可接近 O((log N)^d/N)，但维度高时优势下降。

**[T/E] MCMC 与粒子滤波**：贝叶斯后验/非线性状态空间的数值推断；诊断要看 R-hat、有效样本量、
轨迹与自相关，而不是"跑完了"。

**[T] 数值 PDE**：有限差分（显式/隐式/Crank-Nicolson）；稳定性（CFL 条件）、一致性、收敛性；
美式期权用自由边界/最小二乘蒙特卡洛。

**量化用途**：期权定价、风险模拟、状态空间滤波、参数不确定性传播。
**陷阱**：把"模拟收敛"当成"模型正确"；伪随机种子决定结论；重要抽样权重方差爆炸。

## 八、信息论与学习理论：复杂度与泛化的直觉

**[T] 熵**：H(X) = −Σ p log p；**[T] KL 散度**：KL(P‖Q) ≥ 0，不对称；
**[T] 互信息**：I(X;Y) = H(X) − H(X|Y) = KL(P(X,Y)‖P(X)P(Y))。

**[T] 最小描述长度/奥卡姆剃刀**：在模型族内，编码长度 + 拟合误差的最优权衡给出正则化的信息论解释。

**[T] 学习理论**：VC 维、Rademacher 复杂度、PAC-Bayes 界给出"泛化误差 ≤ 经验误差 + 复杂度项"。

**为什么这些界在金融里近乎无用** [J]：

1. 界假设 iid 或平稳，而金融数据是**非平稳、强相关、分布漂移**的；
2. 界通常是"最坏情况"，数值极松，无法指导模型选择；
3. 有效样本量（独立信息量）远小于行数，复杂度项被严重低估。

**仍有用的部分**：复杂度惩罚的方向、正则化的必要性、"参数越多越需要更强先验"的直觉。

## 九、谱分析、滤波与周期提取

**[T] 傅里叶/功率谱**：平稳时间序列可分解为不同频率的正弦叠加；谱密度描述各频率的能量。
**陷阱**：非平稳序列的谱没有稳定含义；趋势会污染低频；加窗（Hann/Hamming）会模糊分辨率。

**[T] 小波**：多尺度时频分析；适合非平稳/局部突变的信号，但边界效应与参数选择敏感。

**[T] Kalman 滤波**：线性高斯状态空间的最优递归估计；预测步 + 更新步；
数值实现要注意协方差对称性/正定性（Joseph 形式、平方根滤波）。

**[E] HP 滤波的争议**：Hodrick-Prescott 滤波在宏观里广泛用于提取周期，
但 Hamilton (2018, *REStat*) 批评其会产生虚假周期、端点不稳定，建议用回归替代。
**结论**：HP 滤波可以当"展示工具"，不宜当"信号生成器"。

**量化用途**：宏观 nowcasting、波动率/相关性状态估计、去趋势、季节性调整。
**陷阱**：滤波的实时值与最终修正值差异巨大（宏观数据尤其如此，见 `24`）；端点估计最不稳定。
