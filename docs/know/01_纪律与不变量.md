# 纪律与不变量（动手前必看）

来源：`CLAUDE.md` + `plans/weekly-terminal-plan-20260912.md` §6 + 本会话实测教训。这些都是踩过坑换来的。

## 一、判据类

1. **预注册**：跑数之前把判据写死（写进脚本 docstring/常量），跑完不许改判据；若事后发现判据写错，必须如实登记修正并说明为什么这不是"放宽"。
2. **组合层两轴判决**：任何"改进"都要同时看 **超额** 与 **最大回撤**。IC 只作参考 —— 本项目已三次实证"全截面 IC 与头部（策略真买的 top 6~100）收益反相关"。
3. **多重比较**：候选数量 N 要事前登记，判据用 Bonferroni/DSR 打折（F38 已判 DSR 不通过）。
4. **样本外只在开封前有效**：留出集（2024-01~2026-08）已被 F28 **一次性开封**并判不通过；之后任何在该窗上的读数都只是"方向性"，不产生新的显著性证据。
5. **改口径 = 换 pin**：A/B → 预注册 → 重钉 → 提交带 Δ。禁 `REGEN_GOLDEN=1`。
5b. **仅改「报数/呈现」口径 ≠ 换 pin**（2026-09-24 补，W2-F43）：若改动**不含任何判据阈值 / 窗口 / 参数**，只是改变读数怎么呈现（例：报告新增偏差列、把年化改成不报）⇒ **不算换 pin**，但**必须**登记一条 W2-F（或老盘对应行）并写明「影响读数 = 无」；凡**触及**预注册已冻结的阈值/窗口/参数 ⇒ 一律换 pin。⚠️ 边界判定写不下的场合，**从严**按换 pin 处理。

## 三、报告类

13. 报任何超额数字，**必须同时给窗口 / 基准 / 成本口径 / 样本外标记**。
14. 只报好看的半边 = 误导。失败必须写进证伪登记（计划 doc §7 与本知识库 05 号文件）。
15. 结论分三类写清：**已核实的事实 / 合理推断 / 未核实**。
17. **读数与产物必须在同一个动作里生成、同一次 commit 入库**（2026-09-20 加，用两次事故换的）：
    凡要进知识库的数字，先有被跟踪目录里的产物，再写文字 —— 只在会话里"跑出来了"不算证据。
    反例两件：① 九条口径项的判决表抄进权威文档后**脚本与产物双双失踪**（`logs/` 被 gitignore 是通道），
    只能整段撤回（14 号三补二十九·补）；② 把"门已过 / pin 已换"写在真跑**之前**，
    连 commit message 一起错（14 号三补二十八 §⑦、07 号 09-20 条）。
    配套硬闸：`scripts/audit_ledger_14.py`（审计第 8 项）—— 证据指针不存在 / 指向 `logs/` ⇒ 红。
18. **申报实验前先做覆盖度预检**（2026-09-20 加）：门禁对"整列无有效截面"的因子是
    `MIN_NAMES=200` 静默 `continue`、不留登记 ⇒ 第五轮申报 5 列、实际只有 4 列进死区判决，
